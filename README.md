# 名もなき文明 v0.5 — 自動で見守る・文明の記憶

ひとつの架空文明の歴史を眺めるブラウザシミュレーター。勝利条件はありません。v0.5ではドット絵・イベントの種類は増やさず、観察の操作性と過去から未来への因果関係を強化しました。

## 起動

Node.js 20以上。ZIPにはビルド済みの `dist/` が入っています。

```sh
node scripts/serve.mjs
```

`http://127.0.0.1:5173` を開きます。ソースを変更した場合は `npm run build`、テストは `npm test`。

## v0.6 Phase 1 開発版

新規世界では地域・居住地・共同体別の人口を記録し、確定した各年の人口を読み直せます。分岐待ちの年は未確定と表示し、情景は最後の確定年を表示します。旧セーブの地理は未確定として引き継ぎ、移行年までの情景を「推定情景」と表示します。保存には新しいキーを使用します。

人口の増減には従来の文明単位のルールを使います。

### Phase 2A

近隣との食糧交易、食糧事情による移住、交易路の共同管理を年末に計算します。河川の氾濫で交易路が途絶える場合があり、年代記から関連する記録を開けます。旧セーブの地理未確定人口は、受け入れ余力のある居住地へ少しずつ定住します。共同体の分立・制度の継承と、建物ごとの履歴は後続の作業です。

ブラウザー回帰テストは `npm ci`、`npx playwright install chromium` の後に `npm run test:browser` で実行できます。

## 自動選択モード

- 「選択も自動にする」をオンにして「自動で見守る」を押すと、選択肢が発生してから **2・4・7秒**（既定4秒）後、選択肢の一つを自動で選びます。
- 自動選択後は **それまでの進行速度のまま** 次の出来事へ進みます。自動選択はオン・オフ切り替え可能です。
- 自動選択をオフにすると選択肢のところで待機し、手で選択すると自動進行を再開します。
- 「自動進行を停止」で進行と選択待ちタイマーを停止します。年代記から過去を見る場合も停止します。
- 選択肢を選ぶ乱数はセーブデータに含めるシード付き乱数を使用。同じシードと同じ操作・設定なら同じ歴史を再現可能です。
- 選択待ちの残り秒数はセーブ対象ではありません。読み込み直したときは自動進行を再開してください。

## 文明の記憶

過去の出来事は、その場の数値変化だけで終わりません。以下の慣習・社会基盤が世代を超えて残ります。

| 記憶 | 生まれる契機の例 | 後世への作用の例 |
|---|---|---|
| 共同の穀物庫 | 穀物庫の建設・食糧の分配 | 飢饉・干ばつ時の食糧への影響を緩和 |
| 水路と堤の管理 | 灌漑・橋の修繕 | 食糧生産と人口許容量を補助 |
| 継続した交易網 | 交易所・渡し舟 | 人口許容量と文化交流に影響 |
| 記録の習慣 | 記録文化・文字の利用 | 知識の蓄積を後押し |
| 寄り合いの制度 | 共同の寄り合い | 制度の履歴として残る（直接効果は限定的） |
| 看病と衛生の知恵 | 看病など | 疫病による人口損失を部分的に緩和 |
| 移住者との共生 | 移住者の受け入れ | 文化的な履歴として残る（直接効果は限定的） |
| 分かれた共同体の記憶 | 分裂など | 文化的な履歴として残る（直接効果は限定的） |

これらは永続するとは限らず、社会や環境の条件に応じて徐々に弱まり、消えることもあります。画面の「文明の記憶」で現在の記憶を閲覧でき、過去観測中は当時の記憶が表示されます。年代記には成立・消滅が記録されます。

**重要な限界**：v0.5は社会制度の精密な数理モデルではありません。記憶の成立率や強度、効果は仮説的なゲームパラメータです。疫学・人口動態・地質学の実測値に校正したものではありません。また、建物の建設・修復履歴はv0.4と同じ簡略化モデルです。

## セーブデータと互換性

v0.4以前の保存形式（`version:2`）は引き続き読めます。旧版でまだ存在しなかった「文明の記憶」は読み込み時に空で初期化されます。**既に経過した過去の記憶が自動的に補完されるわけではありません。** v0.5で一から生成した世界では成立から喪失までの履歴が蓄積されます。
