## 1. D4-b 文化ごとの廃墟（`architecture-ruin-v1`）

- 廃墟になった施設・住宅の部品を、その時に建っていた世代の様式のまま描く（これまでは文化によらない共通の廃墟の形）。`src/architecture/scene-v1.ts` の `drawRuin`。
- 崩し方（Humanの指摘「パッと見で分からない」を受けて強めた2版目）：
  - 元の高さの20〜45%だけが残る（1版目は40〜65%）。崩れ方は3pxごとに、建物ごとに決まっている
  - 3pxごとの区切りの約4分の1は、地面近くまで崩れる
  - 残った部分は風化した灰色がかった茶色に寄せ、少し暗くする。開口部（暗い色）はそのまま
  - 足元にがれきの帯を置く
- 描画は読み取り専用で、同じ建物はいつも同じ形に崩れる（テスト）。

## 2. D4-c 年代記と公開（v0.8）

- `src/story/world-session.ts` の `worldArchitectureChronicle`（読み取り専用）：建て直しごとに「（v8の記録の主語）が建て直される（様式、技術）」の行を作る。
  - 様式：もとの様式で／その時の様式で／もとの造りに、その時の様式を合わせて
  - 技術：大スパンの木造で／石造とアーチで／金属とガラスで
- `src/main.ts`：年代記で、v8の「再利用される／修繕される」の記録のすぐ上（新しい順の表示で、時間ではその直後）に、時代の表記「建築」で表示する。押すとその年の風景に戻る。
- `index.html`：版を v0.8 に上げ、説明文に一文を足した（Human判断）。
  > 廃墟になった建物は、暮らしが戻るとその土地で建て直され、もとの様式で再現されることも、その時の様式や新しい技術で建て直されることもあります。
