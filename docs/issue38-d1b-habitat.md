## 2. 三つの層（D0 §3）

1. **生息候補**：地区の地面（y 96〜179）を16×12pxの格子20×7に分け、各マスに1点。位置は `terrainHash(['fauna-habitat-v1','candidate',seed,site,列,行])` だけで決まり、年・環境・表示に左右されない。候補ごとの閾値も同じく固定のハッシュで決める。その年に使えない候補は、何も表示しないだけ（D0 §4）。
2. **適性（0〜1）**：その年の確定した地形・植物・建物・人口から、種群ごとに求める。候補の周りの複数パッチを集計する（半径：大型草食32px、小型地上12px、小鳥16px、水鳥12px、飛翔鳥48px。1パッチ＝1頭にはしない）。
3. **出現計画**：閾値を超えた候補から、種群ごとの上限・地区の上限・群れの間隔の範囲で、表示する種類・頭数・各個体の位置を決める。上限枠は候補ごとの**固定の優先度**（ハッシュ）の順に配り、その年の余裕（適性−閾値）は群れの頭数にだけ使う（§5）。

### 適性の入力と種群ごとの向き

| 種群 | 必要条件 | 増えるもの | 人の影響 |
|---|---|---|---|
| 大型草食 | 候補が陸 | 草地・低木・若い植生＋樹林×0.3（熱帯雨林では×0.9） | 建物から遠ざかる（24〜48px×(0.5＋人口圧)） |
| 小型地上 | 候補が陸 | 草地＋樹林×0.8（熱帯雨林では×1） | 建物から遠ざかる（8〜20px×…） |
| 小鳥 | 候補が陸 | 草地＋樹林×0.7（熱帯雨林では×0.9）＋裸地×0.3 | 集落の縁（建物から約20px）を好む。建物の直近（4px未満）は嫌う |
| 水鳥 | 6px以内に水 | 周りの水面の割合 | 建物から遠ざかる（12〜30px×…） |
| 飛翔鳥 | 地平線の行の候補だけ | 海面の割合、または草地・裸地＋樹林×0.3（熱帯雨林では×1） | なし |

- 人口圧は log10(1＋人口)/5（人口10万でほぼ1）。**人が増えると全種群が一律に減る規則にはしていない**（D0 §5）。
- バイオームの適合（D0 §6の表）を掛ける。値は `HABITAT_PARAMETERS.biomeFit`。河畔・湿地のパッチでは陸の種群を最低0.8に上げる（D0 §5）。岩場では大型草食を0.6倍にする。
- 熱帯雨林だけ樹林を生息地として数えるのは、Humanレビューの判断4による（§8）。温帯林・亜寒帯林は判断1で量が承認されたので、元の重みのまま。

### 体が収まるか（D0 §8・§9）

各個体は、次の条件をすべて満たすときだけ置く。

- D1aのスプライトの足元の画素がすべて、その年の陸（勾配1以下）か、水面（浮かぶ姿のとき）に乗る。
- 体の外接矩形が、建物・畑・橋などの区画（`sceneOccupiedPlots`。廃墟も含む）から種群ごとの余白以上離れている。
- 左右に2pxずらしても同じ条件を満たす（短い一歩の余地）。

サギは陸に立ち、4px以内に水があること。飛翔鳥はy60より上の空だけ。

置けない個体は、候補の周り（左右10px・上下4px）の固定の6か所まで試し、だめならその個体を出さない。遠くへ移さない（D0 §4）。個体どうしは、種群をまたいでも体が重ならない（1pxの隙間）。大きさはD1aの判断どおり奥行きで縮める（飛翔鳥は既定サイズ）。

## 4. 閾値の決め方（D1bでの校正）

最初の閾値（大型0.55・小型0.5・小鳥0.5・水鳥0.45・飛翔0.55）では、ほぼすべての地区・年で上限の12頭が埋まった。7世界×3地区×5時点の適性の分布を測ると、地区ごとの最大値の中央値は、大型0.39・小型0.80・小鳥0.73・水鳥1.0・飛翔0.67だった。これをもとに閾値を大型0.7・小型0.85・小鳥0.75・水鳥0.8・飛翔0.8（候補ごとに±0.05）、上限を大型2群・他1群（海のある地区の水鳥は2群）・地区10頭に改めた。数値は `HABITAT_PARAMETERS` と report.json にある。

## 5. 閾値付近の点滅：固定閾値と平滑化の比較（D0 §5）

D0は、固定閾値と、その年以前の確定状態だけを使った平滑化・ヒステリシスの比較を求めている。平滑化は「その年を含む直近10年の適性の平均」で試した（画面を見た記憶は使わない）。

**結果（1000〜1200年を1年刻み、21地区の合計。レビュー反映後）**

| 方式 | 切替の回数 | うち10年以内に元へ戻る点滅 |
|---|---|---|
| 固定閾値＋固定の優先度 | 96 | 3 |
| 平滑化（10年平均） | 120 | 17 |

（反映前は固定59／点滅2、平滑化77／点滅13。熱帯雨林・砂漠で動物が増えた分、切替の総数も増えた。）

- **事実**：固定閾値で起きた切替は、ほとんどが確定した出来事の結果だった。新しい建物の区画ができる（例：ステップ川辺の候補で適性0.9→0.156）、人口が増える、上限枠を持つ群れが消えて次の候補に交代する、など。
- **事実**：平滑化は変化を数年遅らせるだけで、遅れの間に上限枠の交代が重なり、かえって点滅が増えた。
- 最初の版は上限枠を「余裕（適性−閾値）の大きい順」に配っていた。そのため余裕の近い候補が毎年入れ替わり、ステップの川辺だけで200年に26回切り替わった。順位を候補ごとの**固定の優先度**に改めた。
- ヒステリシス（前年に表示していたかで閾値を変える）は、その年の表示を決めるのに年0からの全履歴をたどる必要がある。10000年の観測で毎回たどるのは重いため、試していない（未検証）。
- **Human判断（§8）：固定閾値＋固定の優先度で進める。**

## 6. 範囲外・未検証

- 本編の画面（Canvas）での描画、植物・建物との前後の遮蔽、季節（#36）、鏡像の地区、短い動作の経路、性能（毎フレーム）はD1c。地図は記録座標で、鏡像を適用していない。
- 建物の区画は地面の矩形で、屋根の高さを持たない。そのため飛翔鳥はy60より上に限った（屋根との見た目の重なりはD1cで画素で確かめる）。
- #37の植生回帰（廃墟の敷地に戻った植物）は、植物のパッチの段階を通して効く。廃墟の区画そのものは `sceneOccupiedPlots` に含まれるので、動物は立ち入らない。廃墟の内側に動物を置くかは未決（D0 §9：体を置ける地表を別に証明できるまで禁止）。
- 熱帯雨林の樹上の動物（サルなど）は、枝への止まりが初版の対象外（D0 §2）なので作っていない。
- 1,000/5,000/10,000年・保存往復・一括と分割の進行の総合監査はD3。D1bでは3000年まで、1000年で分割した世界との一致を確かめた。

## 7. 1回目のHumanレビューの質問（回答は§8）

1. 量：地区あたり平均0〜8頭、0頭の時点がある地区も多い。この程度の「控えめ」でよいか。
2. 入り江：カモメ・カモがほぼ常に出る。海辺らしさとして許容するか、頻度を下げるか。
3. 人の影響の向きと強さはよいか。
4. 種類の割り当てに違和感はあるか。
5. 点滅の扱い：固定閾値＋固定の優先度（推奨）で進めてよいか。

## 8. Humanレビュー結果（2026-11-19）と対応

| 質問 | Human判断 | 対応 |
|---|---|---|
| 1. 量 | 良い | 温帯林・亜寒帯林などの量は変えていない |
| 2. 入り江 | 良いが、種類が欲しいかも | 海の水上にカモメ（浮かぶ姿）も出し、岸の候補はサギにした。海のある地区は水鳥を2群まで、2群目は1群目と別の種類にした。飛翔鳥は3分の1をカラスにした |
| 3. 人の影響 | 良い | 変更なし |
| 4. 種類の割り当て | 熱帯雨林と砂漠の動物が少なく寂しい。特に熱帯雨林は動物が多いイメージなのに乖離がある | 原因と対応は下記 |
| 5. 点滅 | 良い | 固定閾値＋固定の優先度で確定 |

### 判断4の原因（測定）と対応

- **砂漠**：小型地上のバイオーム適合が0.6で、閾値0.85に届かず、一度も出られなかった（地区ごとの最大は0.6、河畔の補正がある川辺でも0.71〜0.8）。大型草食も適合0.15だった。→ 適合を大型0.6・小型1・小鳥0.8・飛翔0.8に上げ、砂漠の種類としてガゼル類・トカゲ類を加えた。
- **熱帯雨林**：1000年には樹林が地区の75〜91%を占める。式が樹林を草地の0.3倍しか数えなかったため、森が育つほど大型草食（最大0.1）・小型地上（最大0.64〜0.66）・飛翔鳥（最大0.31〜0.36）が出られなくなっていた。→ 熱帯雨林では樹林を生息地として数え（大型×0.9、小型×1、小鳥×0.9、飛翔×1）、適合を大型0.8・小型1・飛翔1に上げた。種類としてイノシシ類・インコ型の飛翔鳥を加えた。
- **副作用への対応**：樹林の重みを最初は森林3バイオームに当てたが、温帯林の川辺が3.1頭→7.7頭に増え、判断1で承認された量を変えてしまった。そのため熱帯雨林だけに限った。
- **結果**：熱帯雨林は平均0.7〜1.9頭→6.3〜8.6頭、砂漠は0〜3.6頭→1.5〜5頭。温帯林・亜寒帯林・ステップ・草原・ツンドラの量はほぼ変わらない（ステップの入り江は8.2→8.7頭、水鳥2群の効果）。
