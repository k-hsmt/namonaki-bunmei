# Issue #39 D4｜2つの確定年の風景を並べて比べる

- Issue: [#39 歴史を発見する観察体験](https://github.com/k-hsmt/namonaki-bunmei/issues/39)
- 設計: D0詳細設計 `docs/issue39-historical-discovery-d0.md`（PR #161）の §8・§10 D4。前工程は[D1](issue39-d1-implementation.md)、[D2](issue39-d2-implementation.md)、[D3](issue39-d3-implementation.md)
- 範囲：調べるモード内の2画面比較。**D0 §10の停止線：本工程はHumanのレイアウトレビューが必要**。

## 1. 体験

- 調べるモードのパネルにある「2つの年の風景を比べる」で開く。開くと、パネル内に2枚の静止風景が並ぶ。
  - 同じ世界・同じ地区で、別々の確定年を描く。
  - PCは左右、スマホ（幅680px以下）は上下。それぞれ16:9を保つ。
- **比較元**は、開いた時点の観測年に固定する（ライブなら最終確定年、過去観測中ならその年）。
- **比較先**の決め方：
  - 初期値は、選んでいる対象の最初の記録年（建設）。比較元と同じ年なら、100年前（0年未満にはしない）。「最盛期」のような年を推測して選ぶことはしない。
  - 「記録のある年」：選んでいる対象の各変化の年と、その前年（前年が0年以上で、それ自体が記録年でない場合）。
  - 年を直接入力、±1年、スライダー。いずれも世界暦0年〜最終確定年に丸める。
  - 対象を選んでいなくても、任意の年で比較できる。
- 各画像の下に「比較元／比較先 · 世界暦N年」と、選んだ対象の**その画像の年での**状態を示す。
  - その年にまだ建っていなければ「この年にはまだ建てられていません」。名前に未来の建設年は入れない。
  - 見えていない年は、D2と同じ文言で示す。
- 「選んだ対象に印をつける」（初期OFF）：各画像の上の別レイヤーに、その年に**見えている画素**だけの輪郭を描く。見えない年・建つ前の年には何も描かない。
- 比較先を変えても、上の風景・観測年・年代記・ステータス・グラフは変わらない。比較先の画像の下にある「この年を観測する」を押したときだけ、#29の`observeYear()`で観測年を移す。移しても比較元は変わらない。
- 地区を変える、調べるのをやめる、別の世界を作る・読み込む、のいずれかで比較は閉じる。

## 2. 比較中の進行（D0 §8.2でD4に委ねられた判断）

- **比較を開くと自動進行を止める**（年移動と同じ扱い）。
- その後に利用者が手で進めても、2枚の年は**固定したまま**で、黙って基準年を更新しない。
- 確定した年の風景は、後の世界でも同じ画素になる（確定史の不変性）。そのため、進行しても2枚を描き直さない。テストでは、手で1回進めた後の比較元が、本番静止画と全画素一致することを確認した。

## 4. テスト

`tests/browser/historical-inspector.test.mjs`に2件を追加（D2〜D4で計10件、すべて成功）。

1. 比較元が観測年（1000年）、比較先の初期値が対象の建設年（800年）になる。年の指定は、記録年の前年（799）・直接入力・±1年・スライダーのそれぞれで効き、範囲外の値（99999、−5）は確定範囲に丸められる。
   - 799、0、1200、1135年の比較先と比較元が、いずれも本番静止画と**全画素一致**する。
   - 比較先を変えても、上の風景の画素・観測年・グラフの要約・年代記の見出しが変わらない。
   - 印は初期OFF。ONにすると比較元にだけ描かれ（799年は建設前なので描かれない）、画像自体の画素は変わらない。
   - 「この年を観測する」で観測年だけが移り、比較元は残る。
2. 開くと自動進行が止まる。PCでは左右に、スマホでは上下に並び、それぞれ16:9で、スマホで横スクロールしない。手で1回進めても2枚の年は変わらず、比較元は本番静止画と一致する。地区の変更・調べるのをやめる・別世界の読み込みで閉じる。

テスト作成中に、年の入力欄がフォーカスを持っている間は表示が更新されず、丸める前の値が残る不具合を見つけて修正した。

全体回帰の結果は §6。

## 5. Humanレイアウトレビューで見てほしい点

1. **画像の大きさ**：PCでは2枚がパネル幅（約700px）に並ぶため、1枚あたりほぼ原寸（約330px）。もっと大きく見たい場合は、比較をパネルの外に広げる案がある。
2. **比較先の初期値**：対象の建設年（同じ年なら100年前）。
3. **「記録のある年」の一覧**：各変化の年と、その前年。住宅街区では数十件になる。
4. **進行の扱い**：比較を開くと自動進行を止め、手で進めても2枚は固定（§2）。
5. **印**：初期OFF。各年で見えている画素だけを囲む。
