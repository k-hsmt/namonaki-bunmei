## 1. 方法

- 世界：各バイオームの調整用seed 10個、計70世界（[D1a §1.1](issue40-d1a-baseline.md)）。5000年まで。選択は本番の自動選択。
- full：1000年ずつ進め、全年の経済を捕捉。exchangeは1000年ごと。全世界で保存サイズを測る。往復（保存→読込→状態比較）は各バイオームの1つ目、計7世界。
- engine：`story/engine`単体。exchangeを毎年読む。fullと文明全体の値を比べる。
- 抽選率の実験（判断2a）：
  - 試験用の写しは、実行時に`dist/story/engine.js`から機械的に作る（`scripts/lib/history40-engine-variant.mjs`）。`src/`には置かず、ゲームは読み込まない。
  - 置き換えるのは年次の抽選確率の式1か所だけ。乱数の消費（毎年`rng.next()`1回）は同じ。式が1か所に見つからなければ生成を止める。
  - **写しに現行の確率を与えると、70世界すべてで本番のengineと状態が完全に一致した**（写しの忠実性）。
  - 比べた4つの設定（仮説を切り分けるための例示の値で、ゲームへの提案ではない）：

| 設定 | 年次の抽選確率 |
|---|---|
| production | 現行：29年まで12%、以後19%（状態によらない） |
| fixed-half | 対照：現行の半分の固定率（件数だけの効果を分ける） |
| hardship-linked | 困難に連動：7%＋40%×困難度（food・cohesionの低さ、干ばつ、疫病の4項目の平均） |
| momentum | 直前の出来事に連動：9%＋30%×exp(−経過年/6)（出来事が続きやすい） |

  - 写しはengine単体なので、土地側（経済・建物）への影響は測っていない。

### 4.1 分かったこと

1. **状態に連動した抽選率は、静かな時代と激変の時代の差を生む。**
   - 分散÷平均は、現行の0.81（一定確率の二項分布の値）から、hardship-linkedで2.06、momentumで1.73に上がった。
   - 出来事のない期間の最長も、35年から60年前後に延びた。
2. **しかし、長期の収束と上限への飽和はほとんど変わらない。**
   - 5000年の人口は、4設定とも約10万〜21万人に収まった。
   - knowledgeとcultureが95以上にある年の割合は、件数を半分にしたfixed-halfで少し下がった（0.89→0.79、0.95→0.90）。状態連動の2設定では現行とほぼ同じだった。
   - 地区の無人化は、どの設定でも起きなかった。
3. 結論：固定の抽選率は「年代記の密度が一定」であることの原因である。一方、「世界間の結果が似る」「指標が上限に張り付く」ことの主な原因ではない。収束は抽選率の外にある。
   - この結論は、例示の4設定・engine単体での比較による。抽選率のあらゆる形を調べたものではない。
