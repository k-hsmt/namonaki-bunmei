## 3. Humanレビューで分かったこと（D5-b）

- 集落・村・町・都市が、どれも「家が点在している村」に見える。
- 原因（事実）：住宅街区は地区ごとに15〜24で増えなくなり、施設の置き場所は11か所。人口6万〜9万の都市も建物の数は村と同じ。施設はほとんどの時間が廃墟（#120）。地面・道・広場・建物以外の物がない。
- 判断：建物の様式だけで描き分けるのは難しい。地面と建物以外の物、人口に応じた建物の数は、#35の範囲外として別Issueにする。
