## 2. 季節の強さ（気候から）

- **寒さ** = 冬の目安（有効気温 − 0.8×年較差）が −10 を下回る度合い（40ポイントで1）。
- **乾季** = 降水の偏り（35から35ポイントで1）×乾き具合。寒い世界では弱める。
- 代表seedの1000年：温帯林（seed 6）寒さ0.74、亜寒帯林（18）・ツンドラ（4）・ステップ（11）寒さ1、草原（23）乾季0.77、砂漠（3）乾季0.8、熱帯雨林（1）乾季0.11。

## 3. 位相ごとの見え方（要点）

| 植物 | 芽吹き（0） | 繁茂（1） | 衰退・紅葉（2） | 休眠（3） |
|---|---|---|---|---|
| 落葉広葉樹・河畔樹 | 明るい若葉、寒い地域ほど葉が少ない | 深い緑 | 紅葉（木ごとに黄・橙・赤） | 寒さ0.8以上で落葉して枝を見せる |
| 常緑広葉樹・熱帯高木 | わずかに若葉 | 深い緑 | 乾季に少し黄ばむ | 寒さ・乾季で少しくすむ。紅葉しない |
| 針葉樹 | わずかに若葉 | 深い緑 | 変化なし | 寒さでくすむ |
| 疎林木 | 若葉 | 深い緑 | 乾季に乾いた色 | 乾季・寒さで葉が減り、乾いた色 |
| 低木 | 若葉 | 深い緑 | 紅葉 | 寒さ・乾季で葉が減り、錆色 |
| 寒冷地の低木 | 若葉 | 深い緑 | 錆色 | くすむ |
| 草本・湿地 | 若草 | 深い緑 | 黄ばむ | 乾草 |
| 林床・苔 | 若葉 | 深い緑 | 黄ばむ・錆色 | 寒さで減り錆色・くすむ |

植物の位置・本数・成長段階・根元・大きさは変えない。地表は、草地のバイオームで繁茂期に少し緑、休眠期に乾草色を重ねる（最大20%）。画面全体の色フィルタは使わない。

## 4. Humanレビューで見てほしいこと

1. 季節の違いが分かるか、風景の静けさを損なっていないか。
2. バイオームごとに自然か（温帯林の紅葉・落葉、草原の乾季、熱帯雨林はほぼ変わらない、など）。
3. 落葉した木の枝の形。
4. 季節差が弱すぎる・強すぎるバイオーム。

## 5. D1b：雪

| 対象 | 描き方 |
|---|---|
| 量 | 雪の量（0〜1）は位相と寒さから決める。休眠期は寒さ0.3から0.8で0→1。芽吹き期は寒さ0.8以上で最大0.45（残雪）、衰退期は寒さ0.9以上で最大0.2（初雪）。繁茂期は0。代表seed：温帯林の休眠期0.88、亜寒帯林・ツンドラ・ステップ1 |
| 地表 | 安定した陸地に、なめらかなノイズ（14×7pxのかたまり）で積もらせる。薄い雪はかたまりで残り、斜面では少なめ。水・崖・砂州と、建物の敷地・広場・橋には描かない |
| 植物 | 季節に合わせた絵の**上向きの縁**（針葉樹の各段、落葉した枝の上側、葉の上）にだけ置く。幹の根元より下には置かない。揺れにも一緒に付いていく |
| 屋根・建物 | 建物を1つずつ本編の関数で描き、**その形の上端**（自分の画素の真上が自分でない画素）に雪を置く。深い雪では1段下まで。色や矩形からの推測はしない。廃屋は崩れた形のまま上端に載るだけで、屋根は再生しない。手前の植物は雪の載った建物も隠す |
| 畑 | 地表と同じ積もり方（9割） |
| 遠景の山 | 既存の雪線（#34）のまま。季節の雪を重ねない |

D0 §5は「屋根の形状は描画器の責務を拡張して提供する」案だった。D1bでは、建物を単独で描いた実際の画素の形を使っている（形の推測ではなく、描かれた形そのもの）。この方式でよいかをレビューで確認したい。

### D1bで見てほしいこと

1. 雪の量（休眠期の一面の雪、芽吹き期の残雪、衰退期の初雪）。
2. 屋根の雪（1〜2pxの線）の見え方。もっと厚い方がよいか。
3. 家の敷地（建物の前の地面）に雪を描かず、土のまま見える点。
4. 木の雪（針葉樹の段、枝の上の雪）。
