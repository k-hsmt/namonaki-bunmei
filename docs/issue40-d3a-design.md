## 1. 正本と役割

| 事実 | 正本 | 食料系統が読むもの |
|---|---|---|
| 地区の充足率・不足の継続年数・不足の記録 | 地域経済（`s.economy.districts`） | 確定した年の値と記録 |
| 地区間の移住 | 地域経済の移動の記録（不足の記録を`relatedIds`に持つ） | 記録 |
| 交易路の共同維持 | 地域経済のルート（`agreementRecord`） | 記録 |
| 共同備蓄の慣習 | 集落台帳の慣習（`practices`、成立の記録） | 記録 |
| 飢饉 | 年代記（`kind:'famine'`） | 記録 |
| 選択 | `decisions`と年代記の選択の記録（D2bの出典つき） | 記録 |

- エピソードはこれらを複製しない。また効果を持たない（D0 §3「効果の適用者を1つにする」）。
  - 備蓄の上限・交易路の容量・移住は、既存の年次処理だけが決める。
  - エピソードは「何が起き、どう対応し、どうなったか」を、確定した事実から型付きの履歴にまとめる。
- 経験・エピソードが将来の行動の重みに影響する経路（D0 §5の`episode_i`）は、D3aでは加えない。系統間の相互作用（D3e）と、経験・制度の調整（D4c）で扱う。
- food指標の値だけでは、エピソードを始めない。食料の物量・地域の充足率と、指標を混同しない（D0 §6）。

## 2. 経過の規則（`src/story/episode-food-d3a-review.ts`）

| 遷移 | 条件（その年に確定した事実） | 根拠 |
|---|---|---|
| started | 地区の不足が記録された（不足が3年続くと記録される）、または飢饉が起きた | その記録 |
| reassessed：shortage-spread／famine | 活動中に、別の地区の不足が記録された、または飢饉が起きた | その記録 |
| reassessed：supply-recovering | 関わる地区すべてで、直近5年の充足率が0.90以上 | 経済の台帳 |
| reassessed：supply-relapsed | 回復中に、関わる地区の充足率が0.90未満に戻った | 経済の台帳 |
| resolved：supply-stable | 回復に入ってから20年、戻りなし（計25年の充足） | 経済の台帳 |
| response-started／response-changed | 前回の対応の変化より後に、対応の記録がある（下表） | その記録 |
| response-failed：shortage-persisted | 対応が15年続き、関わる地区がなお15年連続で不足 | 対応の記録と経済の台帳 |
| abandoned：no-response-after-failure | 失敗の後、別の対応がないまま50年、なお不足 | 経済の台帳 |

- 関わる地区：記録された不足の地区。飢饉だけで始まった場合はすべての地区。
- 1年に1遷移。優先順は、広がり→戻り→回復→終結→対応→失敗→断念。
- 対応の記録が他の遷移と同じ年に重なっても、記録の年で窓を区切っているため、翌年以降に拾われる。
- 回復の5年と終結の20年は、閾値を往復するだけの終結・再発を避けるためのヒステリシス（D0 §4.2）。
  - 経済が保持する充足率は5年分。その先の継続は、回復・戻りの遷移として履歴に残す。年ごとのカウンターは持たない（D2cの規則）。
- 断念は、対応の終了理由であり、不足が解消したことを意味しない（D0 §4.1）。
  - 同じ不足の記録は、同じ系統で二度起点にできない。そのため断念の後は、不足がいったん収まって新たに記録されるまで、新しいエピソードは始まらない。
- 無対処も成立する。対応のないまま続く・収まるエピソードがある。

### 2.1 対応の種類

| 対応 | 記録 | 意味 |
|---|---|---|
| decision:<actionId> | D2bの「食糧の蓄えが乏しい」の選択の記録。その出典に、このエピソードの不足の記録を含む | 意図（選択）。効果は現行の選択の効果のまま |
| relocation | 経済の移住の記録。このエピソードの不足の記録を引いている | 実際に人が移った |
| communal-storage | 関わる地区で、共同備蓄の慣習が根づいた記録 | 実際の変化（備蓄の上限が上がる）。動機は主張しない |
| trade-supplement | 関わる地区に接する交易路で、共同維持が始まった記録 | 実際の変化（ルートの容量が2倍）。動機は主張しない |

- 同じ年に複数ある場合の優先順：選択→移住→備蓄→交易。
- 対応中に、同じ種類の記録が出ても対応を始め直さない。別の種類なら方針変更。失敗の後は、同じ種類でも新しい記録なら再試行。
- 「生活規模の縮小」（D0の候補）は、住宅の空き家の記録と不足を結ぶ根拠がない。そのため、移住（不足の記録を引く）だけを対応とした。空き家は、人口・集落の発展と衰退（D4b）で扱う。

## 4. 独立の照合（`scripts/lib/history40-food.mjs`）

定義とは別に書いた照合で、すべての遷移の主張を出典に照らす。照合に使うのは、年代記・選択・毎年捕捉した経済（その年の充足率と不足の継続年数）。

- 開始・広がり：その年の不足の記録・飢饉であること。
- 回復：関わる地区の5年間の充足率。
- 戻り：回復中であることと、その年の充足率。
- 終結：回復の開始から20年以上たっていて、その間（回復の5年前から）すべての年で0.90以上。
- 対応：記録が前回の対応より新しく、種類が合っている。
  - 選択なら、その年の`scarce-stores`で、出典がこのエピソードの不足。
  - 移住なら、このエピソードの不足を引いている。
  - 備蓄・交易なら、関わる地区。
- 失敗：対応から15年以上たち、その年に15年以上不足している地区がある。
- 断念：失敗から50年以上たち、その間に対応がなく、その年に不足がある。

### 6.3 所見（事実と評価を分ける）

- 事実：食料エピソードは、5000年のうち約8割の年で活動している。最長は中央値で1000年、最大2405年。戻り（relapse）は世界あたり中央値31回。
  - 原因：活動中の不足は、関わる地区の5年の充足と20年の継続でしか終結しない。対応がなければ失敗・断念にも至らない。そのため、充足率0.90の前後を往復する地区があると、エピソードは回復と戻りを繰り返して長く続く。
  - 評価（推測）：規則どおりで、出典とも合う。ただし、1000年続く1つの「食糧不足」は、物語の単位としては長すぎる可能性がある。現状では、系統の効果がないので、世界には影響しない。
  - 扱い：D3aでは閾値を変えない。D3b〜dの系統が揃った後、D3eの系統間の比較（同じseed）で、他の系統の長さと合わせて判断する。期間の上限や、長期化の区切り（例：時代ごとの再評価）は、そこで検討する。
- 事実：対応の約半分は移住。経済が不足地区から人を移す頻度が高いためで、選択（D2bの分岐）は約3割。
- 事実：飢饉が起点になるのは1.7%。大半の飢饉は、すでに活動中のエピソードの中で起きている（reassessed:famine、世界あたり中央値3）。
