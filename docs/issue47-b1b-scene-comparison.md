## 1. 検証するもの

**7つの主要バイオーム（強制比較用）×川辺・丘陵・入り江の3地区（現行ゲームの保存地形）×A/B/Cの3描画方式＝63枚の原寸320×180px画像**、加えて各地区の変更前の基準画像を3枚。

- **A 表現力重視**：PR #126 の元の13系統植物の描画形状を忠実に抽出し、実景観での大きさへ縮小する。
- **B 多様性重視**：PR #127 の植物生成コードを使用し、年齢・形状・6個体差を使用する。
- **C 統合**：近景の高木はA、その他の中遠景と下層植生はBとする。
- **同一地区・仮バイオームで、A/B/Cの植物の位置・種類・本数・若齢／成熟の指定は同じ**。違うのは描画形態と寸法・個体差。
- すべての地形・川や海・建物・橋・住宅街区・公共空地は、現在のゲームコードで生成・進行・観測した保存状態を使用する。

**重要**：バイオームの種類・植物構成・背景の試験色はB1bだけの仮入力である。今のゲームに砂漠や熱帯雨林の気候モデルが既に実装されたという意味ではなく、世界の歴史・気候・植生状態を変更・保存しない。

## 2. 本編との接続

- 現行の createNewArchitectureWorld で世界を生成し、advanceArchitectureWorld の通常automatic進行後、observeTerrainProductionScene で同一seed・同一年を観測。
- drawGeneratedSceneReview を使い、元のゲーム景観を基準画像として保存し、背景レイヤーと確定建築物を別々に描く。比較画像の重ね順は §4.1 を参照（建物の上に植物）。
- 植栽候補は実地形の **surface / grade / bearing** と確定した建築のfootprintを参照。水面・急斜面・建物の足元を避ける。
- **物理コード2＝淡水、3＝海水**を厳密に区別。海岸を淡水豊富な河畔植生として誤解しない。
- 植物の配置は専用固定ハッシュ。文明乱数・時刻・既存植生履歴を変更しない。
- 背景色は確認済み陸地セルにのみ混合する。実地形の生成・海水面・川・建物は変更しない。

## 4. 描画上の仮パラメータ

A原画はBより大きいため、Aの画像表示倍率は奥行きに応じ **0.45〜0.73**、Bは **0.58〜1.00** を採用。これらは見た目の比較のための調整値であり、生態学的な木の高さ・年齢・成長速度ではない。

Cは高木のうち、根元が画面y≥142の近景でA、その他はBを使う。

### 4.1 重ね順（遮蔽の比較実験）

| | 変更前 | 現在 |
|---|---|---|
| 1 | 背景・地形（地形・地表・水路・公共空地・橋） | 背景・地形（同左） |
| 2 | バイオームの地表色（陸地セルのみ） | バイオームの地表色（同左） |
| 3 | 植物（下層→高木、根元yの順） | **確定建築物**（住宅の屋根・施設・畑・市場など） |
| 4 | 確定建築物（最前面） | **植物**（下層→高木、根元yの順） |

- 建築物レイヤーは `drawGeneratedSceneReview(…,'structures')` が透明に初期化したキャンバスで、背景を含まない。先に重ねても背景は二重に描かれない。
- 重ね順の変更（コミット `6f02a50`）では、植物の根元・種類・本数・若齢／成熟・倍率を変えていない（以前の順序で再合成した画像が変更前の画像とSHA-256で一致することを確認）。本編の基準画像 `actual_*.png` も変更前と同一。その後の §4.3 の修正で、画面上の植物の位置は鏡像に合わせて変わった。
- **すべての植物がすべての建物の上に描かれる。奥行きによる前後判定ではない。** 建物より奥に根元がある木も、手前の建物を覆う。厳密な奥行き制御は今後の検討事項で、今回は実装しない。
- 建物が隠れすぎる場合も、植物の縮小・間引きで自動的に解決しない。遮蔽量を数値と遮蔽図で示し、Humanが判断する。

### 4.2 画素レベルの検証（生成時に毎回実行）

63枚のすべてで、植物の不透明画素は最終画像で植物の色に、それ以外の画素は「背景＋地表色＋建物」と完全に一致することを確かめる。満たさなければ生成を失敗させる。建物の画素が1つもない画面も失敗とする。各画面について、建物の画素数、植物に覆われた画素数（高木・下層の内訳）を `report.json` の `frames[].occlusion` に記録し、ギャラリーの各画像の下に表示する。

さらに各地区で、実在の建物の手前4pxにC方式の落葉広葉樹を1本置いた検証画面を作り、木が建物を覆うことを画素で確かめる（入り江は手前に建物がないため、C方式ではB造形の木になる）。

### 4.3 鏡像の地区の座標（修正済み）

seed 88・観測年300の3地区は、いずれも地形の `render.mirrorX` が true で、`drawGeneratedSceneReview` は背景と建築物を左右反転して描く。当初の比較画像は、植栽計画（`planReviewPlants`）と地表色（`tint`）を反転前の記録座標のまま、反転していない画面へ描いていた。そのため画面上では、植物の根元1110本のうち237本が陸地以外（主に水面）、24本が建物の敷地内に来ていた。地表色は3地区合計21,542画素で陸地と水面を取り違えていた。

修正後の扱い：

- 植栽計画・占有域・地形物理は**記録座標のまま**（植物の種類・本数・記録上の根元は変えない）。
- 描画時に画面座標へ写す。記録の列 x は画面の列 `319−x`、幅2pxの根元 x..x+1 は画面の `318−x..319−x`。地表色は画面の各画素で、写し先の記録の列の陸地／水面を参照する。
- 植物の画像自体は左右反転しない（B1aの造形のまま）。
- 写像式は、生成時に地区ごとに全320列でキャンバスの実際の反転変換と照合する。すべての根元が画面上で陸地に載ることも生成時に検証する。

**修正後の遮蔽量**：63枚のうちC統合版の最大は3.7%（熱帯雨林×川辺）で、すべて下層植生による。植栽計画が建物の左右18px・手前25px以内に高木を置かないため、高木が建物を覆う画面は63枚の中にはない。修正前の川辺の54〜58%は、鏡像のずれで敷地に入り込んだ木によるものだった。大木が建物を隠す見え方は「確実に重なる検証画面」で確認できる。

## 6. Humanに見てほしいこと

1. 原寸で、植物の**形態そのもの**から温帯林・熱帯雨林・草原・砂漠・ツンドラなどが読み取れるか。
2. Aの大木の存在感は、集落や建築を邪魔するほど大きすぎないか。
3. Bの個体差は、画面内で反復の不自然さを減らしているか。
4. Cの「近景A、中遠景B」は画風の不一致や不自然な境界が生じていないか。
5. 川辺・丘陵・入り江それぞれで、地形と植物の関係や余白が自然か。
6. 建物・橋・道路の読みやすさと植物の存在感が両立するか。
7. 植物が建物を隠す見え方は自然か。樹冠が建物を隠しすぎないか（確実に重なる検証画面、各画像の遮蔽率）。
8. 温帯林・熱帯雨林・亜寒帯林など木の多いバイオームでも、文明を観察できるか。
9. 建物の上に描いてもCの大木の表現力が保たれるか。
10. 現在の植栽計画では高木が建物の近くに来ないため、遮蔽はほとんど起きない。近景の大木と建物の重なりを実景観でも見たいか（植栽計画の除外範囲を変える場合は別作業）。
