## 1. 検証するもの

**7つの主要バイオーム（強制比較用）×川辺・丘陵・入り江の3地区（現行ゲームの保存地形）×A/B/Cの3描画方式＝63枚の原寸320×180px画像**、加えて各地区の変更前の基準画像を3枚。

- **A 表現力重視**：PR #126 の元の13系統植物の描画形状を忠実に抽出し、実景観での大きさへ縮小する。
- **B 多様性重視**：PR #127 の植物生成コードを使用し、年齢・形状・6個体差を使用する。
- **C 統合**：近景の高木はA、その他の中遠景と下層植生はBとする。
- **同一地区・仮バイオームで、A/B/Cの植物の位置・種類・本数・若齢／成熟の指定は同じ**。違うのは描画形態と寸法・個体差。
- すべての地形・川や海・建物・橋・住宅街区・公共空地は、現在のゲームコードで生成・進行・観測した保存状態を使用する。

**重要**：バイオームの種類・植物構成・背景の試験色はB1bだけの仮入力である。今のゲームに砂漠や熱帯雨林の気候モデルが既に実装されたという意味ではなく、世界の歴史・気候・植生状態を変更・保存しない。

## 2. 本編との接続

- 現行の createNewArchitectureWorld で世界を生成し、advanceArchitectureWorld の通常automatic進行後、observeTerrainProductionScene で同一seed・同一年を観測。
- drawGeneratedSceneReview を使い、元のゲーム景観を基準画像として保存し、背景レイヤーと確定建築物を別々に描く。確認済み建築物の間へ仮植物を重ね、建築を最前面で復元する。
- 植栽候補は実地形の **surface / grade / bearing** と確定した建築のfootprintを参照。水面・急斜面・建物の足元を避ける。
- **物理コード2＝淡水、3＝海水**を厳密に区別。海岸を淡水豊富な河畔植生として誤解しない。
- 植物の配置は専用固定ハッシュ。文明乱数・時刻・既存植生履歴を変更しない。
- 背景色は確認済み陸地セルにのみ混合する。実地形の生成・海水面・川・建物は変更しない。

~~~sh

node scripts/preview-biome-scenes.mjs
~~~

## 4. 描画上の仮パラメータ

A原画はBより大きいため、Aの画像表示倍率は奥行きに応じ **0.45〜0.73**、Bは **0.58〜1.00** を採用。これらは見た目の比較のための調整値であり、生態学的な木の高さ・年齢・成長速度ではない。

Cは高木のうち、根元が画面y≥142の近景でA、その他はBを使う。建物は植物の上から描き直すため、屋根の可読性を確認できる。ただし**前景植物と後景建物の厳密な遮蔽順序は未解決**であり、今後の採用候補として比較する。
