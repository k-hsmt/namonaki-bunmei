# Issue 34：環境変化を景観として読み取りやすくする

PR #70統合後の「違いが分かりにくい」「もう少し作り込みたい」というフィードバックに対応する。気候・土壌・植生成長・土地利用のモデル、文明のRNG・人口・食料、建物と敷地は維持し、表示を改善する。

## 描き分け

- 地表は細かい色点の散在から、局所水分に沿った広い色面へ。記録された隣接パッチの値を表示用に補間し、低周波の濃淡を重ねる。未知の区画から気候を補完せず、水面・不安定地盤は塗り替えない。モデルのパッチや計算値は変更しない。
- 乾燥地は土色がまとまり、水辺に緩衝がある土地との違いを出す。湿潤時は地面と樹冠を深い緑、寒冷時は灰緑色へ寄せる。これは実測の気候帯・土質を新しく認定したものではない。
- 草は小さな束、低木は背の低い茂み、若木は小さな樹冠、成熟木は大きな樹冠にする。実際の段階から選び、裸地に未成立の森林を描かない。若木の表示候補は成熟後も候補として残る。
- 空間的に連続した座標ノイズを使い、木や下草をまとまりと余白へ分ける。根元は安定した陸地・斜面条件と最新の占有を検証し、建物の外形からも余白を取る。表示サンプル上限は木24・低木36で、個体の実数ではない。
- 表示の水分・寒暖は8単位に区切り、描画キャッシュにも同じ区分を使う。モデルの数値やラベルの変化だけで同じ画素を再準備しない。静止画と動画は同じ投影・樹冠を使う。

## 保存と既存世界

新しい表示はrenderer `generated-scene-v4`、内部の景観指定は`landscape-v2`。環境schema 1・植生schema 2と組にし、新規世界の既定とする。保存する気候・植生・土地利用の記録はv3と同一で、違いはrendererの指定のみ。

既存renderer v1／v2／v3の保存は読み込み・通常進行・明示保存でも元の表示を維持する。v3の環境世界には「環境の景観を詳しくする」を表示し、選択したときだけv4へ切り替える。選択中の観測年・地点を保ち、再生成・時間進行を行わない。保存操作までは元のブラウザ保存を変更しない。環境記録がない旧世界・固定世界に環境を補完する機能にはしない。

## 比較と検証

- main `4a3faa9` のv3描画から、seed 42・年0／300／1000・3地区のRGBA基準9件を実装変更前に記録。旧保存の画素一致を継続検証する。
- 表示更新前後の完全な保存をrenderer指定以外で比較し、将来進行の文明state・環境・植生・敷地が一致することを確認する。
- 根元の各セルを元の地形と占有に直接照合し、描画された草木が実際の成長段階に属することを確認する。
- ブラウザで過去観測中の切替、未保存時の旧キー保持、保存・再読込、同じ描画キーでの画素一致、水面の非改変を確認する。
- `review-landscape-detail.mjs` は同一世界・同一観測年のv3／v4を15組比較する。境界スライダーで差を確認でき、原寸／4倍画像と元の気候傾向を添える。比較一式はCIの `environment34-landscape-detail`。
- 既存の1万年監査、進行性能、30条件の観測・準備・フレーム計測も新規世界のv4で継続する。フレームp95は12fpsの83.3ms以内。

#34の灌漑・恒久地形改変・社会計算への接続は別段階。この変更で本Issue全体をクローズしない。

景観比較後の「環境の違いをさらに強めたい」を受け、乾燥の色変化を非線形にする。水辺の中程度の乾燥では緑を残し、内陸の強い乾燥では土色を強める。湿潤の深緑、寒冷の灰緑、乾燥時の樹冠・下草の色差も強める。気候・成長速度・記録・表示区分は変更しない。
