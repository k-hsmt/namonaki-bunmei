## 3. 13系統の造形

| 系統 | 造形で区別している要素 | 若齢／疎の扱い |
|---|---|---|
| 1. 落葉広葉樹 | 3つの塊からなる丸く不均一な樹冠、Y字の枝 | 疎：枝の通り道に沿って樹冠を欠き、透けた枝を見せる |
| 2. 常緑広葉樹 | 低い太幹、横に広く厚いドーム | 疎：輪郭の縁を欠く（内部に穴は開けない） |
| 3. 針葉樹 | 段ごとに狭まる枝の層と暗い下面、尖った先端 | 若齢：3段、成熟：5段。疎：段の間に幹が見える |
| 4. 熱帯高木 | 細く高い幹と板根、平たく不規則な傘状樹冠、下層の葉群、垂れるつる | 若齢・疎は下層なし。疎：樹冠を切れ込みで塊に分ける |
| 5. 乾燥地の疎林木 | 二股に開く幹、薄く平らな横長の樹冠 | 疎：樹冠が3枚の葉群に分かれる |
| 6. 河畔樹木 | 傾いた幹、垂れ下がる枝の幕 | 疎：幕の間隔が広い |
| 7. 乾燥地の低木 | V字に開く硬い小枝、先端だけの葉 | 疎：小枝3本 |
| 8. 寒冷地の低木 | 2〜3pxの低いマット、赤みの点 | 疎：2つの小さなマット |
| 9. 一般低木 | 丸い茂みと小さな空隙 | 疎：2つの小さな茂み |
| 10. 草本 | 葉の束。短草・長草・乾草（倒れた穂先）の3形 | 若齢＝短草、成熟＝長草。疎：株の間隔が空く |

個体差：個体0を基準形とし、他は大きさを0.88〜1.12倍の範囲で変え、樹冠の偏り・枝や葉の長さを個体番号からの固定ハッシュで変える。乱数・時刻は使わない。

## 5. Claudeの所見（下書き。採否はHumanが原寸で判断する）

以下は4〜5倍に拡大した画像と上記の指標から書いた**推測を含む下書き**。原寸320×180での視認性は、拡大画像越しにしか確認していない。

**輪郭で読めそうなもの**
- 高木6系統（落葉・常緑・針葉・熱帯・乾燥疎林・河畔）は単色でも形で区別できる。特に針葉樹（縦の段）、乾燥地の疎林木（平らな樹冠と二股）、河畔樹木（垂れる幕）、熱帯高木（高い幹と傘）は遠景でも別物に見える。
- 湿地植物（直立茎と穂）と長草は、手前では区別できる。

**弱い・統合候補と考えるもの**
- **寒冷地の低木↔苔・地衣類**：手前9px・遠景4pxで最も近い組。どちらも高さ2〜3pxで、地面色の上ではほぼ同じに見える。設計書の「寒冷地の個性」を担うには、地表材（寒冷地表・岩）との組み合わせに頼る必要がある。統合、または苔を地表材側へ移す案が考えられる。
- **低木・草本・湿地植物の遠景**：k=0.5では7px前後まで縮み、点の集まりになる。遠景では低い植物を描き分けず、地表の色斑として扱う方が静かな画面に合う可能性がある。
- **落葉広葉樹↔常緑広葉樹**：輪郭は異なる（縦長の不均一な丸 vs 横長の低いドーム）が、手前でも差の主因は高さと幅。落葉の「枝の透け」は疎のときにしか見えない。
- **疎と密の差が小さい系統**：落葉（12px）・常緑（11px）・林床（9px）。密度差を年次状態（被覆）として使う場合、原寸で読めない恐れがある。
- **個体差**：大きさと細部のずれにとどまり、個体ごとの形の違いは弱い。針葉樹は6個体中3輪郭しかない。並べたときに「同じ木の複製」に見えるかはB1bの実景観で確認が必要。
- **熱帯高木の下層の葉群**は幹に短い枝で付けたが、四角い板に見える。描き直し候補。

**その他**
- 草本の短草・寒冷地の低木・苔は、地面色（`#9a9a70`）の上でかなり埋もれる。本編の地面色を前提にするならこれが実際の見え方だが、バイオーム側の地表材で背景を変えると印象が変わる。
- 地表材の岩は横方向の筋で表したが、平坦な見本でしか見ていない。斜面・岩場パッチ上の見え方は未確認。
