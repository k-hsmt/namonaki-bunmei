## 2. 生成方法

### 2.1 乱数源

- 世界seedだけから決める。ハッシュはゲームの `terrainHash`（`src/terrain/terrain-hash-v1.ts`、長さ前置きFNV-1a）と同じアルゴリズムを試作内に写し、名前空間 `initial-climate-v1` を使う。同じ入力でゲームの `terrainHash` と一致することをテストで確認している（B2で本編の関数に置き換えても値が変わらない）。
- 文明RNG・`Math.random`・時刻は使わない。
- **引き直し・出現数の割り当て（クォータ）・却下はしない。** どのseedも与えられた気候のまま。

### 2.2 4軸（設計書§4.1の値域。現実の℃・mmではないゲーム内指標）

各軸の元になる値は、一様乱数4個の和を標準正規分布に近づけたもの（`zT, zM, zR, zC`）。

| 軸 | 式 | 意図 |
|---|---|---|
| 気温 `temperatureIndex` −100..100 | `48·zT` | |
| 水分供給 `moistureSupplyIndex` −100..100 | `50·zM + 0.12·気温` | 暖かいほどわずかに湿る |
| 年間寒暖差 `annualTemperatureRangeIndex` 0..100 | `45 + 14·zR − 0.18·水分 − 0.12·気温` | 乾燥・寒冷ほど大陸的で寒暖差が大きい |
| 降水の季節集中 `rainfallConcentrationIndex` 0..100 | `40 + 15·zC + 0.20·気温 − 0.10·水分` | 暖かく中程度に湿った気候ほど雨季・乾季がはっきりする |

植物に使う有効値：

- **有効気温** ＝ 気温 − 0.30·max(0, 寒暖差−50)（厳しい冬が生育期間を縮める）
- **有効水分** ＝ 水分供給 − 0.30·max(0, 気温) − 0.30·max(0, 季節集中−50)（暑さによる蒸発と長い乾季）

母集団（100,000 seed）での軸の相関：気温〜寒暖差 −0.37、水分〜寒暖差 −0.53、気温〜季節集中 +0.49、水分〜季節集中 −0.21、気温〜水分 +0.11。独立な一様乱数ではない。

### 2.3 7主要バイオームへの分類

有効気温 `T`・有効水分 `M` と固定の閾値で決める。

1. `T < −62` → ツンドラ
2. `M < −65` → 砂漠
3. `M < −36` → ステップ
4. `T < −25` → 亜寒帯林
5. `T ≥ 17`（暑い）→ `M ≥ 2` なら熱帯雨林、それ以外は草原（サバンナ）
6. `M < −13` → 草原
7. それ以外 → 温帯林

- 閾値は `scripts/calibrate-climate-b1c.mjs` が**校正用seed集合**（専用の名前空間で選んだ50,000 seed）に一度だけ当てはめ、コードに固定した。監査のseed集合とは重ならない（監査で検査）。再実行すると同じ閾値が出る（固定点）。
- 当てはめでは目標比率との二乗誤差を最小化し、砂漠・ツンドラの誤差を4倍に重み付けした。
- 実装中の修正：最初の分類では、暑く中程度に湿った世界（`T ≥ 17` かつ `−13 ≤ M < 2`）が温帯林になっていた。暑い世界は草原（サバンナ）から熱帯雨林へ直接移るように直し、閾値を当てはめ直した。
- **移行帯**：有効値を4ポイント以内動かすと別のバイオームになる世界には、隣のバイオームと距離を `transition` として持たせる（植物群が混ざる移行帯をB2で表現するため）。母集団の21.5%が該当。
  - 当初は8ポイント（母集団の41.6%）だったが、Humanレビューで「4割は少し多い」とされ、4ポイントに狭めた。参考：3ポイントで16.3%、5ポイントで26.7%。

## 3. 監査結果

```sh
node scripts/audit-climate-distribution.mjs   # → artifacts/biome47-b1c/report.json, points.json
```

| 集合 | 砂漠 | ステップ | 草原 | 温帯林 | 熱帯雨林 | 亜寒帯林 | ツンドラ |
|---|---|---|---|---|---|---|---|
| 目標 | 11% | 14% | 15% | 19% | 15% | 15% | 11% |
| seed 1〜1000（連番） | 12.1% | 14.0% | 14.7% | 17.8% | 16.2% | 15.5% | 9.7% |
| ランダム1000（集合A） | 10.8% | 15.9% | 13.9% | 18.8% | 16.3% | 12.6% | 11.7% |
| ランダム1000（集合B・再検証） | 11.6% | 14.0% | 14.6% | 21.0% | 14.7% | 12.7% | 11.4% |
| ランダム100,000（母比率の推定） | 11.3% | 13.7% | 15.2% | 19.2% | 15.1% | 14.6% | 11.0% |

- **砂漠・ツンドラ（Human目標：各10〜12%程度）**：母比率の推定は砂漠11.3%（95%区間11.1〜11.5%）、ツンドラ11.0%（10.8〜11.2%）。1000 seedの3集合はすべて警戒目安8〜14%の内側（砂漠10.8〜12.1%、ツンドラ9.7〜11.7%）。
- 1000 seedでは標本誤差がおよそ±2ポイントある。集合A・Bの亜寒帯林12.6〜12.7%は目標15%より低いが、母比率の推定は14.6%で、標本のばらつきの範囲と判断した。
- **気候とバイオームの整合（母集団の平均）**：有効気温はツンドラ −83 ＜ 亜寒帯林 −42 ＜ 温帯林 −4 ＜ 熱帯雨林 47、有効水分は砂漠 −87 ＜ ステップ −50 ＜ 草原 −20 ＜ 温帯林 31。監査はこの順序が崩れたら失敗する。
- 監査は、砂漠・ツンドラが1000 seed集合で8〜14%、母集団で10〜12%を外れた場合、整合が崩れた場合、校正用seedと重なった場合に失敗する（終了コード1）。

## 5. 未検証・限界

- 気候と**世界生成の成否**の関係は未検証。現在の世界生成は地形・集落の成立に失敗するseedがあり、気候の追加で失敗が増えないかはB2で確認する（設計書§7）。
- 気候は世界全体で1つ。川辺・丘陵・入り江の局所環境（淡水・斜面・海岸）による差はB2。
- 森林の「密」など、B1bの植栽計画は試験用の強制バイオームで決めたもの。B2で気候から植生をつなぐときに、有効気温・有効水分・移行帯をどう使うか設計する。
- 係数と閾値は見た目と比率を合わせるための調整値で、現実の気候モデルではない。

## 6. Humanレビューの決定（2026-11-12）

1. 出現比率：このままでよい。
2. 暑く中程度に湿った世界は草原（サバンナ）とする。
3. 移行帯は4割では多い → 幅を8から4ポイントに狭めた（約2割）。移行帯で植物群が混ざる表現は採用。
4. B2へ進む。
