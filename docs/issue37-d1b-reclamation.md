## 1. 現状の確認（事実）

- 本編の植物の根元は、8×8pxパッチごとに候補が1つで、**立っている建物の敷地とその周囲4px**（木は森6/8px・開けた土地18/25px）には置かれない（`flora-scene-v1`・`sceneOccupiedPlots`）。住宅街区は**廃墟でも敷地全体が占有**のままなので、今の本編では廃墟の街区に植物は一切生えない。
- 植生の時間はパッチ単位。住宅の建設は敷地に重なるパッチ全体を`clear`する（`vegetation/history-v1.ts`）。住宅の空き家化・廃墟化では何も起きない。`release`は畑の廃墟化と広場の荒廃にだけある。

### 区域が開く・閉じる規則（D0 §3）

| 確定した状態 | 外縁 | 露出した内部 |
|---|---|---|
| 住宅 使用中・低利用・損傷のみ | 閉 | 閉 |
| 住宅 空き家（`vacated`） | **開** | 閉 |
| 住宅 廃墟（`ruined`、必ず空き家） | 開（空き家からの`openedYear`を維持） | **開** |
| 住宅 修繕（空き家のまま） | 開のまま | 閉 |
| 住宅 再利用（使用中） | 閉 | 閉 |
| 再び空き家 | **新しい`openedYear`で開** | 閉 |
| 施設 廃墟（`building-abandoned`） | 開 | 開 |
| 施設 再利用・修繕 | 閉 | 閉 |

区域が閉じた年からその区域の植物は描かれない。過去の年を観測すれば当時の植物が見える（区域の期間から年ごとに導くので、未来の修繕が過去の植物を消すことはない。テストで、ある年より後の変化を削っても、その年の結果が変わらないことを確認）。

### 根元を置けるマスク（D0 §4）

- **外縁**：敷地の外側4px（本編で人が空けていた余白）と、住宅街区の敷地の内側2pxの縁。施設は敷地＝建物なので内側の縁はない。
- **露出した内部**：敷地のうち外縁を除いた部分。
- 次は常に閉じたまま：**構造の平面**（施設は敷地の縁1pxの壁の線、住宅は各家の描画幅の左右＋1px、地面線から奥へ遠景3・中景4・近景5行。下記の仮定）とその周囲1px、水・崖・急斜面、**その年に立っている他の建物の敷地とその周囲4px**。
- 建設上の占有（`housing-ground.ts`・`sceneOccupiedPlots`）は一切変えない。マスクは植物専用の別の細かい図。

**仮定（要確認）**：本編のモデルには家1軒の平面の奥行きがない。D0 §4「不明な場所は保護」に従い、家の平面を広めにとった（遠3／中4／近5行＋手前1行）。この結果、近景の街区では家の列の間が2px幅の帯しか残らず、**露出した内部に根元が立つのは1区画あたり0〜7本**にとどまる。

### 何が育つか（D0 §5）

- 根元の候補は4×4pxの格子ごとに1つ（世界seed・地区・所有者・区域・開いた年のハッシュ）。2×2pxが同じ開いた区域に収まるものだけ。
- 各根元は区域が開いてから0〜19年遅れて育ち始め、**草→低木→若木→成熟木**（flora-growth-v1の年数）を飛ばさずに進む。上限は根元が立つパッチの群落の気候上限（`ceiling`）。木の種類・低木・草はそのパッチの群落（local-flora-v1）から選ぶ。
- **パッチの年齢は読まず、変えない**。本編の植物（既存の植え付け）にも触れず、間隔（下草7px、木と下草10px、木どうし10/18px）だけ守って足す。木は立っている他の建物から本編と同じ余白をとる。
- 下草の数は開いた区域64px²あたり0.5本まで。

## 3. 比較の舞台

合成した320×180の平地（右に川）、温帯林・草原・熱帯雨林の代表seedの群落。建物はD1aの風化で描く。年表はすべて**開発用**。

| 所有者 | 年表 |
|---|---|
| 街区A（近景、住宅12軒） | 空き家110年・廃墟140年・修繕（空き家）320年・再利用335年・再び空き家400年 |
| 街区D（近景、住宅4軒） | ずっと使用中。街区Aと2px隔てて隣接 |
| 街区B（中景、住宅6軒） | 空き家80年・廃墟100年。パッチ境界をまたぐ |
| 仕事場F（施設） | 放棄（廃墟）120年・再利用420年 |
| 街区C（近景、住宅2軒） | 空き家100年・廃墟130年。外側の余白が川に接する |

各バイオームで、本編（今）／A：パッチ全体のrelease／B：局所アクセス（推奨）／Bのマスク、を100・130・170・300・330・350・420・600年で並べた。Aは「空き家化（施設は廃墟化）の年に敷地に重なるパッチへ`release`を足し、その所有者を占有から外す」という、既存の畑・広場と同じやり方の素直な拡張。

## 4. 監査の結果（report.json、3バイオーム×8年）

| 指標 | A：パッチrelease | B：局所アクセス |
|---|---|---|
| 構造（壁・家の平面）の上に立つ根元 | **1〜14本**（毎年発生） | **0** |
| 本編と比べて消える・位置が変わる屋外の木 | 3〜22本（地区全体の植え直しの波及） | **0**（足すだけ） |
| 敷地に重なるパッチで若返る屋外の木 | 0 | 0 |
| 使用中の建物の敷地に立つ根元 | 0 | 0 |
| 足された局所の植物 | － | 8〜33本（外縁8〜30・内部0〜7） |

- **D0 §5が心配した「同じパッチの屋外の成熟木の若返り」は、この舞台では起きなかった（0本）**。本編の木の余白（森6/8px、開けた土地18/25px）が、敷地に重なるパッチの屋外にもともと木を置かないため。ただし建設時の`clear`がそのパッチ全体の年齢を戻している点は本編のままで、余白が変われば起こりうる。
- Aの実害は、根元が壁や家の上に立つことと、占有を外すと植え付けが地区全体で組み替わり、無関係な場所の木が消えたり動いたりすること。さらにAは外縁と内部の時期を区別できず、修繕・再利用で区域を閉じる手段もない（パッチの年齢は戻らない）。
- **評価（未確定）**：D0の推奨どおり**B**が適している。

## 5. 画像を見た所感

- 草原では、廃墟化から160年（300年）で街区Aの上にアカシアが数本育ち、修繕（320年）の後も330年には外縁の木が残り、再利用（335年）で消え、再び空き家（420年）では草から始まる、という流れが読める。
- 温帯林・熱帯雨林では周囲の森が密で、遺構も局所の植物も周りの木に紛れやすい（D0 §8が許す自然な遮蔽）。差は拡大して見る必要がある。
- 露出した内部はマスクで見ると細い帯で、植物はほとんど外縁に立つ。

## 6. Humanに判断してほしいこと

1. **方式**：B（局所アクセス投影）を採用してよいか。
2. **家の平面の仮定**：家の平面を広めにとった結果、内部はほぼ外縁頼みになる。このままでよいか、平面を浅くして内部（家々の間の庭・路地）にも根元を許すか。
3. **修繕後の外縁**：空き家のまま修繕された街区で、外縁の木を残す（D0の「条件付きで維持」）か、修繕の年に外縁も閉じるか。
4. **局所の植物の量**：周囲の植え付けより少し密（下草は64px²あたり0.5本まで）。荒れた敷地らしいか、多すぎるか。
5. **再利用での消え方**：再利用の年に局所の植物が消える（伐採の描写はない）。これでよいか。
