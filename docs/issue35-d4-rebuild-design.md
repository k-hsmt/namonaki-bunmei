前段：D3（PR #117）、公開 v0.7（PR #118）。D0：[`issue35-architecture-design.md`](issue35-architecture-design.md) §6、受け入れ A09〜A20・A23・A24

## 1. なぜD4か

- D3-dの監査で、v8の新築は世界ごとの中央値で4200年に止まり、それより後の伝統の変化は建物に現れなかった（建物に現れた2軸以上の変化：1万年で57%）。
- D3-cの技術は、建設が止まると失われ、高度な建物は1棟も建たなかった（Human判断A：景観に見えるのはD4の建て替えから）。
- D3-dのHuman判断4：技術の喪失の条件はD4で見直す。

## 2. 調べて分かったこと（事実）

### 2.1 v8が記録する建物の移り変わり

| 対象 | 移り変わり | 記録の種類 |
|---|---|---|
| 施設 | 健全 →（災害）損傷 → 3年以上の担い手の回復で修繕 | `building-damaged` → `building-repaired` |
| 施設 | 担い手・食糧の不足で使われなくなる（廃墟）→ 12年以上の回復で再利用 | `building-abandoned` → `building-reused` |
| 住宅 | 損傷 → 修繕、または長い不足で廃墟 → 12年以上の回復で修繕 | `housing-damaged` → `housing-repaired`／`housing-ruined` → `housing-repaired` |
| 住宅 | 使用中 → 使われにくい → 空き家 → 再利用 | `housing-underused`・`housing-vacated`・`housing-reused` |

- v8には**撤去も建て替えもない**。建物のIDと敷地は一度決まると変わらない。施設の置き場所は地区ごとに決まった11か所で、一度建つと新築されない。
- v8の再利用の記録の文は「〜が再利用される／同じ区画に、以前の暮らしの痕跡が残っている」。

### 2.2 廃墟からの立ち直りの回数（10世界、各1万年、自動の選択）

| | 1世界あたり | 時期 |
|---|---|---|
| 施設の「廃墟 → 再利用」 | 216〜494回 | 1000年ごとにほぼ均等（2000年以降も続く） |
| 住宅の「廃墟 → 修繕」 | 16〜54回 | 同上 |

施設は1世界に30棟前後なので、1棟あたり1万年で約10回、廃墟から立ち直っている。**新築が止まった後も、廃墟から立ち直る出来事は1万年まで続く。**

## 3. D0との関係で決めること

D0の受け入れ条件：

- A11 修繕・再利用：同じID・元の建設年・出典を保つ
- A13 撤去・新築：古いIDの終わり、新しいIDの発行、同じ土地の別の建物
- A14〜A16 建て替えの様式：古い様式の再現・その時の様式・混合（出典つき）
- A19 撤去だけ・新築だけの半端な歴史を残さない

v8の「廃墟 → 再利用」は、v8の上では**同じ建物の再利用**（A11）として記録されている。これを建て替えとして扱うと、v8の記録の文（再利用される）と、v9の見た目（別の様式の建物）が食い違う。

## 4. 案

| 案 | 内容 | 長所 | 短所 |
|---|---|---|---|
| **A** | v8の「廃墟 → 再利用（施設）」「廃墟 → 修繕（住宅）」の年に、v9が**建て直し**を記録する。v8の建物IDは敷地の番号として残し、v9が建物の世代（例：`river-bank-3#2`）を発行する。年代記には、v8の記録の隣にv9の記録「〜が建て直される」を出す | v8の確定した出来事が出典になり、時期が担い手の回復と一致する。1万年まで続く | v8の文「再利用される」と食い違う（v9の記録で補う）。年代記の表示を変える必要がある |
| B | v9が25年ごとの区切りで、長く廃墟だった建物や古い建物の建て直しを自分で決める | v8の文と食い違わない | v8に裏付けのない建設になる（D0「確定した建設イベント」に反する）。担い手の回復と関係なく起きる |
| C | 世界の仕組みそのもの（v8）に撤去と建て替えを加え、v10にする | D0にいちばん忠実 | 社会・経済の歴史が同じseedのv8と変わる。規模が非常に大きい |

**推奨：案A。** 確定したv8の出来事（担い手と食糧の回復）を出典にでき、規模も建築の記録（v9）の中に収まる。v8の文との食い違いは、v9の記録「建て直される」を年代記に並べて示す。

## 5. 案Aの中身（案）

### 5.1 建て直しになる出来事

- 施設：`building-abandoned` の後の `building-reused`（廃墟から12年以上）
- 住宅：`housing-ruined` の後の `housing-repaired`（廃墟から12年以上）
- 損傷からの修繕（廃墟にならなかったもの）は、**同じ様式のまま**（A11）。

### 5.2 建て直しの様式（A14〜A16）

建て直しのたびに、次の3つから決める（確率は仮。調整は監査の後）。

| 様式 | 内容 | 重みを上げるもの |
|---|---|---|
| 古い様式の再現 | 前の世代の様式をそのまま（その技術が残っていれば） | 伝統が前の世代から変わっていない、古い世代が長く続いた |
| その時の様式 | 建て直す年の地区の伝統と技術で、新しく決める（新築と同じ） | 伝統が変わった、新しい技術がある |
| 混合 | 前の世代から構造・壁を残し、屋根・窓・装飾をその時の伝統にする | 中間 |

- 高度な技術（D3-c）は、その年に地区が持っていれば、建て直す会堂・市場・仕事場で使える（D3-cと同じ約60%）。
- 上空の範囲の決まり（D2-b2）は新築と同じ。前の世代の範囲は、建て直しの年に終わる（A19：同じ年に、前の世代の終わりと新しい世代の始まりを一緒に記録する）。

### 5.3 記録と表示

- v9の記録に「世代」を加える：`{v8の建物ID, 世代番号, 始まりの年, 終わりの年, 出典（廃墟の記録・再利用／修繕の記録）, 様式の選び方}`。読込時は全部計算し直して照合する（これまでと同じ）。
- ある年の風景は、その年に有効な世代の様式で描く（過去の年を見れば前の世代が見える）。
- 年代記：v8の「再利用される」の記録の後に、v9の「〜が建て直される（その時の様式／古い様式で）」を表示する。

### 5.4 技術の喪失の見直し（D3-dのHuman判断4）

- 建て直しも「施工の経験」に数える。これで、新築が止まった後も、建て直しが続く地区では技術が保たれ得る。
- 喪失の条件（100年仕事がない）は今のまま。建て直しで経験が戻るので、まず監査で喪失の数を見てから決める。

### 5.5 既存の保存

- v0.7のv9の保存は、D4の後もそのまま開ける必要がある。案：建て直しの記録は、その世界を次に進めたときから付ける（過去の年の廃墟からの立ち直りには付けない）。または、読込時に過去の分も計算する（記録の版を上げる）。**どちらにするかもHuman判断。**
