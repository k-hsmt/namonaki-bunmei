## 範囲と意図

B0でHumanが選択した「植物造形は約12系統を**すべて試作し、比較してから絞る**」を受け、**13系統すべてに固有の形状を持つドット絵**を試作する。固定カメラ320×180pxの原寸で区別できるか、人間が比較して判断するためのもの。

**このPRでは行わないこと**：本編への植物描画接続、地形正本への配置、バイオーム生成確率、年次の植生遷移、社会・RNG・保存形式の変更、Issue #47の完了判定。初期気候と#32・#34の成長・遷移統合は**後続B2で必須**であり、画像試作だけで達成したとはみなさない。

## 造形差の狙い

| ID | 系統 | 色以外での識別ポイント | 検証上の懸念 |
| --- | --- | --- | --- |
| deciduous | 落葉広葉樹 | 分かれた枝、丸い複数の樹冠塊 | 常緑樹と似やすい |
| evergreen | 常緑広葉樹 | 厚く連続した樹冠・濃い葉面 | 落葉広葉樹の色替えに見えないか |
| conifer | 針葉樹 | 高い尖塔・段状の水平枝 | 三角形が人工的に見えないか |
| tropical | 熱帯高木 | 高い直幹・張り出す樹冠・垂れるつる | 建物への大きな被り |
| savanna | 乾燥地の疎林木 | 曲がった幹、傘状に横へ平たい樹冠 | 河畔樹木との見分け |
| riparian | 河畔樹木 | 垂れる枝葉と明るい樹冠 | 水辺樹木の一般化が強すぎないか |
| dry-shrub | 乾燥地の低木 | 細かい分枝、まばらな小葉 | 原寸では小さく見える |
| tundra-shrub | 寒冷地の低木 | 地表に這う枝と低い斑状葉 | 苔類との違いが弱い可能性 |
| bush | 一般低木 | 密な複数の葉群による丸い塊 | 小型の広葉樹に見えないか |
| grass | 草本 | 高さの異なる細い葉と穂 | 1枚の舞台で原寸では細すぎる可能性 |
| fern | 林床植物 | 羽状に左右へ分かれる葉 | 草・湿地植物との差 |
| reeds | 湿地植物 | 垂直の茎・穂・根元の水辺葉 | 草本との形態差 |
| moss | 苔・地衣類 | 地表・岩に沿う薄い被覆 | 単体スプライトでは最も認識しづらい可能性 |

「河畔樹木」は植物分類学上の一樹種ではなく**形状／生息地を組み合わせた試作カテゴリ**。本編の生育適性・局所条件はB2で別に定義する。濡れた地面・砂・岩・落葉等の地表マテリアルは植物13系統と別の試作課題（B1b）に残す。

## テストと再現性

`node --test tests/issue47-b1a.test.mjs` で次を確認する：

1. 13系統の定義、名前とIDの重複がない。
2. 成熟・若齢それぞれ72×64px、輪郭が空でない、若齢は成熟より小さく、再描画で画素が同じ。
3. 13系統の**不透明画素の形状マスクがすべて異なる**（色替えだけではないという機械的条件）。
4. 4枚の320×180プレートのサイズ・再描画一致。
5. 本編のimport・非決定的な乱数・外部読み込みがない。

注意：形状マスクの異なりは視認性を保証しない。**最終的なHuman判断は原寸72×64と320×180を見て行う**。拡大で目立つ差も実際のゲーム画面では消える場合がある。

## Humanレビューの観点・次工程

1. **輪郭**：広葉樹2系統、草・葦、低木3系統などの原寸識別が十分か。
2. **大きさ**：植物と建物・人間の相対的スケールは、既存の320×180の街並みに合うか。
3. **植物としての説得力**：針葉樹の規則的な形、熱帯樹冠とつる、寒冷地の地這い、地衣類の薄さが不自然ではないか。
4. **文化と自然の均衡**：建築や川を隠す高木をどの程度許容するか。今回は固定試作舞台なので実地形の建物遮蔽判定はB1bで行う。
5. **採用／修正／統合**：13系統をそれぞれ採用・要修正・統合候補へ分類し、修正後にB1bへ進む。

本PRはレビュー対象であり、本編へ組み込まない。**Humanの採否判断が出るまではB1b／B2に自動進行しない。**
