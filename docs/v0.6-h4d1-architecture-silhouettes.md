# v0.6 H4-D1｜既存建築のシルエット差別化（Humanレビュー）

**Draftレビュー用。本PRは描画のみを変更し、H4-D2／H4-D3は対象外。**

## 現状の課題

H4-B統合後も、建物がほぼ同じ切妻の箱であり、施設の機能・共同体の核・建築規模の違いが320×180上で読みづらい。H4-D1では既存の建物種別を使って、色や小物でなく大きな輪郭から見分けられるようにする。

なおH4-C（PR #22）は本ブランチ作成時点でDraft・未マージ。H4-Cの自然進行画像はレビュー参考とし、未統合コードは重複実装しない。

## 今回の建築語彙

| 種別 | 新しいシルエット | 歴史の根拠 |
|---|---|---|
| house | 小さな切妻または横長の低い屋根 | 既存 `SiteObject.kind=house` と固定ID |
| granary | 縦長・高床・少ない開口部 | 既存 `kind=granary` |
| workshop | 横長・作業庇・既存の煙突 | 既存 `kind=workshop` |
| hall | 幅広い高屋根・大きい入口 | 既存 `kind=hall` |
| market | 開放的な大屋根・複数の柱・露店的な構成 | 既存 `kind=market` |
| residential low | 小さな切妻と固定variantの棟飾り | `housingAt` 確定 `styleId=low` |
| residential terraced | 水平の連棟屋根・壁面の分節 | `housingAt` 確定 `styleId=terraced` |
| residential courtyard | 緩い屋根・中心の抜け | `housingAt` 確定 `styleId=courtyard` |
| ruined | もとの建物の幅・高床の残骸を一部保持 | 確定 `condition=ruined` |

橋は既存の確定履歴・河川位置に由来する造形を維持する。市場を新規建築として増設したり、橋のない年に橋を出現させたりしない。

## 不変条件

- 新しい施設種別、住宅イベント、セーブスキーマ、人口・社会・交易ルールは**変更しない**。
- `drawBuildingSprite` の建築形状は既存の `kind`・ID（住宅の一部）・確定条件からだけ計算する。時代・居住規模・人口から既存建物の姿を再抽選しない。
- 住宅街区の姿は既存の `styleId`・`styleSeed`・`partId` に従い、同じ履歴では必ず同じ画像とする。
- 建物ID・座標・建設年・地表敷地の占有・屋根が表す住戸数・保存形式は不変。
- 旧セーブの未記録住宅に新しい履歴を追加しない。
- 市場・橋・集会所の施設が他の屋根に埋もれないH4-Bの描画順を維持する。
- 新しい政庁・館・城塞を自然進行に追加しない。

- H4-CのPR #22がまだ未マージなので、最新の自然進行画像についてはPR #22の独立した成果物と照合する。

## 人による受入判断

1. 320×180の原寸で家・倉庫・工房・集会所・市場の**機能の違い**を説明なしで見分けられるか。
2. 4段階の町・都市画像で、住宅と公共建築の建築的な階層を感じられるか。
3. 廃墟が元の施設から連続した姿に見えるか。
4. すでに存在する市場や橋が隠れていないか。
5. 簡潔で穏やかな架空文明の世界観から逸脱していないか。

**アルファ輪郭や画像ハッシュの相違は視覚受入の代わりにはならない。**
