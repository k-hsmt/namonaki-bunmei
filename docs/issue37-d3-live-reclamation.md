# Issue #37 D3｜廃墟の敷地への植物の回帰を本編に接続

- 設計：[issue37-ruin-reclamation-d0.md](issue37-ruin-reclamation-d0.md)（D0 §11 D3）、前工程：[D1b](issue37-d1b-reclamation.md)（方式B採用・Human判断反映済み）、[D2](issue37-d2-live-weathering.md)（マージ済み）
- 状態：**本編の景観に接続**。保存形式・歴史・文明RNG・年次処理・植生の記録（パッチの年齢・攪乱イベント）は変えない。
- 停止線（D0 §11）：建設上の土地占有（`sceneOccupiedPlots`・`housing-ground.ts`）は読むだけで変えない。植物を理由に建物を消したり、建設可否を変えたりしない。

## 1. 何が変わるか（本編の見た目）

v9以降の世界の景観で、**空き家・廃墟の敷地に植物が根を下ろす**（D1bで承認された規則`reclamation-access-v1`）。

- 住宅街区：空き家になった年から外縁（敷地の縁2pxと外側4px）、廃墟になった年から内部（家の列の間）が開く。修繕・再利用の年に両方閉じ、再び空き家・廃墟になればその年から改めて開く。
- 施設（畑・橋を除く）：廃墟になった年から外縁と内部（壁の線の内側）が開き、修繕・再利用で閉じる。
- 根元は、家・壁の平面（＋1px）、水辺、その年に立っている他の建物の敷地（＋4px）には立たない。
- 植物は開いた年から草→低木→若木→成熟木。種類と上限はそのパッチの群落（local-flora-v1）と気候の上限に従う。
- **これまでの植え付け（`planFloraScene`）は一切変えず、その後に足す**。間隔は本編と同じ規則（下草7px、下草と木10px、木どうし10/18px）。
- 建設時から記録のない建物は扱わない（D0 §3：履歴不明は保護）。

**既存の世界への影響**：保存データはそのまま読み込める。読み込んだ世界の空き家・廃墟の敷地に、上のとおり植物が描かれる（作り直しは不要）。

## 3. 検証

- 単体テスト：623件すべて成功（新規 `tests/ruin-d3.test.mjs` 2件）。
  - 実際の世界（seed 6、1400年まで）の12場面で、足した植物の根元がすべて開いた区域の中にあり、家・壁の平面にも、立っている建物のそばにも立たないこと。これまでの植え付けとの間隔。
  - 確定履歴をその年で切っても同じ植物、同じ観測を繰り返しても同じ植物、観測・植え付けの前後で保存データが同一。
- ブラウザテスト：全体の実行では93件中80件が成功、13件が失敗。
  - 12件はBGMの検査で、作業環境にWebKitがないため起動できないもの（D1c・D2と同じ）。
  - 1件は`flora-scene`の検査で、期待する景観を組み立てるときに足した植物を含めていなかったため。含めるよう直し、このファイルを単独で再実行して成功した（足した植物も、地面線より手前に根がある時だけ建物を覆い、静止画と動く景観が一致する）。修正後に全体を再実行してはいない。
  - CIでの結果は未確認。
- mainとの比較：同じ18場面（4世界）をmain（D2まで）とD3で描いた。目で確認したのは砂漠の5場面で、変わったのは廃墟の周りに乾いた低木・小さな木が増えたことだけだった。

## 4. 性能

`scripts/benchmark-ruin-d2.mjs`（4世界×廃墟の多い6場面、ブラウザ、2回目の描画の平均）で、mainとD3を交互に2回ずつ：

| 世界（seed） | main（2回） | D3（2回） |
|---|---|---|
| 温帯林 6 | 85.5／85.2 ms | 110.5／98.4 ms |
| 熱帯雨林 1 | 80.2／84.8 ms | 99.4／98.0 ms |
| 砂漠 3 | 77.3／65.1 ms | 99.0／83.7 ms |
| 亜寒帯林 18 | 87.4／87.2 ms | 118.4／97.0 ms |

**D3は廃墟の多い場面で1枚あたり約10〜31ms遅い（約+11〜36％）**。内訳をNodeで測ると、足す植物の計算そのものは1場面3〜9ms。残りは、足した植物の描画と、植物が廃墟に重なることで必要になる前後の判定（建物ごとの地面線の作成）で、正しく描くための費用と見ている（確証のための詳しい分解はしていない）。廃墟の少ない場面は計測していない。景観は観測した年が変わるときに描き直す（動く景観の揺れは準備済みの層の合成）ため、毎フレームの費用ではない。
