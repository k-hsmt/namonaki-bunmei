# v0.6 H4-A｜集落・村・町・都市の比較基準と視覚設計（Humanレビュー）

状態：**比較基準の固定／未承認**。本PRは描画アルゴリズム・自然進行・住宅履歴・保存形式を変更しない。Milestone Bは未完了。

## 目的と分離

『名もなき文明』の視覚的な主要課題は「集落／村／町／都市が画面を見ただけでは区別しにくい」こと。H3-Cで河畔住宅の長期履歴と保存再開を検証できたため、地形の丘陵・入り江拡張を待たず、**すでに履歴を持つ河畔**からH4を進める。

- **H4-A（本PR）**：現行の風景を4段階・同一地形・固定カメラ・同じseedで並べ、視覚的改善の判断基準と根拠を固定する。画像は固定履歴fixtureであり、自然進行の実測ではない。
- **H4-B（別Draft PR）**：Humanレビュー後、確定建設履歴の範囲で屋根群・連結した道路や広場・前後関係を描き分ける。画像だけでなく建物由来を保持。
- **H4-C（別Draft PR）**：実際の自然進行で各規模を見られるか、1,000年程度の複数seedで画像・履歴・画素再現を確認。4段階すべてが自然進行で出現するとは仮定しない。

## 現状の実装根拠

| 描画要素 | 正本 | 制約 |
|---|---|---|
| 背景の川・丘・地形 | `drawScene` 固定地形 | 年代や規模で地形を差し替えない |
| 既存の施設（市場・仕事場・橋・集会所等） | `SiteSnapshot.objects`→`SceneComposition.structures` | `scale`を理由に存在しない施設を追加しない |
| 住宅街区と複数屋根の部品 | `housingAt(year)`→`residentialBlocks`→`roofParts` | 住戸数と屋根数を同一視しない。状態・敷地・建設年を固定 |
| 道路・公共空間の色面 | `SiteSnapshot.visual`、履歴由来の施設アンカー | 道路施設そのものの確定履歴ではない。「舗装・小径の表現」として扱う |
| 河岸利用 | 確定済み市場・仕事場・橋 | 港・埠頭・新施設を暗黙生成しない |
| 建築様式・建設年 | 各住宅イベント、施設履歴 | 規模分類だけで既存屋根の外形を変えない |
| 過去・旧セーブ | v4 `housing`／`unknown,partial,known` | 追跡開始前の住宅を推測で追加しない |

既存のVisual AとH1ブラウザテストには画像の相違・再描画の決定性の検証がある。ただし「四段階が見分けられる」ことは画素差だけでは証明できない。Humanによる評価を必須とする。

### 人間が画像を評価する質問

1. 説明を読まずに「疎らな集落」「集まった村」「公共・交易機能のある町」「道路と住宅街区が一体化した都市」を区別できるか。
2. 同じ地形・川の輪郭・ランドマークが時代を通じて追えるか。
3. 歴史上存在する市場・集会所・橋が、住宅屋根の重なりで読めなくなっていないか。
4. 屋根の密度と住宅の数・規模に乖離がないか（1屋根が複数住戸を表してよい）。
5. 道・広場・建物が「独立した点の集合」ではなく、人が暮らす街区として連続して見えるか。
6. 320×180の実寸で視認でき、4倍拡大で不自然なぼかしがないか。

人間の評価結果はPASS/FAILと根拠・画像IDを残す。**単なる4画像のハッシュ相違を視覚受入と取り違えない**。

## H4-Bの推奨実装順

1. **奥行きと遮蔽**：現在は`far`/`middle`の住宅→施設→`near`の住宅の順。前景住宅が既存の市場・橋などを隠す場合があり、建築の識別性を壊さない描画順と安全な地表占有を設計する。
2. **住宅群の連続性**：記録済みの住宅街区のfootprint内だけで屋根のグルーピング、壁面や軒、路地のテクスチャを改善する。街区や施設の実体は追加しない。
3. **道・広場の関係**：既存の施設と住宅の位置から描画できる舗装・小径を連結する。ただし地形・河川の上を道路として塗らず、道が新設施設であるかのように表現しない。
4. **4規模の読み取り**：単なる建物の多寡だけでなく空地の残り方、軒の重なり、公共施設の読みやすさ、地面の連続性によって読み分ける。分類変化だけで既存建物の形を一斉に差し替えない。
