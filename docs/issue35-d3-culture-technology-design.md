## 0. D3でやること

D0 §9 のD3は「地域内発明、技術能力の成立／喪失、地区間の確定交流・受容・混交、高度技術による新建築」。D2では地区の伝統は年0のまま変わらない。D3で伝統と技術が時代とともに変わるようにし、建物は**建った年の伝統と技術**で建つようにする。通常画面への公開（D2-d）はD3と同時に行う（Human判断）。

守ること（D0から引き継ぐ）：
- 年数や知識の閾値で一斉に切り替えない（D0 §7.1）。変化は確定したイベントの結果で、出典を追える。
- 「交易あり＝必ず伝播」「伝播あり＝必ず新築」「新築あり＝必ず新様式」にしない（D0 §4.2）。交流が無くても地域内の発明は起こり得る。
- 技術の成立と建築での採用を分ける（D0 §2）。技術があっても伝統が選ばなければ建てない。
- 既に建った建物の様式は変えない（A10）。
- v8の歴史を変えない（D2と同じく一方向）。

## 1. 調査で分かった前提（main `3e29af7` で確認）

### 1.1 地区間の交流は、過去の分が組ごとに残っていない

| 記録 | 残り方 | 出典 |
|---|---|---|
| 交易路ごとの交易の有無 `routes[].tradeYears` | **直近20年分だけ**（真偽の並び） | `regional-economy.ts`、seed 7で確認 |
| 地区の組ごとの移住 `migrationYears` | **組ごとに最後の年だけ** | 同上 |
| その年の移住の内訳 `moves`・交易量 `traded` | 年次の計算にだけ使われ、**保存されない** | 同上 |
| 交易路の開通・協定・途絶の記録ID | **最後の1件だけ** | `Route` |
| 歴史の記録 `state.history` | 全件残る。ただし交易・移住・来訪の多くは**文明全体**の記録。地区の組は文章（「川辺と丘陵を結ぶ往来が途絶える」）にしか現れない | seed 7、3000年 |

D0 §4.4 は伝播の出典として「どの地区からどの地区へ」の構造化した記録を必須とし、文章からの抽出を禁じている。また、D2では保存の読込時に建築の記録をv8の歴史から**全件再計算して照合**している。今のv8の保存からは、過去の地区間の交流を後から組ごとに計算し直せない。

### 1.2 1年ずつ進めて観測する方法は遅すぎる

v8を1年ずつ進めて交流を観測すれば記録はできるが、seed 7 の1000年で、一括で進めると5.2秒、1年ずつだと265秒（約50倍）だった（結果の歴史は完全に一致）。1万年で約44分かかるので使えない。

### 1.3 年ごとの経済を受け取る口は既にある

`story/economy-observer.ts` に、年ごとの経済の結果（`moves`・`traded` を含む）を受け取る仕組み `EconomyObserver` がある。ただし本番のv8の進行（地形の世代）が使っている口 `CoupledReceiptObserverInternal` は、収穫と廃棄だけを受け取り、その値はv8自身の記録に入る。ここに項目を足すとv8の保存が変わるので使えない。建築のためには、**v8の記録に入らない別の受け口**を、v8の進行の経路に通す必要がある。

### 1.4 後から計算し直せる材料

次のものはv8の保存に全件残るので、読込時に計算し直せる：各地区の建設（D2の建設時様式の記録）、施設・住宅の修繕と放棄の記録（年・建物ID・地区）、地区の規模の変化（集落の台帳の `changes`）、災害の記録（種類・年）、地区ごとの慣習（`society` の `practiceChanges`）、人口の標本 `samples`。文明全体の `knowledge` は**現在値しか残らない**。

## 3. 文化の変化のしくみ（案）

### 3.1 記録

| 記録（案） | 内容 |
|---|---|
| `InteractionEvent` | 年、種類（交易・移住・交易路の開通／途絶）、送り元と受け手の地区、量、出典の記録ID（あれば）。S-Aで観測したもの |
| `TraditionChange` | 地区、年、軸、変更前と後、原因（発明・伝播・再評価・喪失）、出典（交流の記録・建設・修繕・災害の記録のID） |
| `CapabilityEvent` | 地区、年、技術（T01〜T09の一部）、操作（成立・習得・喪失・再発見）、出典 |

伝統は「年0の伝統 ＋ その年までの `TraditionChange`」で求める。建物は**建った年の伝統**で様式を決める（D2では年0の伝統）。過去の建物の様式は変えない。

### 3.2 変化の経路（D0 §4.2の5段階を分ける）

1. **発明・地域適応**：その地区で建設と修繕が続いていること（施工の経験）を条件に、まれに伝統の1軸が近い候補へ変わる。
2. **接触**：交流の記録（S-A）がある組の間で、送り元の伝統の特徴を「知る」。
3. **受容**：知った特徴を、受け手の地区の伝統に取り込むか、拒否・保留する。交流が多いほど受容しやすいが、必ずではない。
4. **新築での採用**：取り込まれた特徴は、その後の新築の様式で選ばれ得る（建設時の個体差と用途の規則はD2のまま）。
5. **継承・喪失・再評価**：長く建設も修繕もない特徴は失われ得る。失われた特徴も、確定した過去の建物が残っていれば再評価で戻り得る。

**判定の時期**：毎年は判定しない。D0 §7.2の「理由のない小刻みなちらつき」を避けるため、25年ごとの区切りで、その区間に起きた出来事（交流・建設・修繕・災害）をまとめて判定する案とする。乱数はD2と同じく文明の乱数とは別の決定的なハッシュで、地区・年・軸・原因から作る。

### 3.3 技術（D3で扱う範囲の案）

D1で絵が受け入れ済みのものだけを対象にする。

| 技術 | 能力 | 建物に現れるもの（D1の語彙） |
|---|---|---|
| T01＋T07 | 木の接合・大スパン | 大スパン木造 X1 |
| T02＋T04 | 組積・アーチ | 石造＋アーチ X2、大規模基礎 F6 |
| T05＋T06＋T09 | 金属・採光・外皮 | 金属支持＋ガラス X3、採光窓 W7、金属板・透過材の屋根、金属支持・複合外皮の壁 |

- 成立の条件：その地区の施工の経験（建設・修繕の数）、規模（町・都市）、交流（S-A）。年数や `knowledge` だけでは成立させない。
- 採用：技術があっても、伝統と用途が選ばなければ使わない。D1の例のとおり、まず会堂・市場・仕事場に現れ、住宅は在来のまま残る場合を許す。
- 喪失：長く使われない技術は失われ得る。失われても、既に建った建物は消えない（A09）。
- 3階建て以上（T08）は、D1で絵が無いので**D3では扱わない**。

### 3.4 校正（D0 §7.4）

- 目標の目安（固定の仕様ではなく、試走の警戒線）：
  - 約500年：多くの世界で初期の面影が残る
  - 約1万年：長く活動した世界の80%以上で、建築の複数の軸が初期から変わる
- 50〜200世界の高速の監査で、軸ごとの変化の回数・時期・原因の分布を出してから、Humanが校正値を決める。
