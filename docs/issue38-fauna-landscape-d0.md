- Issue：[構想｜動物のいる風景：野生・家畜と文明の距離の変化](https://github.com/k-hsmt/namonaki-bunmei/issues/38)

- 状態：**D0 Humanレビュー対象／設計のみ。** 本編・保存・Issue状態はこのPRで変更しない。
- 共通指針：[AGENTS.md](../AGENTS.md)。旧形式の互換を先取りしないが、**現行世界の正本・確定年・保存往復・再現性・乱数の分離**は必須。
- 前提：#47 初期気候・植生、#34 長期気候・地形環境、#36 季節・動く景観、#37 廃墟と植生回復、地形・建築・人口の既存確定史。

## 1. 目的とHuman確定事項

人間の定住以前の草原・森林・水辺に動物がいる。定住・開墾・都市化によって動物が利用する場所は変わり、文明の衰退と自然回帰によって再び生息条件が整う場所もある。人のいない時代にも生き物の営みがあることを、320×180pxの観測窓で**控えめに、時には豊かに**見せる。

| 対象 | Human確定方針 |
| --- | --- |
| 動物存在モデル | **B**：安定した生息候補地点を持ち、確定環境に応じて出現 |
| 家畜導入 | **B**：野生動物＋人里に適応した野生動物。家畜は飼育・家畜化の確定履歴まで保留 |
| 出現密度・存在感 | **B**：日常は控えめ、条件のよい生息地では複数頭・小群れも可能 |
| 移動範囲 | **B**：生息地周辺で短い局所移動、出入りと飛翔を許容 |
| 造形・縮尺 | **B**：人・建築との縮尺関係を保ちつつ、種群の識別に必要な輪郭を優先 |

重要：**同じ生息地を何百年も利用し得る**ことは、同一の個体が何百年も生きることを意味しない。

## 2. D0の範囲と除外

### 対象
- 陸生の野生大型草食動物、野生小動物、森林・草原・水辺・人里に適応する鳥など、まず**姿・動作・生息条件の異なるグループ**で試す。
- 気候7系統、局所環境（ordinary / riparian / wetland / coastal / rocky）、植物の群落・成長段階・地表の状態、河川／海岸の水面、確定した人口・建築・農地・土地利用・廃墟の変化。
- 位置固定の生息候補、観測年ごとの適性・出現計画、原寸での静止・短い動作、地面／水面／飛翔経路の安全判定、前景／後景の遮蔽。
- 世界・地区・過去観測・保存往復・長期進行・性能の検証。

### 初版対象外
- 家畜（飼育牛・馬・鶏など）と飼育・牧畜・家畜化の確定履歴、野生化、経済・農耕・運搬・交易の効果。
- 野生動物の個体数、出生、寿命、繁殖、死亡、捕食、移住、群れの生態史、食物連鎖、動物と人のインタラクティブなAI。
- 年次の生態・疾病・農業・人口変動に動物描画が影響を与えること。
- 実際の屋根、枝、廃墟壁への止まり・営巣は、支持面が確定できるまで保留。飛翔・安全な地上／水辺への着地は初版対象。
- 実世界の特定種の厳密な地理的分布や生態学的な個体密度の再現。

Issue本文にある「野生と家畜の比率が変化」は**将来の拡張構想**。初版の受入条件は「人里に適応する野生動物と大型野生動物の出現差・人間活動に伴う変化」に置き換える。家畜の条件を暗黙に満たしたと扱わない。

## 3. 正本・投影・動作を明確に分離

### 正本（本Issueでは変更しない）
- 世界seed、確定年、確定地形（水域・陸地・勾配・地形改変）・建設と敷地占有・人間の土地利用。
- #47 8×8pxパッチ×440/地区の局所群落・生育段階・初期気候・#34長期環境。
- #37 放棄後に開かれた地面と植生回復の確定履歴由来の描画投影。
- 人口・住宅・利用中施設・農地・橋・水路・公共空地などの確定履歴。
- #36季節の表示位相。年ごとの表示ルールを壊さない。

### 新しい表示専用の派生データ（保存しない）
1. **HabitatCandidates**：世界seed・地点と候補座標から、永続的な生息場所の**候補**を決定。年度ごとに候補IDを振り直さない。
2. **FaunaHabitatProjection**：観測年・候補周辺の気候／植物／水面／人間活動／構造物の適性と、種群ごとの出現可能性。
3. **FaunaAppearancePlan**：候補地点と年に対する出現グループ・表示頭数・配置・短い安全経路・行動位相。**個体史・群れ史ではない**。
4. **FaunaPoseAt(seconds)**：短い描画時間から歩行／採食／羽ばたき／佇み／一時的な不在・出入りを決定。年次処理を呼ばない。

観測するたびに乱数抽選を行わない。文明RNGと独立した`terrainHash(['fauna-...', seed, site, candidateId, ...])`等の**専用名前空間**のみを使用する。`Math.random()`や観測回数・フレーム数・壁時計の絶対時刻を生息・種・候補の正本に使用しない。

## 4. 生息候補地点の不変性と現在地形の整合

- 生息候補を地形の**記録座標**（320×180）に固定。画面の鏡像変換`mirrorX`は描画時に一度だけ適用。
- 安定キーの候補：`worldSeed + siteId + candidateCellId + faunaRuleId`。観測年・その年の環境値・動物の表示個体番号は候補IDの成立根拠には入れない。
- 地形改変・建築・橋・運河・河岸・#37廃墟・回復植物などの**その年の状態**が候補地点と動線の安全を上書きする。候補IDの存続は表示を強制するものではない。
- 同じ地点がある年に水没したら陸生動物の出現は禁止。将来その地点が再び安全な陸地なら同じ候補IDを再利用可能。
- 候補が無効な場合、近くの適地へ**見た目だけ強制ワープ**させない。選択した安全な周辺候補に限って移動するか、その年は非表示。
- 地形情報不明・年次不明・構造支持面不明の場合は**出現・着地不可（fail closed）**。

植物は8×8pxパッチであるが、動物の採食・隠れ場所・採水の評価は種群に応じて**複数パッチをまたぐ近傍集約**にする。1パッチ＝1頭にはしない。

## 5. 生息適性の入力と評価方針

| 入力 | 評価に使うもの | 注意 |
| --- | --- | --- |
| 世界気候／局所バイオーム | 7気候帯、パッチごとの群落、#34確定長期気候 | 砂漠でも河畔湿地などの局所環境を尊重 |
| 地表・水辺 | 現年の水面、岸辺、勾配、岩場、浸水・地形改変 | 陸生動物は水に立たせない、水鳥には水面／岸辺専用マスク |
| 植生 | #47の生育段階、実際の地上植物と#37回復植物の配置 | 立っている樹木／草地の「表示」から未確定の食物量を創作しない |
| 人間活動 | 人口、確定建物と使用状態、農地、既存の人の活動経路 | 地区総人口だけで全野生動物を排除しない |
| 季節 | #36のその年の季節外観 | 冬の雪面・休眠期などの姿の適応は別表示；繁殖・渡り史は創作しない |

大型草食動物／人里小動物／水辺鳥／森林鳥／飛翔鳥では、各入力の重みや使用面が違う。**人間の増加で全種一律に減る**規則は設けない。

構想上の評価手順：
1. その年の確定地形に候補の安全な場所があるか。
2. 種群の必須条件（陸上・水上・空中、気温帯、植生など）を満たすか。
3. 候補の近傍に採食・休息の条件がどれだけあるか。
4. 人間の活動を種群ごとに異なる方向へ反映する。
5. 候補IDの固定閾値と表示密度の制限から**その年の出現可能性・表示計画**を導く。

適性と表示頭数は別。適地が多くても全候補に常時表示しない。候補の適性が閾値付近で年ごとに点滅する場合、D1bで固定閾値方式と**当該年以前の確定状態だけ**を用いた平滑化・ヒステリシスを比較する。未来の変化を読まず、未保存の「前年に画面を見た記憶」を生息継続条件に使用しない。

## 6. 動物分類・家畜境界

初版は「野生大型草食動物」「小型地上動物」「鳥（陸上・水辺・飛翔）」を、シルエットと生息ルールの**種群**として扱う。人里適応は独立した家畜分類でなく、種群ごとの人間活動への耐性パラメータとする。

| バイオーム | 試す種群（例） |
| --- | --- |
| 砂漠 | 乾燥地の小型動物・鳥／水辺があれば局所的に水鳥 |
| ステップ | 草食獣・地上性鳥・小動物 |
| 草原 | 草食獣の小群れ・草地の鳥 |
| 温帯林 | シカ類・森林の小動物・小鳥 |
| 熱帯雨林 | 樹上性・森林性の小動物、鳥 |
| 亜寒帯林 | 寒冷地の草食獣・小動物・森林鳥 |
| ツンドラ | 寒冷地の小動物・鳥・局所的な草食獣 |

表の種名は**造形試作の候補**であり、「世界seedから史実の特定種が確定した」とはみなさない。気候帯の境界はパッチごとの環境を優先する。

**牛・鶏・飼育馬などを農地から推測しない**。野生のウマ類を出す場合にも、飼育・運搬・牧畜を示す建築・道具・人との接触演出はしない。動物数は食料・交易・人口を変更しない。

## 7. 密度と小群れの扱い

- **日常は控えめ**：観測窓に動物がいない時間を許容し、都市の中心に多数の野生大型獣が現れない。
- **環境条件のよい場所**：草原／森林外縁／水辺で、種群に合う複数頭や小群れが成立し得る。
- 群れは一つの`habitatId`に対応した**描画上のまとまり**。構成員に恒久的なID・年齢・出生・死亡を持たせない。
- 群れ全体で近い活動範囲を持ち、各表示員の位相をずらして採食・静止・歩行。一定間隔を確保できなければ小さくする／表示しない。
- 同時の最大頭数、種群構成、出現率、群れ間距離は**D1比較で校正**し、D0で頭数を先に固定しない。
- 表示密度は「その年にその土地で見られやすい程度」の投影であり、**動物の本当の個体群密度ではない**。

## 8. 移動・行動・不在・鳥の飛翔

### 行動
`idle / foraging / walking / resting / taking-off / flying / landing / absent`などの**表示状態**で構成。長い静止と短い動作を基本とし、いつも歩き回る画面にしない。行動時間・歩数はD1で原寸動画を比較して決定する。

### 移動契約
- 陸生動物：生息候補の近傍の安全な地表セルだけを辿る。全身の占有幅・必要な高さ・移動中の通過領域を検査し、建物の敷地／残存壁／水路／急斜面を貫かない。既存の`groundContextWindows`は人用の歩行候補であり、動物の体格・環境を加味した専用マスクが必要。
- 水鳥：その年の実際の水面や安全な岸辺のマスクに限定。動く波・水面装飾の画素を着地点の根拠にしない。
- 飛翔鳥：空中の経路と出発／着地支持面を分離。屋根・枝・廃墟壁への**未確認の着地**は初版禁止。飛行は短距離や出入りを許すが、構造物との見た目の貫通を避ける奥行き区分を持つ。
- 画面端への移動は安全な退出経路がある場合のみ。**画面中央で突然消えることを演出しない**。経路がない場合は休息・非出現。
- 人の移動経路や施設近傍を大型野生動物の活動候補から抑制する。初版は個体が人間を見つけて逃げるAIを持たない。

### 2種類の「いない」
- **生息適性がない年**：その年の出現候補にならない。
- **その瞬間に姿がない**：その年には出現可能だが表示周期上は`absent`。不在も決定的な行動計画の一部。

## 9. 320×180pxの造形と描画順序

### 造形
人（現行表示は約2×6px）・建物・植物との縮尺関係を守り、**シルエットを読むための輪郭のみ強調**。表情の大きなキャラクター化は行わない。奥行きで縮小する。

D1a比較用の**仮の原寸サイズ帯**：
- 大型草食動物：横8〜14px（首、脚、胴体の形）
- 小型地上動物：横3〜7px（尾・小走り）
- 小鳥：横2〜5px（嘴・翼・跳ね）
- 水鳥：横4〜8px（首・水上姿勢）
- 飛翔鳥：翼幅4〜10px（羽ばたき）

サイズ・1動作あたりのフレーム数・色・実際の動作速度はD1aのHuman比較で選ぶ。点のような遠景でも動物として読めるかを試す。

### 空間判定と表示判定を混同しない
1. **Ground/Water/Air Access**：足場・水面・飛翔の経路をその年の地形／占有で証明。静止・移動の両方。
2. **Depth & Occlusion**：地上の足元（支点）と構造物の接地線・植物の前後によって、背後の動物を自然に隠す。飛翔鳥は固定の奥行き区分と構造物マスクを使用。
3. **Compositing**：既存の`scene/flora-draw.ts`にある植物の背後・前景の分割と、建物の現在形状・#36雪・人物のレイヤーに整合。動物を全画面の最後に一律描画しない。

既存`sceneOccupiedPlots()`や`housing-ground.ts`を動物のために緩めない。#37の植物に根元を許した廃墟内でも、動物の身体を置ける地表が別途証明できなければ配置禁止。

## 10. 静止画・動く景観・キャッシュ

現行の動く景観は`scene/motion-plan.ts`が活動を計画し、`scene/motion-frame.ts`が最大12fpsで描画、`scene/motion-player.ts`が描画準備を再利用する。動物をこれに統合するが、**生息適性判定はモーション再生から独立**させる。

- `FaunaAppearancePlan`を静止画と動く景観で共用する。静止画は**既定の表示時刻`seconds=0`**の姿。動く景観でも同じ時刻・同じデータなら同じ対象・座標・姿を再構築する。
- 動画中は`poseAt(plan, seconds)`だけ呼ぶ。毎フレーム植生440パッチや建築の占有を再解析しない。
- 低モーション設定／動く景観OFFでは静止姿を表示可能（その年の出現計画に「不在」があれば、静止画も不在でよい）。
- 同じ年に再表示した際の**行動経過秒数の復元は不要**。存在候補・種群・観測時刻に対する表示だけ再現する。
- 生息環境の変化を`sceneMotionVisualKey()`と静止画側の描画準備更新へ正しく反映する。地形・森林・#37回復植物・人口・施設・生息候補が変わっても**前年の動物をキャッシュで使い回さない**。
- 逆に年を進めただけで全部の地形／植物／建築描画を再生成する必要がない場合は局所キャッシュを検討。最終的なキー・差分単位はD2の性能測定で選ぶ。
- 表示の乱数は独立名前空間に固定。描画ON/OFF・時間停止・PC性能・12fps制御・観測年の行き来で正本を変えない。

## 11. 確定史・保存・過去再生の停止線

- **動物から文明への書込み経路ゼロ**：出生・飼育・生態変動イベントを追加しない。描画が食料・人口・交易・地形・植生の正本に影響しない。
- 動物出現をセーブに記録しない。現行世界の保存形式の整合は守る。旧形式だけのための互換レイヤーを新設しない。
- 任意の年`y`の表示が`y`より後の地形改変、修繕、植生回復、人口変動の情報を参照しない。
- 生息候補／時刻ゼロ表示／短い経路／画素（静止と再生0秒）が同一seed・履歴・観測年・地点で再現する。
- 一括／分割進行、保存→読込→再進行、観測地点の切替、描画ON/OFF、過去→未来→過去の観測で結果が一致する。
- 未確定の動物種・家畜化史・生息能力・支持面を推測で補うことを禁じる。

## 12. D1比較と機械的受入条件

### D1a：独立造形・短い動作の比較
- 複数の種群を同一縮尺の人・家・樹木と並べ、原寸320×180pxと最近傍拡大で比較。
- 佇み・採食・歩行・跳躍・水上浮遊・羽ばたき・画面への出入りを、可能な種群のみに作成。
- 静止が多い構成／動きが多い構成、単体／小群れ、遠景／中景／近景を比較。
- Human確認：小さくても種類が読めるか、建物との縮尺が不自然でないか、静けさを壊さないか。
- **D1aでは本編世界・生息年次・保存に接続しない**。

### D1b：環境・生息候補投影の試作
- 7バイオーム×3地区、森林・草地・河畔・湿地・海岸・岩場、異なる人口・土地利用・#37回復条件。
- 種群ごとの適性、閾値付近の年次点滅、候補IDの安定性、群れの間隔、長期気候と局所植生を比較。
- 動物の身体サイズを考慮した陸地・水面・空中アクセス、建物占有、段階的な廃墟回復との衝突を監査。
- **仮想条件を実際の文明史として保存しない**。自然seedの実世界で再現できる条件との区別を成果物に明記。

### D1c：実景観・動作の統合比較
- 原寸の静止画と短い動く景観、画面内0頭／1頭／小群れ、村と都市・文明以前と自然回帰後を比較。
- #36季節、#47植生、#37風化／植生回帰、左右鏡像、樹冠の揺れと動物の前後関係を確認。
- 同じ`seconds`、同じ観測年、同じseedで決定的な画像・行動結果を取得。
- 性能を計測し、Humanが受け入れるまで本編へ移行しない。

### 必須の自動検証
- [ ] 動物ON/OFFで文明state、保存、環境・植生の正本、文明RNGが不変。
- [ ] 生息候補IDは環境の値・観測年に左右されず安定。ただし無効な土地へ出現を強制しない。

- [ ] 一括／分割進行・保存往復・複数seed・1,000/5,000/10,000年と3地区を検証。

## 14. D0結論

Humanが選んだ5つのB案を正式な設計上の入力とし、追加の「好みを当てる」質問は不要。**世界に記録される人間の歴史と、観測される動物の営みは分ける。** 動物には世代をまたいで利用され得る生息候補があるが、それは個体の保存履歴ではない。動物が見えない時間を認め、条件のよい土地だけに豊かな姿を与える。

本D0をHumanがマージしたら、まず**D1aの独立ドット絵・短い動作・原寸比較**へ進む。表現が承認されていない段階で勝手に年次ルールや保存へ接続しない。
