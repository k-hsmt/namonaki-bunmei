## 前提

H4-B（PR #21）はmainへ統合済み。H4-Aの同一地形・同一画角での4段階比較は**手動で構成した確定履歴fixture**だった。本PRではその不足を補い、自然進行で実際に確定した観測年・居住規模・住宅と施設の履歴を画像とともに記録した。

- seed 7, 42, 82。新規v4文明、0～2,000年。選択待ちはシード付き自動選択で解決。
- 河畔（siteIndex=0）の観測を対象。丘陵・入り江の自然住宅建設は地形未検証のためHOLDのまま。
- 各seedで「各規模に初めて到達した確定年」「最初にcontractingになった確定年」「2,000年」を撮影。**到達していない規模は画像を生成しない**。
- 320×180原寸PNGとNEARESTの1280×720拡大PNGを出力。対応する人口、居住規模、住宅街区数・住戸数・屋根部品数、確定済み施設ID、住宅街区IDをJSONで残す。
- 画像は全て同じseed、同じ地形・カメラで描画。現在の保存をJSON再読込して同じ過去を再描画した際も**画素が完全一致**することを検査。描画は正本のJSONを変えない。

観測点の例：

- seed42 / 958年：自然発生した都市、人口43,348、住宅7街区、25住戸、25屋根部品。確定済み施設11件。
- seed42 / 2,000年：町へ変化。人口91,746、住宅25街区、79住戸、54屋根部品。人口だけで都市分類しないため、単なる人口不足とは断定できない。
- seed82 / 822年：自然発生した都市、人口56,100、住宅9街区、27住戸、27屋根部品。施設11件。
- seed82 / 2,000年：都市、人口53,664、住宅29街区、91住戸、55屋根部品。
- seed7 / 2,000年：町、人口78,298、住宅26街区、82住戸、57屋根部品。都市の画像は生成していない。

**留意点：** 都市なのに初到達年では住宅7～9街区程度であり、施設11件と屋根25～27部品程度。小さな320×180 Canvasでこれらが十分に都市らしく見えるかは、人間の視覚評価が必要。2,000年時点でも屋根部品数は住戸数に等しくない（1部品が複数住戸を表す）。屋根を増やすだけでは根拠のない建物を増やしたことになり得る。

## Human視覚レビューの判断ポイント

1. **ラベルを隠して4段階が判別できるか**：seed42または82で初到達した集落・村・町・都市画像を順序を入れ替えて見る。全段階に別の絵があるだけでは合格としない。
2. **自然進行の都市**：seed42/958とseed82/822が、住宅屋根の集まり・施設・広場・道の配置から町より高密度な都市として感じられるか。
3. **時代を経た都市**：seed82/2,000では住宅の数は増えたが、視覚的密度や道路の一体感に変化があるか。
4. **縮小・再編**：seed42/958の都市とseed42/2,000の町を比較し、建物の座標や過去の履歴を勝手に書き換えずに縮小後の姿が表現されているか。
5. **施設遮蔽**：市場・集会所・工房・橋が住宅に埋もれていないか。屋根の地表の非衝突と画像上の視認性は別判断。
6. **実寸優先**：原寸320×180で読めるか。4倍拡大はピクセル形状の確認用。描画の自動決定性とHumanの美的判断を混同しない。

## 判定・次の提案

- **自動検証：PASS（監査seed／対象年／現行ブラウザに限る）。**
- **居住規模の自然到達：部分達成。** seed42・82では4規模に到達、seed7は都市未到達。全seedが都市へ進む必要はない。
