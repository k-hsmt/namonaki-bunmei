## 1. 何を監査したか

`scripts/audit-issue37-d4.mjs` は、#36 D4（季節）の監査と同じ形で次を行う。

**Node（世界の記録）**：9世界（7つの気候帯の代表seed、温帯林・亜寒帯林はもう1つずつ）を、1,000／2,500／5,000／7,500／10,000年まで、**一括で進めた世界**と**監査年ごとに段階的に進めた世界**の両方で作り、段階的な世界は保存して読み込み直す。各監査年・3地区で次を確認する。

| 検査 | 内容 |
|---|---|
| 風化の時計が一致 | 一括・段階・読み込み直しの3つで、全建物の時計（放棄から・廃墟化から）が同じ |
| 戻った植物が一致 | 3つで、足された植物（D3）が同じ。これまでの植え付けも同じ |
| 過去は後の歴史に左右されない | 段階的な世界はその年より後の歴史を持たないので、一括の世界と一致することが「後の年が前の年を変えない」ことを示す |
| 根元の位置 | 足された植物の根元がすべて開いた区域の中にあり、家・壁の平面（＋1px）にも、立っている建物の敷地（＋4px）にも立たない |
| 保存 | 全監査年・全地区を観測しても保存データが変わらない。保存データに風化・植物の回帰の記録は含まれない。一括と段階の保存データが同一 |

**ブラウザ（Chromium、画素）**：

| 検査 | 内容 |
|---|---|
| 画素の一致 | 一括の世界と、段階的に進めて保存・読み込み直した世界で、各監査年・3地区の景観が画素単位で同じ |
| 地区の切り替え | 地区を切り替えて戻っても同じ画素 |
| 動く景観 | 動く景観の層（背景・建物の背後の植物・建物・手前の植物）を重ねると、建物の画素で静止画と同じ。木を揺らした後に戻すと元の画素に戻る |
| 性能 | 静止画の描画時間と、動く景観の準備時間 |

## 4. 範囲外・確認していないこと

- 10,000年を超える世界は対象外（本編の観測上限が10,000年）。
- 監査年は5つ（1,000年ごと程度）。その間の年は単体テスト（D2・D3）での確認に限る。
- 性能はこの作業環境のChromiumで測った値。利用者の端末での値は確認していない。
- CIでは速い版のみ実行する。完全版はローカルで、Node部分が世界ごとに63〜91秒（9世界で約12分）、これにブラウザ部分が加わる（全体の所要時間は計っていない）。
