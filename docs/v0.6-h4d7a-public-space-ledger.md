# v0.6 H4-D7-A｜公共空地を歴史として成立させるための正本

**状態：履歴・占有・試作描画まで。自然発生は未接続／Humanレビュー待ち。**

## なぜ今は「広場を描くだけ」にしないのか

H4-D6で大型会堂と住宅を結ぶ踏み跡は増えた。しかし、それは描画だけの痕跡であり、共同体が敷地を公共利用に定めた事実は存在しない。ここで人口・集落の規模に応じて突然広場を置くと、過去には空き家や畑があったかもしれない土地を、理由なく舗装したことになる。

今回は既存の「見た目の前庭」と、確定した「土地利用としての共同空地」を厳密に分離する。

## 正本（新設 `src/story/public-space-history.ts`）

`PublicSpaceHistory` は、住宅同様に**イベントから再構築する任意の独立台帳**とする。既存v4では未記録が正常で、読み込み時に空き地を生やさない。

```ts
interface PublicSpace {
  id: string;                              // public-river-bank-... の新ID
  siteId: 'river-bank';
  kind: 'assembly-ground' | 'market-yard';
  footprint: HousingPlot;                   // 実際に占有する地面
  establishedYear: number;
  anchorBuildingId: string;                 // 実在する集会所または市場
  foundationRecordId: string;               // 「公共空地を定めた」確定年代記の出典
  condition: 'used' | 'overgrown';
}
type PublicSpaceTransition = 'established'|'overgrown'|'reused';
```

- **assembly-ground**：集会所に関連する素朴な共同の空地。石造の宮殿や政治権力を暗示しない
- **market-yard**：実在する市場の周辺で品物を持ち寄るための土間。新たな店舗や屋台を捏造しない
- **established**：敷地・用途・接点となる施設・成立年・出典を固定。人口や都市規模から外観を推定して変えない
- **overgrown**：使用が途絶え、草に覆われ始める。空地の位置とIDは残る
- **reused**：後年に明示的な再利用イベントが起きた場合のみ再び使われる

利用状態が荒廃しても物理的な敷地は残り、他の家屋が無断占有しない。改築・撤去・区画整理は別工程とし、今回は行わない。

## 土地とイベントのゲート

明示的な確定年代記の `kind:'public-space-established'` と `publicSpaceId` が一致する場合に限り審査する。独立した `appendConfirmedPublicSpace` は正本を純粋に追記するだけで、**自然進行エンジンからは呼び出さない**。

- 既存の `hall`（assembly-ground）または `market`（market-yard）が実在して使用可能で、対象の空地から遠すぎないこと
- 住宅履歴が確認可能な河畔のみ。丘陵・入り江、追跡不明の旧セーブはHOLD
- 新しい公共空地自体と、住宅街区（廃墟も含む）、確定施設、川、将来の固定施設11区画が**重ならない**こと
- 既存公共空地の重複ID・物理敷地重複を拒否すること
- `appendConfirmedPublicSpaceUse` では成立年・敷地・用途・出典・施設アンカーを保持したまま、記録済みの荒廃／再利用イベントのときだけ状態を変える
- 新設で `clear` が出ても**自然進行による設置承認ではない**。共同体の慣習、人数、資材、候補年の計算は別のHumanゲートで確定する

## 互換性・将来の建設

- `CivilizationState.publicSpaces?: PublicSpaceHistory` は**任意**。旧v2/v3/v4データへの架空の遡及補完、セーブキー変更・バージョン変更は行わない。
- 新しい台帳を持つ場合は、`housing-save.ts` の保存前・読み込み時に全イベントの年次順、厳密な状態遷移、出典記録の一致、歴史的敷地と施設の整合性、確定後の住宅・施設の衝突を検査。
- `housing-progression.ts`、`civic-progression.ts`、`engine.ts` は**既に確定した**公共空地の敷地を後発の住宅・固定施設・大型会堂の候補から除外する。**公共空地そのものは自動建設しない**。
- `snapshotAt` は当年の記録にある空地だけを渡し、`drawScene` はその実敷地内に土色の共同利用面、または放棄後の草地を描く。空地が存在しない文明では景観は変わらない。
- 描画の優先順位は **史実として確定した公共空地 > 旧D2/D6の推測的な踏み跡・前庭**。公共空地に重なる小さな旧描画はスキップし、形式の異なる土地利用を二重描画しない。
- 確定した建設年以前には一切表示しない。既存のD2/D6の「推測された踏み跡」は正式道路や共同空地に自動昇格させない。
