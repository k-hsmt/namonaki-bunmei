## 1. 試作の厳密な境界

- **現行の`drawArchitecture()`・`drawRuin()`と建築語彙を使用**し、建物の幅・用途・基礎・元の輪郭を確認できる。この試作で新しい建築史、建材、文明、土地占有を生成しない。
- **現行世界を進行させていない**。建築史・植生史・地形史・#34長期気候・セーブデータは読み書きしない。
- 気候の分類は`generateClimateBaseline()`が実際のseedから導いたもの。各バイオームの背景空・地表は**比較専用の描画舞台**であり、実際に生成された地形・生育個体・地表材ではない。
- **放棄後100年で`ruined`になるという仮想イベントを試作上で明示**する。これは文明の自動遷移規則ではない。放棄直後・50年は`vacant`、200・500年は`ruined`の描画。建築の状態は指定 fixture として固定し、年齢だけで実際の建物の物理状態を自動変更しない。
- 苔・蔦は**表面画素の描画**だけ。適合する気候・材料・露出期間で違いを試す。蔦の根元の実在証明、#47植生パッチや地形アクセスとの接続は**D1b**で行う。この段階の根元条件は比較専用代理条件で、確定した蔦個体の歴史とみなさない。
- 風化マスクの色・欠損は**絵の中だけ**。確定した建物ID、建設年、敷地、道路、建築可能性、過去の本編セーブに影響しない。
- 再利用・修繕と部分補修の再現、#36積雪、実地形への苔・蔦の侵入はD1b以降に保留。描画の見た目による受入と、年次モデルの受入を混同しない。

## 2. 比較マトリクス

| 軸 | 条件 |
| --- | --- |
| 経過年数 | 放棄直後・50年・200年・500年 |
| 建材 | 木板・木造（S02）、土壁（S03）、石造（S05）、木石混合（S06） |
| 気候 | 砂漠、ステップ、草原、温帯林、熱帯雨林、亜寒帯林、ツンドラ |
| 画像 | 7×4×4＝**112枚**、各320×180px、ピクセル補間なし |

- 全画像で同一の比較用建築用途（会堂）・中心座標・寸法を用いる。**木造・土壁・石造などの正規構造規則により屋根と基礎の形状に差は生じる**。
- 背景にはバイオームを理解するための静的な色味と少数の植生風目印を使う。人物・草は雰囲気の参照であり、文明史上の住人・実際の植生記録ではない。
- ピクセル比較は最小二つの方法で記録する：建物の可視画素数、苔／蔦の塗り画素数。色や視認性のHuman評価の代わりではない。
- `report.json`には素材ごとの建築正規形、各seedの気候指標、表示の仮パラメータ、PNGのSHA256と試作範囲の制約を記録。

## 3. 試作の期待と限界

### 風化
- **0年**では既存の`drawArchitecture()`と画素単位で一致（制御試作の初期条件で余計な加工を加えない）。
- **50年**では、建物を空き家として維持しながら色褪せ・微細な欠け・気候に応じた苔を描く。
- **200年**では、明示的な仮想`ruined`イベントを経た状態として既存の`drawRuin()`の欠損輪郭を土台に描く。
- **500年**では、さらに欠損と表面被覆が進む。ただし建物の存在・敷地の権限は描画で変化しない。

### 苔・蔦
- 苔は湿潤度・温度・材料と露出期間の関数で、既存の建築画素上にのみ描く。
- 蔦は湿潤で比較的温暖な条件を優先し、建築の残存画素の上に限定する。根元がない場所に実際の植生個体を発生させることは**この試作では検証していない**。
- 生育条件が合わない砂漠で不必要な緑化が起きないことを比較する。
- 現状の単純な経年彩度・風化の値は**D1用の仮値**。このままD2の本編パラメータに採用しない。

## 4. 自動検証

- 4素材を`normalizeSpec()`で正規化し、建築描画の0年の完全一致をテスト。
- 0年は苔・蔦の付着を発生させない。
- 明示的に確定した（仮想）廃墟イベント以前は空き家、以後は廃墟に見える。
- 同一seed・建材・年月では全画像が決定的で、`Math.random()`を使用しない。
- 砂漠相当の乾燥条件で苔・蔦が抑制される。
- 長期段階へ進むと建物の可視画素が増えず、建物が意図せず再生されない。
- 7バイオームの自然seedから全112画像が出る。原寸が常に320×180。
- SHA256、由来seed、試作制約をレポートに記載。

## 5. Humanレビューで判断したいこと

1. **長期の風化強度**：50年→200年→500年の変化は自然か。元の建築様式をどこまで読み取れるか。
2. **建材差**：木・土・石・混合で違いが十分にあるか。特に石積みが残る景観と木材の崩れ方。
3. **苔の被覆**：熱帯雨林・温帯林で「緑の汚れ」ではなく湿潤な表面として読めるか。石目地・木材で密度が不自然でないか。
4. **蔦の伸長**：壁を這う表現として成立しているか。建築部品から不自然に浮いていないか。
5. **原寸の見え方**：320×180で時間の蓄積が読み取れるか。表面被覆が遺構の形を過度に消していないか。

**Humanが採否を決めるまではDraftのまま停止する。D1aの景観が未承認でもD1bの安全な土地アクセス規則を本編に接続しない。**
