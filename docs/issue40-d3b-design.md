## 1. 正本と、交易の実態（実装前の調査）

| 事実 | 正本 | 交易系統が読むもの |
|---|---|---|
| ルートの途絶・その年の交易の有無・共同維持 | 地域経済（`s.economy.routes`：`blocked`、直近20年の`tradeYears`、`agreementRecord`） | 確定した年の値 |
| 途絶・共同維持の成立・共同管理の休止 | 地域経済の記録（年代記の「地域」） | 記録 |
| 地区の充足率・不足の継続年数 | 地域経済（`s.economy.districts`） | 確定した年の値 |
| 共同備蓄の慣習 | 集落台帳の慣習（成立の記録） | 記録 |

調べた事実（6世界×5000年、エピソードなし）：

- ルートは2本で、どちらも川辺を通る（川辺–丘陵、川辺–入り江）。
- 途絶は、川辺の洪水で起きる。洪水の間（試走ではいつも3年）だけ続き、必ず開き直す。2本が同時に途絶える。世界あたり7〜18回。
- 交易は、地区の不足を埋めるときだけ起きる。ルートごとに5000年のうち17〜22%の年。交易のない年は、需要がないことが多い。
- 共同維持の成立は世界あたり0〜2回。成立した共同維持は、5〜90年で休止する。
- 「断絶が定着した」と言える記録・状態はない。

D0 §4.2の「ルートの状態と交易量を区別。交易ゼロだけで断絶と判断しない」に従い、交易のない年だけを根拠に、エピソードを始めない・広げない・終えない。

- エピソードは、上の正本を複製しない。効果も持たない（D0 §3）。容量・維持費・移住は既存の年次処理だけが決める。
- 経験が将来の行動の重みに影響する経路は、D3bでは加えない（D3e・D4c）。

## 2. 経過の規則（`src/story/episode-trade-d3b-review.ts`）

| 遷移 | 条件（その年に確定した事実） | 根拠 |
|---|---|---|
| started（途絶） | 直近20年に交易のあったルートが途絶えた | 途絶の記録 |
| started（休止） | 共同管理が休止した | 休止の記録 |
| started（共同維持） | ルートが共同維持に入った（長く続いた交易の記録） | 共同維持の記録 |
| reassessed：route-closed | 活動中に、関わるルート、または直近20年に交易のあったルートが途絶えた | 途絶の記録 |
| reassessed：upkeep-lapsed | 活動中に、共同管理が休止した（進行中の共同維持の対応のルート以外） | 休止の記録 |
| reassessed：route-reopened | 途絶の後、関わるルートがすべて開いた | 経済の台帳 |
| reassessed：trade-resumed | 開いた（または休止した）後に、関わるルートすべてで交易があった | 経済の台帳 |
| resolved：relation-stable | 交易の再開から20年、途絶・休止がなく、関わるルートすべてで直近20年に交易がある | 経済の台帳 |
| response-started／response-changed | 前回の対応の変化より後に、対応の記録がある（下表） | その記録 |
| response-failed：upkeep-lapsed | 進行中の共同維持の対応のルートで、共同管理が休止した | 休止の記録と、対応の記録 |
| response-failed：supply-still-short | 別の供給手段が15年続き、関わる地区がなお15年連続で不足 | 対応の記録と経済の台帳 |
| resolved：supply-converted | 別の供給手段が進行中、関わるルートで20年交易がなく、両端の地区で直近5年の充足率が0.90以上 | 対応の記録と経済の台帳 |
| abandoned：no-response-after-failure | 失敗の後、別の対応がないまま50年、交易は再開していない | 経済の台帳 |

- 関わるルート：途絶・休止・共同維持の記録のルート（広がると加わる）。関わる地区は、その両端。
- 1年に1遷移。優先順は、途絶→休止→開き直し→交易の再開→終結→対応→失敗→転換→断念。
- 途絶は、直近20年に交易がなかったルートでは起点にしない。交易のない関係は、途絶で失われるものがない。
- 開いたルートで交易がない間は、エピソードは開いたまま続く。交易のない年だけで終結・断念にしない。
- 共同維持から始まったエピソードでは、その共同維持そのものが維持の試み（対応）。翌年に`response-started:joint-upkeep`として同じ記録を引く（対応の窓を1年前から開く）。
- 無対処も成立する。途絶→開き直し→再開→安定は、対応がなくても起きる。

### 2.1 対応の種類

| 対応 | 記録 | 意味 |
|---|---|---|
| joint-upkeep | 関わるルートが共同維持に入った記録 | 関係を保つ試み（容量2倍、双方が維持費を負担） |
| alternative-route | 関わる地区に接する、別のルートが共同維持に入った記録 | 別の供給手段（実際の変化。動機は主張しない） |
| local-storage | 関わる地区で、共同備蓄の慣習が根づいた記録 | 別の供給手段（実際の変化。動機は主張しない） |

- 同じ年に複数ある場合の優先順：共同維持→別ルート→備蓄。
- 対応中に、同じ種類の記録が出ても始め直さない。別の種類なら方針変更。
- 選択（D2b）は交易の対応にしない。D2bの分岐には、ルートの記録を出典にするものがない（「来訪者」の`trade-only`は来訪の記録を出典にしている）。

### 2.2 実装しないもの

- 断絶の定着（D0の終結の候補）：地域経済では、途絶は洪水の間だけ続いて必ず開き直す。関係が失われたことを示す記録もない。交易のない年だけでは根拠にならない（D0 §4.2）。そのため、断絶を終わり方として作らない。試走ではN/Aとして扱う。
- 依存（D0の発生の候補）：地区の輸入の割合（`importShare`）はあるが、依存を記録したものがない。エピソードは記録から始める（D2cの規則）ため、起点にしない。

## 3. 独立の照合（`scripts/lib/history40-trade.mjs`）

定義とは別に書いた照合で、すべての遷移の主張を出典に照らす。照合に使うのは、年代記と、毎年捕捉した経済（ルートごとの交易と途絶、地区ごとの充足率と不足の継続年数）。

- 開始・途絶・休止：その年の、その種類の記録であること。途絶なら、そのルートで直近20年に交易があったこと。
- 開き直し：途絶の状態にあったことと、その年に関わるルートが途絶えていないこと。
- 交易の再開：開いた年からその年まで、関わるルートすべてで交易があったこと。
- 安定：再開から20年以上で、直近20年に関わるルートすべてで交易があったこと。
- 対応：記録が前回の対応より新しく、ルート・地区が合っていること。
- 失敗：休止なら、進行中の共同維持のルートの休止と、その対応の記録。不足なら、15年以上の対応と、15年以上の不足。
- 転換：別の供給手段が進行中で、20年交易がなく、5年間の充足率。
- 断念：失敗から50年以上、その間に対応がなく、交易が再開していない。

## 5. テスト（`tests/episode-trade-d3b.test.mjs`、5件）

- 照合と定義で、閾値が同じ。
- 実世界（seed 23、900年）：途絶・開き直し・再開・安定・別の供給手段（備蓄）・その失敗が起きる。対応なしで安定するエピソードがある。開いたルートで69年交易がない間、エピソードは開いたまま続く（終えない）。全体の検査と、独立の照合が合格する。
- 実世界（seed 20、700年）：共同維持から始まり、それが対応になり、その休止が失敗になる。
- 照合は、出典が支えない主張（開き直しの年に途絶えている、再開までの交易をなくす、失敗の年の不足をなくす、途絶の前20年の交易をなくす）を検出する。
- エピソードなしの世界と、文明・建築台帳が一致する（効果なし）。
