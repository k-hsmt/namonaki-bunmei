**仕組み**：

- **育ち**：その年の#34のパッチの記録（最後に切り開かれてからの年数）を使う。#34はすでに建物・畑・火災・放棄・灌漑の水路・整地のすべてを反映し、建物の下では育たない。
- **上限**：植物群がその気候で保てる最も発達した段階。初期気候＋その年の#34の長期偏差（湿度・気温の半分を足す）＋局所環境（河畔・湿地は水があるので、気候がどれだけ乾いていても一定以上に湿る）＋B2bの定着しやすさで決める。系統ごとに耐えられる有効気温・有効水分の範囲を持つ（`TOLERANCE`）。パッチごとに範囲の端を0〜6ポイントずらし、景観全体が一斉に切り替わらないようにした。
- **衰退**：上限が下がっても25年はその段階を保ち、以後25年ごとに1段階ずつ下がる。別の樹種に急に変わることはなく、回復は育ち直しでだけ起きる。
- 過去の年の湿度・気温は、#34のチェックポイントから#34と同じ規則で再現する（実際の世界で#34の値と完全一致することをテスト）。

**計画からの変更**：100年ごとの状態を保存する予定だったが、**保存しない**ことにした。植物の段階は、世界がすでに記録しているもの（seed・気候・植物群・#34の記録）だけから毎回同じ結果に決まるため。保存する必要がなく、保存と再計算が食い違う心配もない。計算は1地区あたり1〜4ms。**保存形式の変更はない**。

**植物の決め方**：

- 若い林（段階3）・成熟林（段階4）のパッチだけが、その植物群の高木を若木／成木で描ける。低木（段階2）はその植物群の低木、草（段階1）は草本。林の下（段階3以上で木を置かなかったパッチ）は低木か草本。
- 本数の上限はB1bの値（バイオームごと。森林は「密」で高木×3、間隔10px、建物から6/8px）。移行帯の世界では、地区の陸のパッチのバイオームの割合で上限を按分する。

- 描画器A/Bは植物ごとに固定ハッシュで約半々（Aの下層植生は0.6倍）。地表色はパッチのバイオームごと（B1bの色）。

**描画の順序**：地形・地表 → 地表色 → 雲・水の動き → 建物より奥の植物 → 人 → 建物の層（本編の順序のまま）→ 建物より手前の植物。手前の層には「建物の画素の上にあり、根元のyがその建物の接地線より大きい」植物の画素だけを入れる（同じなら建物が手前）。建物に重ならない植物は奥の層に入るので、人を隠さない。静止画は木が止まった状態で、同じ順序で描く。

**動き**：動きのある表示では、高木の樹冠（根元から見える高さの40%より上）が以前の木と同じ周期で左右に1px揺れる（Human決定 2026-11-12）。下層植生は揺れない。揺れた姿ごとに前後判定をやり直すので、揺れても建物との前後は崩れない。歩く人は新しい植物の根元を避けない（Human了承）。

| 動きのある表示の1フレーム（平均） | 0.1ms前後 | 0.01〜2.3ms |

準備で増えた分の大半は植物の配置（2〜8ms）と接地線の図（1〜37ms、建物と屋根の数に比例）。1フレームの増加は揺れた姿の植物の層の作り直し（表示は毎秒12フレーム）。**予算**（Human了承）：1地区の準備で150ms以内、1フレームの植物の処理で5ms以内。

- **遠景**（Humanレビュー 2026-11-13）：山すその平地・山並み・中景の丘は、どのバイオームでも同じ固定の色だったため、手前の地面と合わなかった。地平線から24px以内の陸の実際の平均色に空の色を混ぜた色（霞：平地62%、最も遠い山並み42%、手前の山並み30%、中景の丘12%）へ55%寄せる。元の色を45%残すので、山並みの重なりと#34の気候による山の色の変化は残る。雪はそのまま。中景の丘にだけ、その地区で最も多いバイオームの地表材の粒（3.5%）を入れる。最初に試した「地表色を遠景の明るさへ引き伸ばす」方式は、森林で遠景が明るい黄緑になったため採用しなかった。
- 描画時間は1地区あたり約3ms（年・地区を切り替えたときの準備だけ）。B2dの予算内。

**地表材の分布**（各バイオームの代表seedで最も多いもの）：砂漠＝砂、ステップ・草原＝裸土、温帯林・亜寒帯林＝落葉、熱帯雨林＝湿った土、ツンドラ＝寒冷地表。河畔・湿地は湿った土、岩場は岩、海岸は砂（B2bの規則）。**ステップと草原、温帯林と亜寒帯林は地表材が同じ**で、地表では色だけが違う（植物の形で区別される）。

**保存形式・歴史への影響**：なし。v10の世界の地表の見た目が変わる。

## 4. 各段階の受け入れ条件

**B2a**
- 同じseedは同じ気候。B1cの試作とseed 1〜1000で値が一致。
- 気候を持つ世界と持たない世界（同じseed）で、文明の歴史・文明RNGの状態・保存されたv9部分が一致する（気候は文明に作用しない）。
- 保存→復元→同一操作で一致。改変した気候・未知のruleId・v9は拒否。

**B2b**
- 水域・建物の敷地に植物群を置かない。海水を淡水として扱わない（河畔は淡水の近くだけ）。
- 移行帯の世界では、隣のバイオームの植物群が一部のパッチに混ざる。
- 同じseedで同じ初期植物群。作り直しと保存値の不一致は拒否。

**B2c**
- 砂漠・ツンドラは長期の無攪乱でも一律に成熟林にならない。
- 長期の乾燥化・湿潤化は、ストレス・成長・世代交代を通じて**徐々に**植生へ作用し、翌年に急に別の樹種へ変わらない。
- 灌漑・経済の結果（湿度・土壌負債・経済効果）がB2c導入前と一致する。
- 分割／一括進行・保存再開・過去観測で植物状態が一致する。

**B2d**
- B1bで決めた見た目（D・森林「密」・Y座標の前後判定）が本編で再現される。
- 描画が文明の乱数・歴史を変えない。描画時間の予算をB2dで測って固定する。

**B2d2**
- 同じ地形で7つの気候を比べたとき、地表が色だけでなく素材の模様でも区別できる（設計書§10「地表」）。
- 描画が文明の乱数・歴史を変えない。B2dの描画時間の予算に収まる。

**B2e**
- 設計書§10の受け入れ条件をすべて確認する。
