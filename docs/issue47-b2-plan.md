**Human決定**：バイオームの文明（収穫・人口）への影響は別のIssueで扱う。#47は見た目だけとし、B2cは「#34の数値を変えず、植物専用の層を別に作る」案（案2）で進める。

| 変更 | 内容 |

| `src/story/world-session.ts` | `worldFloraAt(session, year, siteIndex)`：B2dの描画が使う入口 |

**仕組み**：

- **育ち**：その年の#34のパッチの記録（最後に切り開かれてからの年数）を使う。#34はすでに建物・畑・火災・放棄・灌漑の水路・整地のすべてを反映し、建物の下では育たない。
- **上限**：植物群がその気候で保てる最も発達した段階。初期気候＋その年の#34の長期偏差（湿度・気温の半分を足す）＋局所環境（河畔・湿地は水があるので、気候がどれだけ乾いていても一定以上に湿る）＋B2bの定着しやすさで決める。系統ごとに耐えられる有効気温・有効水分の範囲を持つ（`TOLERANCE`）。パッチごとに範囲の端を0〜6ポイントずらし、景観全体が一斉に切り替わらないようにした。
- **衰退**：上限が下がっても25年はその段階を保ち、以後25年ごとに1段階ずつ下がる。別の樹種に急に変わることはなく、回復は育ち直しでだけ起きる。
- 過去の年の湿度・気温は、#34のチェックポイントから#34と同じ規則で再現する（実際の世界で#34の値と完全一致することをテスト）。

**計画からの変更**：100年ごとの状態を保存する予定だったが、**保存しない**ことにした。植物の段階は、世界がすでに記録しているもの（seed・気候・植物群・#34の記録）だけから毎回同じ結果に決まるため。保存する必要がなく、保存と再計算が食い違う心配もない。計算は1地区あたり1〜4ms。**保存形式の変更はない**。

**長期の様子**（3地区の合計。裸地/草/低木/若い林/成熟林の%）：

| 気候 | 年0 | 年1000 | 年2000 |

| ツンドラ | 25/51/24/0/0 | 8/1/91/0/0 | 32/2/66/0/0 |
| ステップ | 26/50/23/1/0 | 17/0/78/0/4 | 33/0/62/0/4 |

**植物の決め方**：

**描画の順序**：地形・地表 → 地表色 → 建物より奥の植物 → 雲・人 → 建物の層（本編の順序のまま）→ 建物より手前の植物。手前の層には「建物の画素の上にあり、根元のyがその建物の接地線より大きい」植物の画素だけを入れる（同じなら建物が手前）。建物に重ならない植物は奥の層に入るので、人を隠さない。

**動き**：新しい植物は揺れない（B1bの絵をそのまま使うため）。歩く人は、以前の木の根元を避けていたが、新しい植物の根元は避けない。

**描画時間**（ヘッドレスChromium、1地区。中央値）：静止画 30〜73ms → 46〜91ms、動きのある表示の準備 41〜84ms → 50〜104ms。増えた分の大半は植物の配置（2〜8ms）と接地線の図（1〜37ms、建物と屋根の数に比例）。動きのある表示の毎フレームの追加は、手前の植物の層を1枚重ねるだけ。**予算**：1地区の準備で150ms以内（年や地区を切り替えたときだけ。毎フレームではない）。

**保存形式・歴史への影響**：なし。描画だけの変更で、文明の乱数・歴史・保存値を読むだけ。v10の世界の見た目は変わる。v10以外の世界（固定世界・旧形式の閲覧）は変わらない。
