## 2. 調査で確認した現状（2026-11-12時点のmain）

- 新しい世界は `createNewArchitectureWorld`（v9）。v9の保存は、v8の世界一式（地形・植生 #32・環境 #34・灌漑・経済）と建築台帳を包む。
- 植生 #32（`src/vegetation/history-v1.ts`）は3地区×440個の8×8パッチに、初期の［齢・成長速度・最大段階］を持つ。環境 #34（`src/environment/`）は100年ごとの湿度・気温の**相対偏差**と、パッチごとの［成長単位・ストレス・土壌負債・利用時計］を年次で進める。
- 文明側（人口・経済・建設・集落配置）は植物の**成長（齢・段階）を読まない**。経済が読むのは湿度・水辺補正・土壌負債だけ。→ 植物の成長則を気候で変えても文明の歴史は変わらない。
- 本編の植生描画は `landscape-v3`（`src/environment/landscape-v3.ts` と `src/scene/draw-generated-review.ts`）。

## 4. 各段階の受け入れ条件

**B2a**
- 同じseedは同じ気候。B1cの試作とseed 1〜1000で値が一致。
- 気候を持つ世界と持たない世界（同じseed）で、文明の歴史・文明RNGの状態・保存されたv9部分が一致する（気候は文明に作用しない）。
- 保存→復元→同一操作で一致。改変した気候・未知のruleId・v9は拒否。

**B2b**
- 水域・建物の敷地に植物群を置かない。海水を淡水として扱わない（河畔は淡水の近くだけ）。
- 移行帯の世界では、隣のバイオームの植物群が一部のパッチに混ざる。
- 同じseedで同じ初期植物群。作り直しと保存値の不一致は拒否。

**B2c**
- 砂漠・ツンドラは長期の無攪乱でも一律に成熟林にならない。
- 長期の乾燥化・湿潤化は、ストレス・成長・世代交代を通じて**徐々に**植生へ作用し、翌年に急に別の樹種へ変わらない。
- 灌漑・経済の結果（湿度・土壌負債・経済効果）がB2c導入前と一致する。
- 分割／一括進行・保存再開・過去観測で植物状態が一致する。

**B2d**
- B1bで決めた見た目（D・森林「密」・Y座標の前後判定）が本編で再現される。
- 描画が文明の乱数・歴史を変えない。描画時間の予算をB2dで測って固定する。

**B2e**
- 設計書§10の受け入れ条件をすべて確認する。
