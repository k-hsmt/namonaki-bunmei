# Issue #31 D3-B共同空地段階

前提：#56の大型公共建築3地点対応。状態：**通常施設・civic・住宅・共同空地を統合した独立試走。実ゲームCanvas・正式v5保存は未接続**。
旧ゲームは固定地形・従来進行を維持する。今回の追加でIssue #31の完了や本編公開を宣言しない。

## 実装と確定順

`generated-public-space-review.ts`は通常施設→civic→住宅建設→住宅状態更新→共同空地の順で、各段階内を川辺・丘陵・入り江の順に判定する。
前段階で確定した全占有を後段階で参照し、既存の共同空地も通常施設・civic・住宅の候補から保護する。
共同空地の利用が失われても、過繁茂でも敷地を解放しない。撤去や移設機能は追加しない。

種類は既存のassembly-groundだけ。新しい市場の土間や様式・演出は作らない。
既存の20年周期、16年間続く同一起源の寄り合いと健全な通常hall、人口900以上、直近5年のcoverage≥.92、不足0年、利用中住宅の条件を維持する。
24×10の候補をhallの南・側面に置き、2px格子、幅2px以上の通り口、同じ共通地表と占有・予約・通行ゲートで検査する。
南側候補は2px格子へ切り上げるため、hallと3pxの隙間になる場合がある。北側の裏庭は選ばない。
斜面・水面を無視した敷地や、屋根の外接矩形を敷地として使わない。

通路の2×2窓グラフ上でhall・核へ接続し、利用中住宅の入口までの最短通路が80px以内であることを要求する。
スコアは核・hallへの通路距離、水際・手前の補正、独立hashで評価する。
未建設の予備地を実在建物や通行障害とみなさず、Q5の3方式を明示的に比較できる状態を維持する。

成立後は、同じ不成立条件が8年続いた場合だけ過繁茂へ遷移する。
寄り合い喪失、hall利用不能、利用中住宅なし、長期不足の条件と優先順は既存のものを使う。
再利用には寄り合い・hallの16年継続と維持余力・近隣住宅を要求し、敷地・成立年・anchor・初回出典は変えない。
現在の条件が有効なら「過去8年すべてが不成立」にはならないことを利用し、不必要な過去再生を避ける。

## 履歴・互換・検証

PublicSpaceの地点型を3地点へ広げたが、既定の`validatePublicSpace`と`publicSpacesAt`はlegacy-fixedのまま。
旧v4入力で丘陵・海岸の空地を黙って受け入れない。生成試走だけが明示モードを渡す。
生成モードの空地同士は同じ地区内でのみ重複を検査し、別地区の同じ画面座標を衝突とみなさない。

IDは`public-SITE-assembly-YEAR`。同年の地区別イベントは単調で一意なseqを持つ。
成立・過繁茂・再利用の年代記出典IDと年・空地IDを照合し、全遷移の不変属性を検査する。
生成空地は24×10・2px格子に固定し、成立年の保存済み地形・施設・住宅・先行空地・予約を再構築して敷地と通り口を検査する。
現在年のcivic台帳も併せて検査し、未確定年のイベントを拒否する。
過去の観測では後年の施設・住宅・空地を占有へ混入させない。

この検証は土地利用台帳の検査であり、v5の未知JSON全体・localStorage保存UIを実装したものではない。
試走stateを旧v4キーへ保存しない。
トランザクション内の不変な生成住宅史だけで既存の検査済みviewを再利用する。公開提案関数の既定readerと旧読込は従来どおり履歴を検査する。

## 結果と限界

- 寄り合いが41年から失われた場合、47年には変化せず48年に過繁茂。49年から回復した場合、64年は再利用不可、65年には同じ敷地を再利用できることを検査した。
- 別地区で画面座標が同じでも成立でき、履歴途中の敷地改変は拒否する。
- 500年の一括と250＋250年の継続が全状態で一致し、年0の空地観測は不変。
- 自然進行のseed42・畑のみ予約・2,000年は空地0。社会条件・土地不足のHOLDを記録した。
