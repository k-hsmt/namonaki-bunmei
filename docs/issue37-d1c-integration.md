## 3. 検査と性能

| 検査 | 結果 |
|---|---|
| 本編のpainterの描画が`drawWorldSession`と同じ（本編は不変） | 4世界×2件すべて一致 |
| 開発用painterで風化・植物を両方切ると本編と同じ | すべて一致 |
| D1cを新しいpainterで描き直すと同じ画素 | すべて一致 |
| 1枚あたりの描画時間（ブラウザ、平均） | 本編 90〜118ms → D1c 103〜131ms（約+5〜14％） |

最初の版は1枚739ms（本編の約5倍）だった。原因は（1）局所植物の候補を地区全体の格子で毎回ハッシュしていたこと、（2）本編が建物を何度も描き直す（構造の層、地面線の判定、雪の判定）たびに風化を計算し直していたこと。（1）は`src`側で区域の外接矩形に絞り、（2）は開発用painterで同じ建物・同じ時計の結果を再利用して解消した。**（2）の再利用はD1cの開発用コードにしかない。D2で本編に接続するときは同等のキャッシュが要る。**

単体テスト618件はすべて成功。ブラウザテストの結果は§6に追記する。

## 4. 画像を見た所感（事実と評価）

- **事実**：実際の世界では、町が衰えると**地区の街区・施設がほぼ同時に空き家・廃墟になる**（seed 6の995年の丘陵では街区6・施設5が同時に開いている）。D1bの局所植物は地区全体に広がり、100年後には町の跡が若木と低木に覆われる。
- **事実**：本編の廃墟は何百年たっても同じ姿だが、D1cでは廃墟化の年に壁の高い廃墟が現れ、数十年で本編の輪郭へ、さらに低く崩れる。砂漠では砂に沈み、熱帯雨林では緑に覆われる。
- **事実**：多くのフレームが冬（季節の位相3）に当たり、雪の中で廃墟の差が見えにくい（25年ごとの季節が年に従って決まるため）。季節の4位相の比較は別に描いた。
- **事実**：熱帯雨林の丘陵の施設は、100年後には周りの森で完全に隠れた。D0 §8は自然な遮蔽を許容しており、遺構を見せるための間引きはしていない。
- **評価（未確定）**：町の跡が森に戻る流れは読める。一方、地区全体が一度に回復するので、「生きた街と朽ちた街の共存」（Issue受け入れ条件3）が見えるのは、地区の一部だけが放棄された時期に限られる。

## 5. Humanに判断してほしいこと

1. **統合した見た目**：実際の世界で、廃墟の段階的な変化と植物の回帰が自然に見えるか。
2. **遮蔽**：熱帯雨林などで遺構が森に完全に隠れることを、このまま許容するか（D0の決定どおりなら変更なし）。
3. **D2へ進むか**：D0 §11のD2は「版付きの風化と苔・蔦を本編の建築描画に接続する」。D2では本編の廃墟の見た目が変わり（廃墟化直後が高くなる、基礎が残る、風化・苔・蔦・砂が付く）、性能のためのキャッシュを本編側に入れる。植物の回帰（D1b）の本編接続はD3。
