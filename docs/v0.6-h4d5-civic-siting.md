# v0.6 H4-D5｜大型公共建築の立地選定と街並みの中心性

**対象：H4-D4-B/Cで実装した自然建設の「土地の探し方」を改善する。**
**非対象：新しい城・館・政庁の建設、住宅の移設、既存建物の描画様式変更、地形編集。**

## 問題と観察

H4-D4-B/C（PR #28）の自然進行3例では、seed7/42/82でそれぞれ中庭・会堂・中庭という建物の違いは成立したが、**すべて画面左手前の同じ敷地**へ建設された。候補リストの先頭付近の合法敷地が繰り返し採用され、「町の中心になる建築」が街並みではなく孤立した前景の大型建物に見えた。

そのため、この工程では建築物のサイズをさらに大きくするのではなく、**その文明が実際にどの施設を持ち、住宅をどこに築いてきたか**に基づいて場所を選ぶ。

## 実装設計

- 地形検証がある**河畔のみ**対象。丘陵・入り江、城・館は引き続きHOLD。
- 建設時の新規提案のみ変更。現存する大型建築の座標、敷地、建設年、ID、建築様式の正本は不変。過去セーブの既存建築を遡及再配置しない。
- 左右の岸を含む地表候補を格子状に列挙。候補は実占有の44×22px／56×30pxを確保でき、Canvas原寸の地面上に収まるものに限定する。
- すべての候補について既存の `reviewCivicConstruction()` による**河川・住宅・施設・建設イベントの合法性**を検査。不可なら採用しない。
- 合法候補の中で、既存の集会所と実在する住宅街区への距離、前景へ出すぎない奥行き、および同程度の候補の安定したseed差を使って順位付けする。
- 幻の施設や規模分類、表示中の画角による補正を使わない。同じseed・年・確定履歴からは同じ座標を選ぶ。失敗した場合は `no-safe-plot` でHOLDし、無断の取り壊し・埋立て・移設を行わない。
- 仮に**同じ敷地が唯一の合法候補**なら、人工的に多様性を演出するために不法敷地を選ばない。「3文明で必ず違う位置にする」ことそのものは生産ロジックの条件にしない。

## 検証

- `tests/h4d4bc-natural-civic.test.mjs`：従来の「全候補の地表が占有済みならHOLD」を新グリッドに合わせて更新。
- `tests/h4d5-civic-site-selection.test.mjs`：seed7/42/82を自然進行2,000年、1,000年で保存・再開し、建設年の土地占有・古い歴史・決定性・場所の選択を確認する。場所が全件同一なら自動検証を停止し、独立した敷地調査に戻る。
- 出典：CI `h4d5-natural-placement` の `natural-placement.json`。設計上の候補座標と、**自然に建築された確定敷地**を混同しない。
- 既存のH4-D4-C Playwrightにより、更新された自然進行による建設前年・建設年・1000年・2000年を320×180原寸と4倍で再生成。mainのPR #28アーティファクトをBeforeとして比較。
- 現時点では街路形成・都市の景観密度の再設計はしない。Humanレビューで「共同体の中心に見えるか」「川と屋根の重なりが自然か」を評価してから後続工程を決める。

## 既存の保存との境界

建設済み建物は、確定履歴に保存された敷地・座標をそのまま使い、実行時に今回の候補選定をやり直さない。未建設の既存v4保存は**今後の進行で**新しい選定方式が適用される場合があるが、保存済みの年と観測履歴は変えない。
