# v0.6 H4-D6｜共同建築と街区の「つながり」を風景にする

**実装：描画限定。** 新施設・道路・橋・広場・町の発展条件・保存形式は追加しない。D4-Cの大型会堂・中庭型共同建築の**確定履歴**を景観の接点に使う。

## 目的と発見

D5では共同施設の立地は自然になったが、3つの文明のうち2つは右手前の似た敷地を選び、「大きな建物だけ孤立して建っている」印象が残る。新たな施設を作らず、既に住んでいる住宅群との物理的な関係を小さな踏み慣らされた地面の表現として示す。

## 新しい表示契約

- 入力は、観測年の `SiteSnapshot.objects` にある確定 `civic` と `composeScene` の住宅街区。
- 建築が実在する年だけ・廃墟でない大型公共建築だけを始点にする。住宅は実際に利用中・低利用で廃墟でも空き家でもない街区だけを接点にする。
- 追跡不明・部分追跡の住宅履歴、丘陵と入り江は今回の歩行痕を **HOLD**。旧セーブの未記録住宅を推測補完しない。
- 共同建築の実占有敷地と住宅の実占有敷地の**外側**に、2px幅の安全な通行候補領域（直線または最大1回のL字屈曲）を検討する。
- 連結は最長68px、近接街区のみ。土地に合法なルートがなければ描かない。1施設につき最短の1接続だけなので、道路網を捏造しない。
- **各線分すべて** `isUnoccupiedGround` で住宅・施設・川との衝突を検査。川を渡る近道や橋のない道、建物を貫通する描画はしない。
- 実際の歩行痕は連続線にせず、**幅2px以内の短く途切れた色**を置く。縦の帯が柵や柱のように見えないようにする。\n- さらに、実在する大型共同建築の敷地の**外縁だけ**を、小さい土色の区画に分けて描く（`civic-margin`）。地表・施設・住宅・川と衝突する区画は必ず省く。道路や公共広場の確定履歴を作るものではない。\n- 絵は「生活者の足が触れたかもしれない地面の質感」を表し、**確定した道路建設・往来の史実を意味しない**。建物と住宅が並んでいても、観測史に道路イベントは追加しない。
- 町／都市の分類や人口を入力にしない。ID・敷地・状態・年の既存履歴だけで座標が決まる。休止・無人化した景観に新しい活動を作らない。
- 既存D2の街区間の踏み跡・集会所と市場の前庭は変更せず、`projectStreetscape` に `civic-approach` を追加するだけ。描画順も住宅の屋根より奥に保ち、市場・橋の絵を隠さない。

## 実装と検証

- `src/scene/civic-approach.ts`：独立した純粋な経路・安全投影と既存施設の地面の外縁投影。入力を変更せず、同年同履歴で同じ結果。
- `src/scene/streetscape.ts`：既存の投影へ統合。
- `src/scene/draw.ts`：安全判定済みの2px領域内に、短く途切れた2px以内の地面模様と、実在施設の敷地外縁の土色区画を描く。路面や公共施設そのものではない。
- `tests/h4d6-civic-approach.test.mjs`：施設／住宅が存在するケース、欠損・廃墟・空き家・追跡不明・別地点・長距離・河川のHOLD、実自然seed 7/42/82の建設前と建設年・保存再開を検証。
- `tests/browser/h4d6-civic-footfall.test.mjs`：実際の自然進行画像を原寸320×180／4倍で生成し、ルートの出典と再描画決定性をアーティファクトに残す。
- CIはH4-A～D5の画像回帰、住宅履歴の10,000年監査、ブラウザの旧保存の回帰を継続する。

## 受入条件と残課題

- 建設前の風景に歩行痕を生やさない。廃墟や空き家に活動的な道を補完しない。
- 川の近道・橋のない川越え・住宅敷地の侵害を描かない。
- 原寸320×180でも集会所と住宅の土地のつながりが分かること。
- 地表の質感だけでは、**「街全体の中心性」の強化は限定的**である可能性がある。路地や公共空間の確定した社会史・構築史が必要なら、別工程で設計する。
- 城・館・政庁は自然建設しない。丘陵・入り江のH3-D HOLD継続。
