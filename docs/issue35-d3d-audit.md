## 4. Human判断が必要なこと

1. **1万年の目安を、記録と建物のどちらで測るか。** 記録なら今のままで満たす。建物なら確率を上げる必要があるが、建設が止まった後の変化は建物に現れないので、確率を上げても届くかは未確認（推測：上げると500年の目安とぶつかりやすい）。
2. **行ったり来たり（19%）を許すか。** 抑えるなら、例えば「最近手放した値は、伝わる変化でもしばらく取り入れない」規則を足す。
3. **川辺への偏り（全体の50%）を許すか。** 川辺だけが2本の交易路の両方につながっている、v8の構造による。
4. **技術の喪失（D3-c）**：建設が止まると技術は失われていく（最後まで持っていたのは7件）。D4の建て替えと合わせて見直すか。
