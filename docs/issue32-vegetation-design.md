# Issue 32 植生の自然遷移

2026-11-07着手。#31はHumanの指示で完了・クローズ。今回は#32の完了を目標に、独立比較から新規世界の描画・保存へ接続する。

## 体験と範囲

8×8pxの小さなパッチを基礎に、裸地→草地→低木→若木→成熟林を年単位で変える。全画面を同時に切り替えず、開始時の齢・成長速度・到達できる段階を混在させる。成長の目安は草8年、低木28年、若木75年、成熟150年。遅い土地は2倍の時間を要する。これらは観察用の仮定で、実測の森林成長モデルではない。

土地条件は保存済みの淡水への距離・斜面・安定した地表を使う。気温・降水量・土壌を推定した値で埋めず、砂漠や熱帯等の初期気候帯は#47、後世の気候・恒久地形改変は#34に残す。水辺から離れた開けた斜面等では低木で止まり、どこも同じ森林へ戻るようにはしない。木材収穫量・人口・施設需要・通行判定にはまだ植生を作用させない。

## 正本と時間

初期の植生条件を地形とは別の版付き記録に保存する。読み込み時に初期植生を再抽選しない。成長は記録された齢と速度から解析的に再構成し、年ごとの全パッチの複製を保存しない。成長計算に文明の乱数列を使わない。

確定した建設・耕作地・共同空地の利用、放棄・再利用、場所を特定できる火災を植生の攪乱記録へ変換する。描画や過去観測から歴史を追加しない。未確定年には進まず、火災の場所が確認できない記録を画面全体の山火事に置き換えない。建物火災の影響範囲は、確認できた建物の敷地の周囲24pxを試作上の局所的な範囲とする。実際の延焼面積を再現した値ではない。部分的な攪乱は該当パッチの回復齢を戻し、周囲へ一斉に伝播させない。

水・岩盤・建物・利用中の畑・共同空地では植物の根元を描かない。放棄された畑では回復を描く。建物と住宅の確定敷地は変更せず、樹冠も建築の輪郭を隠さない密度・余白で表示する。廃墟を森林が全面的に包む表現は#37の別課題。

## 保存と互換性

新規世界から版付きの植生記録を付ける。旧保存は初期植生が不明なので静的な既存描画のまま継続し、過去の森林を捏造しない。地形・施設・住宅・公共空地の既存契約は保持し、生成世界の保存へ任意の植生正本を追加する。植生ありの描画には別renderer IDを使い、未知版・壊れた記録・出典と一致しない攪乱を拒否する。

保存・再開、分割進行と一括進行、選択待ち、過去観測、3地区の切り替えで同じ植生を得る。旧世界の画像と保存を固定検証する。

## 受け入れ

1. 0・30・100・200・300年の自然成長と、伐採→利用→放棄→回復、火災→回復の比較を320×180原寸・4倍で用意する。
2. 同じ履歴でも水辺と開けた斜面で到達段階や回復速度が異なる。
3. 新規世界の建設・火災・放棄と接続し、既存の建物・人口・乱数列・選択結果を変更しない。
4. 保存往復と過去観測、独立タブ、生成器なし読み込み、長期10000年と容量・性能を検証する。
5. 静かな画面と余白を維持し、家屋・水面・橋と植生の根元が衝突しないことを確認する。

進捗と検証結果は後続PRおよび本Issueに記録する。未実装の段階を完了とは扱わない。

互換監査のため、`createNewWorld(seed, policy)` のように旧配置方式を明示した呼び出しは従来の植生なしを既定にする。同じ方式で植生を有効にする検証は第三引数を `true` にする。本編の `createNewWorld(seed)` は植生あり。

## 実装・検証記録

- 正本は `src/vegetation/history-v1.ts`。初期条件は新規生成時だけ `initial-v1.ts` で作り、保存した後は再抽選しない。初期記録の検証済みキャッシュは地形のオブジェクトにも結び付ける。
- 成長は解析的な再構成とし、攪乱だけを出典付きで保存する。初期条件・攪乱を含む `vegetation` と renderer `generated-scene-v2` の対応を検証し、旧保存では植生のないrendererを維持する。
- 木の根元は2×2px全体を検証する。草・低木・木の基部は安定した陸地に置き、木は建物の外形にも余白を取る。木22・低木32を各地区の表示上限とする。これは植生パッチの数や生態系全体の樹木本数を表す値ではない。
- ユニット309件、既存ブラウザ32件、および追加の植生ブラウザ2件が成功。過去・再描画・別タブの画像一致、生成器を読み込まない保存復元、10000年のブラウザ容量、旧キー保持を検証した。
- seed 42・1・21・198を10000年まで自然進行し、植生のない同じ配置方式と文明の完全state・敷地が一致。gzip保存・読み込み後の続き・過去48情景も一致。保存は圧縮後約0.7〜0.8MBで、最終値はCI artifactの `audit.json` を参照。
- 正式性能計測は1回ウォームアップ＋5回計測。seed 42の2000年・10000年、seed 21の2000年で、絶対5秒／25秒と植生なし比2倍以内（分母最低1秒）の両方を検証する。ローカル計測は2000年0.90〜1.04秒、10000年6.26秒、比0.90〜1.02で全条件を満たした。初期化・描画・保存は計測外。
- 比較は自然進行45景観と、伐採／放棄／火災／開けた斜面を明示した独立試走20景観。試走用の攪乱は本番の履歴へ混ぜない。比較・監査・性能結果を `vegetation32-acceptance` artifactに保存する。
