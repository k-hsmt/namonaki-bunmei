## 3. 見つかった問題（Humanの判断が必要）

### 3.1 地形への適応がほとんど効いていなかった（重要。§3.1.1で調整済み）

地区の入力の実測値（千分率、200seed）は次のとおりだった。

| 地区 | 傾斜 | 水 | 崖 | 成熟林 |
|---|---|---|---|---|
| 川辺 | 常に0 | 48〜174（中央値133） | 常に0 | 19〜403 |
| 丘陵 | 26〜184 | 常に0 | ほぼ0（最大478） | 0〜391 |
| 入り江 | 常に0 | 265〜485（中央値354） | ほぼ0（最大111） | 16〜442 |

**「成熟林」の定義（レビューで指摘）**：`forest` は、地区の面積のうち森林が占める割合**ではない**。年0の初期植生パッチのうち、存在するもの（null以外）の中で段階3以上のものの割合である。パッチが少なくても古ければ高い値になる。何を指標にすべきか（面積比か成熟度か）も、下記の調整と合わせてHumanの判断事項とする。

- **傾斜**は丘陵でしか値が出ない。地形の記録が傾斜を丘陵の地区でしか計算していないため（`rasterizeRecordShapes` の `hillGrade`）で、川辺・入り江の傾斜は記録上0である。
- **崖**はほとんどの世界で0。
- 補正は `1000 + 係数×入力` の倍率なので、入力が小さいと効きが弱い。例えば入り江の水354では、高床の重みが約2倍にしかならない。

その結果、地区ごとの選ばれ方はほぼ同じになった。例えば構造S07（高床）は川辺20・丘陵18・入り江24、石積みS04は19・19・20。**3地区の形の違いは確かにあるが、主にハッシュによる偶然から生まれており、「地形と対応した差」（設計書§8 A02）としては弱い。**

対応の候補（調整値の決定はD0 §7.4によりHumanの合意が必要なので、本PRでは変更していない）：
- 案1：係数を大きくする（例：水の係数3→10）。単純だが、入力の幅が地区でそもそも違う（水は入り江で常に大きい）ため、地区の種類で文化がほぼ決まってしまう恐れがある。
- 案2：入力を「3地区の中での順位」や「全世界の分布の中での位置」に正規化してから掛ける。地区の種類の差と、同じ種類の地区どうしの差の両方が出る。
- 案3：地区の変種（river/hills/coast）そのものを入力に加える。設計書§4.1に候補として挙げてあり、記録に存在する値である。

私の推奨は、案2と案3の組み合わせ。D2-cの実世界の画像で、効きすぎていないかを確認する前提である。

**ゲート（PR #113 レビュー P1）**：調整前の時点で、A02の「地形と対応した地区差」は未達だった（調整後の結果は§3.1.1）。D2-bに進む前に、(1) Humanが調整の方針を決め、(2) 200seedで「地形条件→選択の傾向」の**条件付き分布**（例：水の多い地区での高床・木杭の割合と、少ない地区での割合の比較）を再測定し、(3) D2-cで原寸の画像を確認する。「全世界で3地区の形が異なる」件数だけでは合格にしない。

### 3.1.1 調整（Human判断：案2＋案3）と再測定

PR #113 でHumanが案2＋案3を選んだ。実装は次のとおり。

- **案2**：地区の入力を、固定した全世界の参照分布（`src/architecture/adaptation-reference-v1.ts`）の中での位置（千分率）に直してから重みに掛ける。参照分布はseed 1001〜1200の600地区から作った101分位で、監査（seed 1〜200）とは別の標本である。下限に同じ値が多い入力（崖がまったく無い等）は、0のまま留まるようにした（同順位の中央を取らない）。参照分布を作り直すと全ての伝統が変わるので、作り直しはHumanレビューを経る。
- **案3**：地区の種類そのものに相性の表を持たせた。川辺は木造・高床・木杭、丘陵は石積み・整形石・段状基礎、入り江は板壁・高床・木杭を好む。効きは重みを最大2倍にする程度で、決定はしない。
- `forest` は従来どおり「成熟度」（§3.1の定義）。面積比への変更は決めていない。

200seedで「地形の条件→選択の傾向」を条件付きの割合で再測定した（`issue35-d2a-audit.json` の `conditionalShares`）。

| 傾向 | 地区別の割合（川辺／丘陵／入り江） | 地形の値の三分位別（低／中／高） |
|---|---|---|
| 高床・木杭・高床支柱（水） | 63.5%／19.0%／62.5% | 19.0%／63.4%／62.6% |
| 石積み・整形石（傾斜） | 12.0%／39.5%／14.0% | 13.0%／（中は3件）／39.1% |
| 段状基礎・石の土台（傾斜） | 18.0%／67.0%／21.0% | 19.5%／（中は3件）／66.5% |
| 木造（成熟林） | 57.0%／22.0%／60.5% | 30.1%／44.7%／64.6% |

調整前は、例えば高床の構造（S07）は川辺20・丘陵18・入り江24でほぼ差が無かった。調整後は50・9・55になった。

**良くなった点**
- 地形と対応した傾向がはっきり出た。
- 成熟林は同じ種類の地区の中でも値がばらつくため、三分位で30%→45%→65%と段階的に効いている。これは地区の種類だけでは説明できない、地形の値そのものの効きである。

**残る問題（Humanの判断が必要）**
- **川辺と入り江が似てきた**。どちらも水が多く、相性の表も木造・高床に寄っているため、地区の種類の差よりも共通性が強い。水の三分位の中と高（ほぼ川辺と入り江にあたる）で、高床の割合が同じ（63%）になっている。入り江の方が水が多いことは効いていない。
- その結果、3地区のうち2地区で地区ごとの軸（構造・壁・基礎・屋根材・窓・入口）が**完全に一致する世界が3件**、1軸だけ違う組が9組になった（調整前は0件・4組）。配色は地区ごとに違い得るが、配色は形の違いに数えない。
- 傾斜と崖の値は、記録上、丘陵以外では0のままである（§3.1）。そのため、傾斜の効きは実質的に「丘陵かどうか」と同じ意味になっている。

対応の候補（いずれも未実施）：
- 入り江の相性を川辺と分ける（例：入り江は瓦・漆喰・土壁など、潮風や乾いた砂地に寄せる）。ただし記録に「潮風」や「砂地」の値は無いので、地区の種類による文化的な仮定になる。
- 同じ世界の2地区で地区ごとの軸が全て一致した場合だけ、その組を区別する仕組みを入れる。ただし地形と無関係な差を人為的に作ることになる。
- このまま受け入れ、D2-cの原寸の画像で、配色と個体差も含めて区別できるかを見てから決める。

**Human判断（PR #113、2026-11-10）**：最後の案（このまま受け入れ、D2-cの原寸の画像で決める）を採る。D2-cの比較には、2地区の地区ごとの軸が完全に一致した3世界と、1軸だけ違う組を必ず含め、配色と個体差を含めて原寸で区別できるかをHumanが判断する。区別できなければ、入り江の相性を分ける等の対応をその時点で決める。

### 3.2 D1の手書きの違いのうち再現しないもの（6セル）

用途の規則は、D1の「市場」「穀物庫の窓」「仕事場の大開口」「会堂の整形石」などの機能による違いを再現した。再現しなかったのは、D1で**文化ごとに手で指定していた**違いである。

| セル | 規則の結果 | D1 |
|---|---|---|
| C1 穀物庫 | 屋根材 茅 | 木板 |
| C2 穀物庫 | 窓 W1 | W6 |
| C3 会堂 | 装飾 O1+O7、2階 | O7+O8、1階 |
| C4 会堂 | 装飾 O1 | O2 |
| C5 穀物庫 | 入口 E6 | E2 |
| C6 会堂 | 屋根材 木板、2階 | 瓦、1階 |

2階建ての差は、監査で用途の規則に固定のハッシュ値0を渡したために出たもので、建設時の様式では建物ごとのハッシュで30%の会堂だけが2階になる（4,200件中61件）。それ以外の差は文化の個性であり、機能の規則で再現すべきものではないと考えている。D1の6文化を「規則で完全に再現する」ことは目標にしていない。
