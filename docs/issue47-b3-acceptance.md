**状態：B0〜B2eはすべてmainにマージ済み。B3はHumanによる最終受入（本書を見て、実際のゲームで確認し、Issue #47 を閉じるかを決める）。**

設計書：[issue47-biome-design.md](issue47-biome-design.md)（B0）。実装計画と各段階の記録：[issue47-b2-plan.md](issue47-b2-plan.md)。

## 1. 何ができたか

新しく作る世界は、seedから**初期の気候**を持ち、それに従って**植物と地表の見た目**が決まり、年とともに変わる。

- **気候と7バイオーム**：砂漠・ステップ・草原（サバンナ）・温帯林・熱帯雨林・亜寒帯林・ツンドラ。境界に近い世界（約21%）は、隣のバイオームの植物が一部のパッチに混ざる。
- **植物群**：3地区×440パッチ（8×8px）ごとに、局所環境（普通・河畔・湿地・海岸・岩場）と植物群（高木・低木・草本・地表材）を持つ。
- **年ごとの生育**：植物は切り開かれてからの年数で育ち（裸地→草→低木→若い林→成熟林）、気候とその年の#34の長期偏差が許す段階までしか育たない。環境が悪くなると25年ごとに1段階ずつ衰える。
- **描画**：13系統の植物を2つの描画器（A/B）で約半々に描く。建物とはY座標で前後を決め、木は揺れる。地表は色と地表材の模様（砂は粒）で描き分け、遠景も手前の地面のトーンに合わせる。

**見た目だけの変更である**（Human決定 2026-11-12）：気候と植物は、文明（人口・収穫・経済）にも#34の数値にも作用しない。文明への影響は別のIssueで扱う。

以下を、新しい世界をいくつか作って見てください（seedの目安：砂漠3・5、ステップ11、草原23、温帯林6・21、熱帯雨林1、亜寒帯林18、ツンドラ4、移行帯44）。

3. 建物と植物の前後、木の揺れ、遠景の色が自然か。
4. 過去の年に戻る・地区を切り替える・保存して再読込する、を繰り返しても見た目が変わらないか。
5. 動きのある表示で、もたつきが気にならないか（年や地区を切り替えた直後に0.1秒前後の準備がかかる）。

## 6. Humanの確認結果（2026-11-13）

1. 気候が絵で分かるか：だいたい分かる。
2. 森が育ち、集落の周りが開けていくか：見えた文明もある。
3. 前後・揺れ・遠景：**一部の畑が屋根を貫いて手前に見えた** → 修正した（下記）。
4. 過去観測・地区切替・再読込：問題なし。
5. 切り替え時のもたつき：気にならない。

**畑の描画順の修正**：畑は平らな地面だが、建物の層の中で家や施設と同じリストの順に描かれていた。手前の家（例：接地線y=135）より後に奥の畑（y=118）が描かれると、家の上部が畑に塗られる。#47以前（B0のマージ前）のコミットでも同じ7件が起きるため、#47で生じた問題ではない。

- 修正：畑を、屋根・人・公共建築・その他の建物より先に描く（`src/scene/structure-order.ts`）。畑は自分の敷地の中しか塗らないので、先に描いても隠すべきものを隠さない。植物の前後判定（接地線の図）とB1bの比較スクリプトも同じ順にした。
- 影響：画素が変わるのは、畑と手前の建物が重なる所だけ。旧形式の世界の静止画の照合（`tests/fixtures/scene-motion-static-reference-v1.json`）では9件中2件が変わり、変わった画素（8px・12px）はすべて畑の敷地の中だった。この2件の値を更新した。保存・歴史は変わらない。
- テスト：`tests/browser/structure-order.test.mjs`（畑と手前の建物が重なる画素に、静止画でも動きのある表示でも畑が出ない）。修正前のコードでは失敗、修正後は合格することを確認した。
