# 橋の対岸にも集落が育つ配置（terrain-placement-v3）

seed 42 の川辺で、橋があるのに1000年時点でも住宅が片岸にしか建たないことを再現した。v2は既存の家だけを成長の起点にし、そこから80pxを超える候補を除外していた。最初の対岸の家を建てる前に、同じ岸の空き地が優先され続けていた。

v3では、通行可能な検証済みの橋の両岸の入口も、家・住宅の成長の起点にする。橋の保存済み幾何が持つ入口を用い、曲がった川岸でも架橋時に検証した通路を使う。周辺の密度評価により、空いている対岸の入口から住宅が育ち、その家も次の成長の起点になる。

入口からの80px制限、余白、物理的な敷地条件、既存建物の入口と元のアクセス根への接続検証は維持する。渡れる橋がない・橋が壊れている・経路が建物で塞がれている場合には、対岸への接続を作らない。単に川の左右へ建物を均等に描く処理ではない。

## 既存の文明でも利用できる

新規作成はv3を使う。v1・v2の生成地形の保存を開くと、「記録の保存」の隣に **今の文明の配置を改善** が表示される。押すと、その年以降の建設にv3を使う。現在までの建物・住宅の敷地、橋、地形、年代記、過去の景観は変更しない。「この歴史を保存」を押すと、配置方式も保存され、読み込み後の続きに引き継ぐ。

ボタンを押すまでは元のv1・v2で継続し、保存値を黙って書き換えない。旧固定地形の世界は対象外。建設が対岸へ広がるため、将来の建設数や発展の時期は従来の継続と異なり得る。

## 検証

- seed 42の自然進行で、橋ができた後に初めて対岸の住宅が成立することを確認する。
- 旧1000年の世界からの切り替えで、過去の保存内容と景観が変わらず、後続の住宅が対岸に成立することを確認する。
- 対岸の候補選択を全探索と比較する。破損した橋・橋上の障害物では対岸の建設を認めず、通行可能な橋に戻すと過去のHOLDキャッシュに妨げられないことを確認する。
- ブラウザでボタンを押した直後の画像が変わらず、明示保存したv3のpolicy・履歴を別タブから復元できることを確認する。
- `scripts/audit-cross-river-growth.mjs` でseed 42の10000年、seed 1・21の2000年を検証する。gzip保存往復・読み込み後の続き・過去27情景を照合する。
- 旧v1・v2の固定監査は各方式を明示して維持する。新方式の結果で旧承認や固定ハッシュを上書きしない。

`PLAYWRIGHT_BROWSERS_PATH=/tmp/namonaki-browsers node scripts/review-cross-river-growth.mjs` で、`artifacts/terrain31-cross-river/index.html` にseed 42の1000年の新旧比較、および1000年から改善した場合と旧方式のまま継続した場合の1500年の比較を生成する。建物や人口を画像用に追加しない。CIの `organic-growth` jobが監査と画像を再生成し、`terrain31-organic-growth` artifactに保存する。
