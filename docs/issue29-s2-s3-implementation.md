### 1.1 ステータスバー（S2）

- 値：人口は「約 N 人」、他は「x.x / 100」。差分は「↑ +2.1」「↓ −16.8」「±0.0」のように**記号と符号を文字で**示し、色で善悪を表さない（中立色のみ）。丸めは表示だけで、差分は丸め前の値で計算。正負で同じ丸めになるよう絶対値で丸める。
- 見出し：「世界暦 N年の確定値 · 増減はN−20年との差」。過去観測中は「（当時）」、選択待ちは「（分かれ道の前の年）」。
- 20年未満は「比較対象なし（20年未満）」（欠測とは区別）。#29以前の台帳の世界は「記録なし」（人口は従来どおり景観の人口を表示し、他は推測しない）。
- 選択待ち：最後の確定年の値だけを表示し、未確定年の途中値は出さない（E2Eで、途中値ではなく確定値が出ることを確認）。
- 観測地点の切替では5指標は変わらない（文明全体であることを注記）。
- レイアウト：PCは5列、幅680px以下は3＋2の折返し。

### 1.2 歴史グラフ（S3）

- 縦軸：4指標は0〜100固定。人口は0起点で、表示範囲の最大値を切りの良い値へ切り上げ（人数・「万」表記）。人口と0〜100指標を同じ軸に重ねない。
- 表示窓と観測年を分離：既定は最後の確定年で終わり、ライブ中は追従。グラフで過去を観測すると窓を固定し、再センタリングしない。窓の外の年（入力・記録移動など）を観測した時だけ、その年が入る最小限だけ窓を動かす。「現在へ戻る」で追従に戻る。窓は0年未満・最後の確定年より後へ出ない。
- 最後の確定年を選ぶとライブ観測（スライダーと同じ。選択待ちの分かれ道は表示されたまま）。
- 全期間の縮約：横幅の列ごとに確定値の**先頭・末尾・最小・最大（元の年付き）**だけを描く。1年だけの急落・急増も残る（テストで確認）。保存データは削らない。選ばれる年は常に整数年で、値は正本から読み直す。
- 欠測年は線で結ばない（系列を連続年ごとに分割）。
- 記録マーカー：年代記の`important`な確定記録だけ。同年・同列（4px）の複数記録は1本にまとめ件数を示す。因果は表示しない。
- 入力（Human決定C）：
  - マウス・ペン：グラフ上で押して離した主ボタンの年へ直接移動（`pointerType`で判定。UA判定なし。右クリックや外から持ち込んだドラッグでは移動しない）。
  - タッチ：候補年とその年の値・記録を表示し、「この年を観測」で初めて移動。
  - キーボード：年の数値入力、±1年、前後の記録の年へ移動し、「この年を観測」で確定。最後の確定年より後は確定年に丸め、空欄は無視する（0年扱いにしない）。
  - 進行・新しい世界・読込・スライダー・年代記からの移動で候補は破棄。
- 系列の読み取り：`confirmedMetricRange()`（S1の契約に追加）で1回の走査。人口はblocksを先頭から1度だけ辿る（年ごとのチェックポイント再生をしない）。年ごとの`observeCivilizationMetrics()`と完全に同値であることをテストで確認。
