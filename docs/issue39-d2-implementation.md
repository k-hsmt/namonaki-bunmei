## 1. 体験

- 観測画面の上部（「動き」の右）に「調べる」ボタン。初期はOFFで、通常の観測画面は変わらない。
- ONにすると：
  - 風景は**静止画**になる（「動き」は一時的に無効。OFFに戻すと元の設定に戻る。設定値は変更しない）。
  - マウスを載せた対象と選んだ対象だけに、**風景の外側の別レイヤー**へ1pxの淡い輪郭を描く。風景のCanvasには描かない。
  - クリック（タッチ）した**見えている画素**の対象の記録を、風景の下のパネルに表示する。
  - パネル下部の「この土地の記録から調べる」（折りたたみ）に、その年・地区の全対象を「風景に見えるもの」と「記録はあるが、この年の風景には見えないもの」に分けて並べる。キーボード・支援技術でも、ここから選べる。
- 進行・乱数・保存には一切触れない。調べている間に自動進行していれば、表示年と一緒に対象を再検証する。
- 地区を変えると、別地区の選択は解除する。世界の作り直し・読み込みでも解除する。

## 2. 選択マスク（`src/scene/historical-pick-mask.ts`）

静止画は次の層を順に重ねて描かれている（`drawGeneratedSceneReview`の本番経路）。

背景（地面・水路・橋）→ 雲 → 奥の植物 → 人 → 建物の層 → 手前の植物 → 動物

ある対象がある画素の持ち主になるのは、次の2条件を両方満たすときだけ。

1. **自分の層で一番上にある**：その対象だけを除いて同じ層を描き直すと、その画素が変わる。判定は描画コード自体が行う。色からの推定や矩形の当たり判定は使わない。
   - 施設：建物の層から、その施設を除く。
   - 住宅街区：建物の層から、その街区を除く。屋根部品はすべて街区へ対応づける。
   - 橋：背景から、その橋を除く。
   - 水路：背景から、水路の描画だけを除く。
2. **後の層に覆われていない**：
   - 建物の層の対象：手前の植物・動物に覆われていない。
   - 背景の対象：雲・植物・人・建物・動物のどれにも覆われていない。

その他の扱い：

- 1画素に2つの対象が該当した場合は「競合」として記録し、候補の選択で解決する。黙ってどちらかに割り当てない。実世界の検証では競合は0件だった。
- 左右反転の地点では、各層が反転後の画面座標で描かれるため、マスクも画面座標のままになる。
- **見えない対象**はマスクに画素がないため、風景からは選べない。記録一覧からだけ開ける。見えない理由には次の2種類があり、どちらも一覧の「見えないもの」に入る。
  - 描かれているが、全体が覆われている。
  - そもそも描かれていない（例：埋め戻した水路）。
- 選択はマウス・ペンなら押した画素だけ。タッチは約12 CSS px（1〜8画素）の範囲で近い順に探し、2件以上あれば「近くの候補」を表示して選び直せる。

**正しさの裏付け**：マスクが使った同じ層を重ね直した画像は、本番の静止画とRGBAが**全画素一致**した（seed 42の4年×3地区、seed 1の左右反転3地区）。したがって、マスクの重なり方は実際の画面と同じである。

## 5. テスト

- `tests/browser/historical-inspector.test.mjs`（新規5件）。実世界を2つ使う（seed 42：反転なし、水路あり／seed 1：全地区反転、各1,200年）。
  1. マスクの層を重ね直すと本番静止画と全画素一致する。見えている全対象について、その画素をUIでクリックすると同じ対象のパネルが開く（PC、反転地区を含む）。
  2. 覆われた街区と埋め戻した水路は、風景からは選ばれず、記録一覧の「見えない」側から開ける。その際、輪郭は描かれない。
  3. 調べる操作の前後で、書き出した保存JSONがバイト単位で一致し、風景Canvasの画素も不変。輪郭は別レイヤーにだけ描かれ、OFFで消える。観測年も動かない。
  4. スマホ幅（390px、タッチ）：小さな対象の脇をタップしても届く。複数候補が表示され、別の候補へ選び直せる。Canvasは16:9のまま、パネルはCanvasの外。キーボードでボタン→記録一覧→対象を開ける。
  5. 選んだ橋を700年で見ると「まだ建てられていません」となり、建設年は表示しない。1135年では「損傷して渡れない」。別地区へ移る・別世界を読み込むと解除。動きは調べる間だけ停止し、終えると戻る。
- 変異確認：「後の層に覆われていない」条件を外すと、テスト2が失敗することを確認した。
- `tests/historical-records.test.mjs`：`name`の検査を追加（8件）。
- 全体回帰の結果は §8。

## 6. 性能（手元計測、ヘッドレスChromium）

- 1枚のマスク生成は**約110〜220ms**（1,200年世界、対象1〜23件）。同じ年・地区はキャッシュする。
- 調べている間に年が変わると再生成する（高速進行では描画自体が1.4秒間隔に間引かれる）。
- 実機スマホ、10,000年世界での計測はしていない。

## 7. Humanレビューで見てほしい点

レビュー画像は `artifacts/issue39/gallery/`（git管理外。生成スクリプトは同じディレクトリ）。

1. **輪郭の見え方**：淡い黄白色の1px輪郭を、対象の外側に描いている。選択中は不透明度0.95、マウスを載せた対象は0.55。明るい空や水路の上では目立たない。
2. **小さな対象**：600年の水路は数画素しか見えておらず、輪郭も細い。風景からは選びにくいが、記録一覧からは開ける。
3. **タッチ半径**：約12 CSS px。スマホ幅ではほぼ12画素分。
4. **パネルの密度**：住宅街区は履歴が30件を超えるため、一覧は高さ16remでスクロールさせている。年代記は題名だけを表示する（年移動はD3）。
5. **「見えない」の文言**：「記録はありますが、世界暦N年の風景では見えていません。」とし、理由（植物・埋め戻し等）は断定しない。状態の文言（例：埋め戻されている）がある場合は併記する。
