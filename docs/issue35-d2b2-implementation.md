## 2. 判定の決まり（Human判断A、設計書 v2.3）

- **最も小さい形（代替の最後の段階：平屋根・通常の軒・低い勾配）でも重なる部分は受け入れる。** 今の本番の画面でも、施設の絵（20〜41px）は幅18pxの敷地からはみ出して隣と重なっているため。
- 判定するのは、最も小さい形からはみ出した部分（文化によって増えた張り出し）だけ。それが次のどれかに当たると、決まった順で代替する（深い軒をやめる → 勾配を下げる → 張り出しの小さい屋根 → 最も小さい形）。
  - 同じ地区で**前の年までに**建った建物の範囲（同じ奥行きの帯＝接地の高さの差が6px以内）
  - その年に建っている橋の床
  - 敷地の左右、地面に近い2行の水面
- 最後の段階は必ず収まるので、上空の判定によるHOLDは起きない。制約の修復に失敗した場合のHOLDは残り、そのときは進行を失敗として元の世界を保つ。
- **同じ年に建った建物どうしは判定しない。** 保留中の選択の解決で同じ年に建設が入っても、すでに記録した様式が変わらないようにするため（D2-b1のレビューで直した問題と同じ構造を避ける）。

厳しい判定（同じ帯ではまったく重ならない）のままだと、3世界中2世界（seed 7・3）で市場・会堂の壁の幅だけで隣と重なり、進行が止まった。
