# Issue 33 風景と暮らしの動き

2026-11-08着手。#32（PR #66）の統合・公開を確認し、次の課題として進める。

## 設計

年次シミュレーション・植生の齢・保存正本とは別の秒単位の描画時計を持つ。雲、草木の1px程度の揺れ、水面の小さなきらめき、稼働する工房等の煙と、住宅から実在施設へ向かう軽量な往来を描く。新しい履歴・住民・道路・建築現場は作らない。乱数は演出専用の座標ハッシュのみを使い、文明のRNGを消費しない。

活動は確定年に存在する使用中の住宅・家屋と、稼働中の畑・市場・工房を結ぶ往復。2pxの歩行窓を使い、敷地・木の根元・荷車を避け、検証済みで通行可能な橋だけを渡る。安全な経路がなければ移動を表示しない。人口・地区の規模に応じて最大6人、無人の地区は0人。これは個別住民の行動を保存する本格AIではなく、その年の生活の意味に基づく演出。

観測時は最新年の情報を返し、同じ地形で描画内容が同じ間は背景・建築・経路を再利用する。建物・植生段階・橋の状態・活動人数・20年単位の演出位相などが変わったときに準備し直す。毎フレーム履歴や地形を読み直さず、準備したレイヤーを合成する。背景・建物・経路に共通する投影は一度だけ計算する。凍結した地区の物理情報・占有・通れる橋・木の根元・荷車・活動元／目的地・人数上限が同じ間は、直近の経路を再利用する。キャッシュは地区ごとに1件だけとし、返した歩行配列の変更で内部の結果が汚染されないようにする。木の根元・建築・川筋は動かさず、樹冠や水面だけを動かす。動く人は地表と建築の間に描き、建物や屋根の上を歩かせない。破損橋で対岸へ近道しない。

描画は最大12fps。非表示タブでは停止し、復帰時に大きな位置飛びをしない。端末のモーション軽減設定を優先し、「動き」チェックで停止できる。演出設定は世界保存と別のキーに記録し、保存できない環境でも停止操作が使える。旧固定地形の情景は静止画を維持する。

動きを無効にした場合と、従来の静止画APIを使った場合は以前の画素を保つ。保存形式・renderer ID・施設の配置方式は変更しない。秒時計は保存しないので、任意秒での画素一致と、同一年に存在する施設・活動の意味の一致を分けて検証する。

## 検証

- 自然の動き、家→畑→家／市場往復、人口減少・無人化、破損橋と過去観測を原寸と4倍で比較する。
- すべての経路・足元が2pxの歩行窓に入り、実在する入口を結ぶこと、障害物・水面を不正に横切らないことを検証する。
- 同じ観測と秒指定で同じ動きになり、再描画・停止・再開・描画だけで文明の履歴、植生、RNG、保存が変わらないことを確認する。
- モーション軽減、チェック操作、非表示タブ停止、更新レート上限と、観測の変更時だけ準備をやり直すことを確認する。
- PCとスマホ相当のviewportで確認し、後者はCPUを4倍遅くしたChromeでも計測する。これは実機の測定とは区別する。準備時間とフレーム描画時間を記録し、12fpsの83.3ms予算内に収まることを検証する。

## 比較と受け入れ資料

`scripts/review-scene-motion.mjs` はseed 42の年0・300・1000の自然到達景観と、破損橋・無人化の制御比較を出力する。`artifacts/motion33/index.html` で10秒間の再生・停止・コマ送りができ、原寸・4倍・経路確認画像も添付する。制御比較は実際の歴史とは区別して表示する。10秒抜粋の繰り返しでは末尾から先頭へ戻る。

`scripts/benchmark-scene-motion.mjs` はPC／スマホ相当（ChromeのCPU 4倍スロットリング）各3地区で、静止画・初回準備・再準備と、180フレームの描画時間を別々に計測する。基準はフレームp95が12fpsの83.3ms以内。初回準備は同期処理のため、低速環境では数百msかかる場合がある。これはフレーム予算の合格と分けて記録し、実機スマホの計測とは扱わない。

CIの `scene-motion` ジョブが比較一式と `performance.json` を `scene-motion33-acceptance` として保存する。ユニットテストは実在入口・全歩行窓・橋・人口ゼロ・往復・キャッシュの分離を確認する。ブラウザテストは旧画素9例、任意秒の決定性、保存全体の一致、最大fps、非表示時停止、端末設定、停止設定の持続、実際の連続年での再利用と画素一致を確認する。静止画を比較する既存ブラウザテストでは端末のモーション軽減を指定する。

## 水面と雲の調整（PR #67マージ後）

Humanの景観確認を受け、雲を0.45／0.65px毎秒から0.68／0.98px毎秒（約1.5倍）へ変更する。川は保存された出口へ向かう水面上の短い筋、海は実際の陸地との境界へ寄せる短い波を加える。水面内の距離場から経路を準備し、中州を避ける。出口につながらない水域には流れを作らない。河口が非表示の場合は海または画面下端に接続する淡水を出口として使う。

筋・波は進みながら現れて薄く消え、繰り返しの位置飛びを目立たせない。水面の保存セルと実際の背景色を照合し、岸・橋・桟橋を塗り替えない。秒ごとの描画では準備済みの短い経路とマスクのみを使う。海辺を比較に追加し、自然進行5景観・制御比較2景観を生成する。川の中州回避、海の岸向き移動、鏡像と橋を含む全変更画素の水面内制限をテストする。
