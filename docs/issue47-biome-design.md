## 3. バイオームの7主要分類

| ID（仮） | 主要バイオーム | 自然の造形・地表 |
| --- | --- | --- |
| desert | 砂漠・乾燥地 | 砂・裸地・岩、乾燥灌木、疎らな乾草、局所的な河畔の緑 |
| steppe | 半乾燥地・ステップ | 乾いた草、低木、断続的な裸地、少量の樹木 |
| grassland | 草原・サバンナ | 草本優勢、点在する疎林木、乾季の濃淡 |
| temperate_forest | 温帯林 | 落葉／常緑広葉樹、混交、下草、落葉 |
| tropical_rainforest | 熱帯雨林 | 大きく不規則で重層的な樹冠、シダ・つる、湿った地表 |
| boreal_forest | 亜寒帯林 | 針葉樹優勢、控えめな下草、苔、暗い土 |
| tundra | ツンドラ | 樹木がほぼない寒冷地、低木・苔・地衣類・岩 |

- 名称は世界の代表的な**気候由来の分類**であり、背景画像のスキンではない。
- 湿地、河畔、海岸、岩場は**局所環境**として扱い、独立した8番目・9番目の主要バイオームにはしない。
- 砂漠世界の川沿いにも河畔林があり得る。局所的に緑が濃いからといって世界全体を熱帯雨林へ変換しない。
- 同じ主要分類でも、地形やseed、局所的な水分で異なる植物構成と景観になる。

### 3.1 出現頻度の目標

調整前の例：砂漠11%、ステップ14%、草原15%、温帯林19%、熱帯雨林15%、亜寒帯林15%、ツンドラ11%（100%）。

**Humanが確定したのは砂漠とツンドラ各10〜12%程度という方向性**。他の具体的割合はB1で試走し見直してよい。この数値表は**バイオームを直接抽選する確率表ではない**。世界の気候分布と分類境界を調整する際の評価目標とする。

1000seedの標本比率は統計的に揺れるため、毎回厳密に10〜12%に収まることは要求しない。母比率約11%を目指し、一次監査で各8〜14%程度を警戒目安とし、別のseed集合でも再確認する。特定バイオームを捨てて引き直す処理や固定出現クォータは使わない。

## 4. 気候の生成アルゴリズム

### 4.1 世界共通の初期気候

値域と名前は現時点の設計候補。すべて**ゲーム内の整数指標**であり、現実の℃・降水mmではない。

~~~ts
type WorldClimateBaseline = Readonly<{
  schemaVersion: 1;
  ruleId: 'initial-climate-v1';
  temperatureIndex: number;             // -100..100: 寒冷〜高温
  moistureSupplyIndex: number;          // -100..100: 水分供給
  annualTemperatureRangeIndex: number;  // 0..100: 年間寒暖差
  rainfallConcentrationIndex: number;   // 0..100: 降水の季節集中
  dominantBiome: BiomeKind;
}>;
~~~

世界seedの名前空間化された専用ハッシュから作り、**文明RNGを消費しない**。同じseedと生成規則なら同じ気候。画面描画・読込・地区切替で再抽選しない。

### 4.2 生成順序

1. seedから温度、水分供給、寒暖差、降水集中の基礎値を決定的に生成する。
2. 4軸を無条件の独立一様乱数にはしない。気温・蒸発傾向・降水の偏りなどの整合を考慮した**相関ある生成**にする。ただし特定の緯度や現実世界の地図は再現しない。
3. 基礎値から、植物に使う「有効な生育温度」と「有効水分」を導く。例えば高温下の水分消費や降水集中による乾季の長さを考慮する。
4. 有効温度・水分を主因として7主要分類へ割り当てる。極寒で樹木が育たない場合はツンドラ、適度に湿った寒冷地は亜寒帯林、著しく乾燥した生育可能地は砂漠、その隣はステップ、中湿の開放地は草原、湿潤温帯は温帯林、通年的に高温多湿なら熱帯雨林を主な方向性とする。
5. **植物の適性は連続値**として残す。分類の境界付近でバイオームラベルが変わっても、植物群が全て瞬間的に入れ替わる仕様にはしない。
6. 生成分布の校正は気候生成関数と分類境界を調整し、生成済みの世界を別カテゴリへ「再抽選」しない。

**B0ではこの生成順序と分離原則を決定する。** 正規化係数、相関、具体的な閾値はB1で全7景観・1000seed監査の証拠を得て確定する。未検証の数値を現実の気候モデルとして説明しない。

### 4.3 地区・8×8pxパッチの局所条件

入力は#31で確定済みの地形正本。共通気候を共有したうえで以下を評価する。

- **川辺**：実在の淡水への距離や斜面から湿潤な河畔帯を成立させる。
- **丘陵**：傾斜、岩面、表土、標高に応じて樹高・成立可能な植物群を変える。
- **入り江**：海水は淡水bufferと混同しない。塩・風・水際を別の局所条件として表現する。
- **湿地・河畔・海岸・岩場**：地区全体の別バイオームではなく、複数のパッチへ局所的に分布させる。

水域、斜面、土地利用、施設敷地、建設可能地は保存済み地形・土地利用の正本を尊重する。植物の配置だけを理由に地形や建物を変更しない。

## 5. 植生の造形：B1で全系統を比較する

約12系統というHuman決定を満たす、**13系統の試作候補**を採用する。比較後に統合・削除する余地はあるが、B1aでは最初から3種類に絞らない。

| 系統 | 造形で区別する要素 |
| --- | --- |
| 1. 落葉広葉樹 | 丸く不均一な樹冠、枝の透け方 |
| 2. 常緑広葉樹 | 厚く広がる葉群 |
| 3. 針葉樹 | 尖った樹形、段状の枝 |
| 4. 熱帯高木 | 大きな不規則樹冠、縦方向の層 |
| 5. 乾燥地の疎林木 | 横に広い枝、疎らな葉 |
| 6. 河畔樹木 | 水辺で成立する特徴的な樹形 |
| 7. 乾燥地の低木 | 小さく硬い灌木、葉の間隙 |
| 8. 寒冷地の低木 | 地表に沿う低い姿 |
| 9. 一般低木 | まとまりある茂みと空隙 |
| 10. 草本 | 短草・長草・乾草の姿 |

| 13. 苔・地衣類 | 岩や地面を覆う低い植生 |

**地表材**（砂、岩、裸土、落葉、湿った土、寒冷地表）は植物とは別のカテゴリ。樹木のない場所にも景観の個性を持たせる。

各植物について、可能な範囲で若齢／成熟、疎／密、背丈／樹冠幅の造形を試す。**単純な色替えを主な差別化手段にしない。** B1では植物単体と、建物・橋・道のある実景観で評価する。採用数をHumanが判断するまでは本編へ大量導入しない。

### 5.1 植生データの責務分離

- **形態**：幹、樹冠、枝、葉、色群、草の高さなど描画の特徴。
- **生育適性**：温度、水分、季節集中、局所的な淡水・岩場・海岸条件など。
- **年次状態**：生物的な齢、被覆、活力度、ストレス、攪乱・回復の進行。
- **描画**：確定した年の年次状態と形態を、地形と遮蔽順序に従って投影する。

植物群とパッチの初期値を**世界正本として固定**する。過去観測で当時の植物群を現在の気候から再抽選しない。

### 5.2 既存8×8パッチとの統合

現行の#32実装は3地区それぞれ440個（地表y=96..179）の8×8pxパッチを持ち、初期の[齢、成長速度、到達段階]と、#34の年次[成長単位、ストレス、土壌負債、利用時計]で動く。この空間区分は**まず維持する**。

新モデルの概念的なパッチは次の通り。

~~~ts
type VegetationPatchBaseline = Readonly<{
  habitat: 'ordinary' | 'riparian' | 'wetland' | 'coastal' | 'rocky';
  canopyArchetype: PlantArchetype | null;
  shrubArchetype: PlantArchetype | null;
  herbArchetype: PlantArchetype | null;
  groundMaterial: GroundMaterial;
  initialAge: number;
  establishmentPotential: number;
}>;

type VegetationPatchYearState = Readonly<{
  growthUnits: number;
  stress: number;
  soilDebt: number;
  // 被覆と世代更新の追加状態は実装設計で最小限に確定
}>;
~~~

1パッチに高木・低木・草本・地表を併存させてよいが、すべての植物個体をシミュレートする必要はない。建設・水域・地面のマスクを踏まえ、年次の植物状態を描画へ変換する。**旧実装の固定最大段階だけで将来の全気候を説明しない。**

## 6. #32・#34との一体的な年次成長（Q4）

**#47の完成範囲には、初期景観に加え、気候に適合した長期の成長・衰退・回復を含める。** 既存#32の自然遷移・確定攪乱と#34の長期変動の責務を尊重して統合する。全機能の作り直しは求めない。

### 6.1 初期基調と長期偏差を区別

現行の#34 EnvironmentState の humidity / temperature は実気温や実降水量ではなく**長期の相対偏差**。年0の0は「温帯・標準的森林」を意味しない。

生育適性は、**初期気候基調 + 確定年Yの長期偏差 + 地区／パッチの局所環境 + 土壌・土地利用・灌漑効果**から決める。基調と偏差の尺度が違う場合は単純加算せず、明示的な変換式・範囲制限を通す。

### 6.2 生育・衰退・遷移

- 高適性の土地では裸地→草→低木→若木→成木が成立しうる。
- 砂漠やツンドラの不適地では、1000年経過しただけで**一律に成熟林にならない**。
- 気候が変わっても翌年突然別の樹種に変換しない。生育停止、持続ストレス、枯損、更新という時間経過を持つ。
- 長期湿潤化・温暖化が続けば、新しい植物群が**徐々に定着可能**となる。初期の最大成長段階が永久固定の制約にならない。
- 伐採、火災、耕作・土地の占有、放棄など、出典付きの確定した攪乱を保持する。未知の過去の攪乱を捏造しない。
- 自然な更新に確率を使う場合、seed・地点・パッチ・確定年の**専用ハッシュ**から決定し、文明RNGや描画アニメーションに依存させない。
- 進行は確定した年に限り、過去観測が状態を書き換えない。

#34の気候周期や灌漑施設・川の形そのものは本Issueの改修対象外。相対偏差と基調の合成、および植物適性への作用を接続する。海水を淡水として扱わない。

## 7. 初期文明と景観の整合（B案）

- 新規生成に成功した世界では、年0の小集落を維持する。
- 砂漠の川辺、寒冷地の生活可能な場所など、**保存済みの可住地・水辺**と矛盾しない初期景観にする。
- 気候を都合よく別分類へ引き直したり、植物のために施設・川を移設しない。
- 現行世界生成は地形・集落の成立に失敗するseedがありうるため、**気候追加によって新しい生成失敗が増えないか**B2で検証する。失敗時に別の気候へ黙って差し替えない。
- #47では人口・食料・交易の文明シミュレーションを直接変えない。環境は文明の未来を固定しない。

## 8. 描画・保存・責務境界

- 描画は固定320×180、既存3地区と建物・水・土地の正本を尊重し、樹冠による建物の過遮蔽を避ける。単なる背景スキン差し替えは不可。
- 同一世界の大域気候を共有しつつ、川辺・丘陵・入り江に地形起因の違いがある。草が疎らな土地や、低い植物しかない静かな景色も受け入れる。
- アニメーション（#33）や将来の季節の秒時計（#36）は、文明年次・植生年次の書込から分離する。
- 保存する正本は、初期気候・分類規則、必要なパッチ初期状態、攪乱の出典、長期気候・年次進行の履歴。現行形式のseed、年、地形、攪乱、観測の整合を検証する。
- 現行形式の保存→復元→同一操作、分割／一括進行、過去観測、3地区切替で**確定履歴・景観・文明RNGが不変**であること。
- 未知ルール、破損・改変・未来年・地形に合わない植物・出典不一致を拒否する。
- 旧セーブ読込のための移行コードは新設しない。形式破壊がある場合は**PRに変更内容と新規開始の要否**を明記する。

## 10. 受け入れ条件

- [ ] 同一地形×7気候で、木の**形・樹冠・下層・地表**に明確な差がある（背景色だけは不可）。
- [ ] 13植生系統を原寸スプライトで比較し、7バイオーム×3地区の320×180・4倍画像を提出する。強制気候はテスト専用。
- [ ] 同一バイオームでもseedや地形によって風景が異なり、同一世界の3地区に一貫性と局所差がある。
- [ ] 海水と淡水、物理的な地面と水域、植物と建物占有域に矛盾がない。
- [ ] 砂漠・ツンドラの出現率は各10〜12%程度を目標として1000seed以上で監査（標本誤差と観測率を区別）。
- [ ] 同一seedで同じ気候・初期植生を生成し、文明RNGを消費しない。気候による恣意的なリロールがない。
